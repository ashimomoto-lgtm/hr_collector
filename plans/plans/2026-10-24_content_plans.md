## A. ブランディングコンテンツ（第一想起獲得・専門性訴求）

### A-1. AI時代の1on1再考：若手の「AIで十分」にどう向き合うか？

| 項目 | 内容 |
|------|------|
| **想定読者** | マネジャー、人事担当者、経営層 |
| **切り口** | 若手社員がキャリア相談にAIを活用する傾向に対し、1on1が提供できる人間ならではの価値と、マネジャーがその価値を最大化する方法を考察します。 |
| **使用するネタ** | 若手のキャリア相談におけるAI活用志向 / 1on1の形骸化指摘 |
| **接続する資料** | メンバーのための1on1完全ガイド |
| **Why Now** | AIの進化と若手社員の価値観変化により、1on1のあり方が問われているため。 |

### A-2. 管理職の「罰ゲーム化」に終止符を！人的資本経営でマネジャーを救うHR戦略

| 項目 | 内容 |
|------|------|
| **想定読者** | 人事担当者（HRBP含む）、経営層 |
| **切り口** | 多くの管理職が多忙や孤独感から「罰ゲーム」状態にある現状を分析し、人的資本経営の視点から管理職をサポートし、その役割の魅力を再構築するためのHR戦略を提言します。 |
| **使用するネタ** | 管理職の「罰ゲーム状態」に関する報道 / 管理職の魅力度調査で低水準 |
| **接続する資料** | 1on1総研 調査レポート（各種） |
| **Why Now** | 人的資本経営が推進される中で、その要となる管理職のエンゲージメントが課題となっているため。 |

### A-5. 「互いに支え合う組織」の作り方：1on1が育む心理的安全性とチームワーク

| 項目 | 内容 |
|------|------|
| **想定読者** | 人事担当者、経営層、マネジャー |

| **Why Now** | 働き方改革やダイバーシティ推進が進む中で、個人のワークライフバランスと組織の持続可能性を両立させるために、相互支援の文化が不可欠となっているため。 |
