## A. ブランディングコンテンツ（第一想起獲得・専門性訴求）

### A-1. 3人に1人が「就職やり直し」を考える時代：新入社員のエンゲージメントを高める1on1の本質

| 項目 | 内容 |
|------|------|
| **想定読者** | 人事担当者、新入社員の定着・育成に課題を持つマネジャー |
| **切り口** | 新入社員の約3割が就職活動のやり直しを検討する現状を深掘りし、その背景にある「仕事内容」や「働き方の柔軟性」への期待と入社後のギャップを分析します。1on1が新入社員の早期エンゲージメントと定着にどう貢献できるか、その本質的な役割と企業の取るべき戦略を考察します。 |
| **使用するネタ** | 新入社員の就職活動やり直しに関する調査 |
| **接続する資料** | 1on1総研 調査レポート（各種） |
| **Why Now** | 新入社員の定着が企業の重要課題となる中、早期離職を防ぐための新たな視点が求められているため。 |

### A-2. AI時代のキャリア自律：1on1が拓く個と組織の成長戦略

| 項目 | 内容 |
|------|------|

| **切り口** | AIの進化がキャリア観に与える影響と、約7割がスキルセット変更の必要性を感じている現状を分析し、人的資本経営におけるキャリア自律の重要性を再確認します。1on1が個人のキャリア開発と組織の成長支援をどう両立させ、未来を創る人材を育成するかを論じます。 |
| **使用するネタ** | AI時代のキャリア観に関するアンケート / キャリア自律と組織環境の実態調査 |
| **接続する資料** | 1on1総研 調査レポート（各種） |
| **Why Now** | AI技術の進化が加速し、個人のキャリア形成と企業の成長戦略が密接に連携する中で、HRの新たな役割が問われているため。 |

### A-3. 働き方改革の副作用？「職場の低体温化」を1on1で乗り越え、組織に活力を取り戻す

| 項目 | 内容 |

| **使用するネタ** | 職場の低体温化の実態に関する調査 |

| **Why Now** | 働き方改革が進む中で見過ごされがちな「職場の活力」の重要性が認識され始め、新たなマネジメントアプローチが求められているため。 |

### A-4. ドラッカーに学ぶ「会社の測り方」：現代組織における「見えない社員」問題と1on1の役割

| 項目 | 内容 |
|------|------|
| **想定読者** | 経営層、人事担当者、組織規模拡大に伴うマネジメント課題を持つマネジャー |
| **切り口** | ドラッカーが提唱した「トップが資料なしに把握できる人材の数」で会社を測るという視点を現代の組織に適用し、規模が拡大する企業でいかに個々の社員が見えにくくなるかを考察します。現代のマネジメント層がこの課題にどう向き合い、1on1が個と組織のエンゲージメント向上に果たすべき本質的な役割を論じます。 |
| **使用するネタ** | ドラッカーの会社の測り方に関する記事 |
| **接続する資料** | 1on1総研 調査レポート（各種） |
| **Why Now** | 組織が複雑化し、個と組織のエンゲージメントが課題となる現代において、古典的な経営理論から新たな示唆を得ることで、本質的なマネジメントのあり方を問い直す機運が高まっているため。 |
