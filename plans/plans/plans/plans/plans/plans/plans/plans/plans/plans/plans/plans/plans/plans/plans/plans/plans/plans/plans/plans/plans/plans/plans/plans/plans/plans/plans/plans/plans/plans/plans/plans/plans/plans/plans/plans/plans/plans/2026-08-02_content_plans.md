## A. ブランディングコンテンツ（第一想起獲得・専門性訴求）

### A-1. 「管理部門」からの脱却へ。戦略人事の構想力を高めるHRBP連携の要諦

| 項目 | 内容 |
|------|------|
| **想定読者** | 経営層、人事担当者（HRBP含む） |
| **切り口** | 人事部門が「管理・運用部門」と認識され、経営課題を人事課題に落とし込む構想力が不足している現状を分析。HRBPを設ける予定がない企業が多い中で、いかに戦略的な人事機能を構築し、経営に貢献できるか、そのためのマネジメント層との連携や1on1の活用を論じます。 |
| **使用するネタ** | 人事部門の「縦割り」意識調査 / 人事部門の兼務実態 / HRBP設置予定がない企業の割合 / 人事部門の構想力不足に関する課題認識 / 人事部門が他部門から「管理・運用部門」と認識されている実態 |
| **接続する資料** | 1on1総研 調査レポート |
| **Why Now** | 人的資本経営の要請が高まる中、人事部門が真に経営パートナーとなるための変革が急務だからです。 |

### A-2. 「孤独」が若手を蝕む？入社3年以内離職率を下げるオンボーディングと1on1の設計

| 項目 | 内容 |
|------|------|
| **想定読者** | 人事担当者、経営層、マネジャー |
| **切り口** | 大成建設の事例に見る「孤独」が若手離職の大きな要因であるという分析から、新入社員のオンボーディングと継続的な1on1がどのように若手の定着に貢献するかを考察。入社から定着までの「線」で捉える支援の重要性を説きます。 |
| **使用するネタ** | 大成建設の若手離職率と孤独解消への取り組み / 新入社員育成・定着課題に関する調査 / オンボーディングのプロセスに関する分析記事 / 新入社員が会社を去る理由に関する考察 |
| **接続する資料** | 1on1導入ガイドライン |
| **Why Now** | 労働人口減少と採用難が続く中、せっかく採用した若手社員の早期離職防止は企業の最重要課題の一つだからです。 |

### A-3. 「低体温化する職場」の処方箋：マネジャーが組織の活力を取り戻す1on1戦略

| 項目 | 内容 |
|------|------|
| **想定読者** | 経営層、人事担当者、マネジャー |
| **切り口** | 働き方改革で残業は減ったが職場の活力は低下しているという「職場の低体温化」の実態を深掘り。この現象の背景にある要因（マイクロマネジメント、成長錯覚など）を分析し、マネジャーが1on1を通じて部下との信頼関係を再構築し、組織のエンゲージメントと活力を向上させるための戦略を提言します。 |
| **使用するネタ** | 冷めた職場が再び熱を取り戻すための考察 / 働き方改革後の職場の活力低下に関する調査 / 職場の低体温化の実態 / マイクロマネジメントが部下の「成長錯覚」を広げるという指摘 |
| **接続する資料** | 信頼関係16段階シート |
| **Why Now** | 働き方改革が進む一方で、職場のエンゲージメント低下が顕在化しており、その解決策が強く求められているからです。 |

### A-4. キャリア自律は「社員の責任」か？企業が担うべき育成責任と1on1の役割

| 項目 | 内容 |
|------|------|
| **想定読者** | 経営層、人事担当者 |
| **切り口** | プロティアン・キャリアが広がる中で、キャリア自律が「企業が育成責任を個人に転嫁する」と捉えられかねない点に警鐘を鳴らします。企業が真に社員のキャリア自律を支援するために、どのような育成責任を果たすべきか、そしてその中で1on1がどのように機能するかを深掘りします。 |
| **使用するネタ** | プロティアン・キャリアと企業の育成責任に関する議論 / 新入社員の早期離職とキャリア自律の必要性 |
| **接続する資料** | 1on1総研 調査レポート |
| **Why Now** | キャリア自律の推進が企業の喫緊の課題となる一方で、その本質的な意味と企業の役割が見直されているからです。 |
