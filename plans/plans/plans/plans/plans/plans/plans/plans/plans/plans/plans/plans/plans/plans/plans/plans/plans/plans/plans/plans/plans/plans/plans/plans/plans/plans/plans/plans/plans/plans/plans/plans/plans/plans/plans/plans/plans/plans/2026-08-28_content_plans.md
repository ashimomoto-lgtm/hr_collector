## A. ブランディングコンテンツ（第一想起獲得・専門性訴求）

### A-1. 人的資本経営の要諦：ISO30201が示す「真に価値ある」人材マネジメントとは

| 項目 | 内容 |
|------|------|
| **想定読者** | 経営層、人事担当者（HRBP含む） |
| **切り口** | 人材マネジメントの国際規格ISO30201が正式発行されたことを受け、その背景にある「人的資本」をどのように経営に統合し、実効性のある人材戦略を構築すべきかを解説する。単なる開示要件の充足に留まらず、企業価値向上に繋がる人材マネジメントのあり方を示す。 |
| **使用するネタ** | 人材マネジメントの国際規格ISO30201の正式発行 |
| **接続する資料** | 1on1総研 調査レポート（各種） |
| **Why Now** | 人的資本経営の注目が高まる中、国際的な基準が示されたことで、より本質的な人材マネジメントへの転換が求められているため。 |

### A-2. 「サーベイ疲れ」は「無視疲れ」だった？従業員の声が組織変革につながらない根本原因

| 項目 | 内容 |
|------|------|
| **想定読者** | 人事担当者、マネジャー、経営層 |
| **切り口** | エンゲージメントサーベイが形骸化し「サーベイ疲れ」を引き起こしている現状を深掘りし、その本質が「回答した声が活かされないことへの不満」にあると指摘する。従業員の声を具体的なアクションにつなげ、組織変革を推進するためのマネジメントの役割を考察する。 |
| **使用するネタ** | 従業員サーベイ疲れの本質は無視疲れという調査 |
| **接続する資料** | 0から始める！1on1導入ガイドライン |
| **Why Now** | 従業員エンゲージメントサーベイが普及する一方で、その効果を実感できない企業が多い中、根本的な課題解決が求められているため。 |

### A-3. ジョブ型人事の「成否」を分けるのは制度ではない？運用フェーズでマネジャーが担う役割

| 項目 | 内容 |
|------|------|
| **想定読者** | 人事担当者、マネジャー、経営層 |
| **切り口** | ジョブ型人事制度導入企業の約2割が成果を実感していないという調査結果を踏まえ、制度設計だけでなく、現場での「運用」が成否を分ける鍵であることを指摘する。特にマネジャーが職務定義書をいかに活用し、メンバーのキャリア自律を支援するか、評価に対する納得感を高める対話の重要性を論じる。 |
| **使用するネタ** | ジョブ型人事制度の成果実感がない企業の割合と運用課題 |
| **接続する資料** | マネジャーのための1on1完全ガイド |
| **Why Now** | 多くの企業がジョブ型人事制度を導入・検討する中で、その実効性を高めるための具体的な運用ノウハウが求められているため。 |

### A-4. 「職場の低体温化」が企業を蝕む：働きがいを失った組織に活気を取り戻すマネジメント戦略

| 項目 | 内容 |
|------|------|
| **想定読者** | 経営層、人事担当者、マネジャー |
| **切り口** | 残業時間減少と引き換えに職場に広がる「低体温化」の現状を分析し、仕事へのやりがいや情熱が失われるメカニズムを解明する。単なる働き方改革に留まらない、組織の活力を再燃させるためのマネジャーの役割と、エンゲージメントを高めるための対話の重要性を提言する。 |
| **使用するネタ** | 働き方改革後の職場の低体温化に関する調査 |
| **接続する資料** | 1on1総研 調査レポート（各種） |
| **Why Now** | 働き方改革が進む一方で、職場の活力が低下しているという新たな課題が顕在化しており、その解決策が急務となっているため。 |

### A-5. AI時代におけるHRの再定義：組織変革をリードする「指揮者」としての役割とは

| 項目 | 内容 |
|------|------|
| **想定読者** | 経営層、人事担当者（HRBP含む） |
| **切り口** | AI技術の進化がHR部門の役割を大きく変革させつつある現状を踏まえ、「組織の管理者」から「組織変革の指揮者」へとシフトするHRの新たな役割を提言する。AIを人事業務に活用しつつ、人間ならではの強みである対話や関係構築を通じて組織を動かす重要性を論じる。 |
| **使用するネタ** | AI時代のHRの役割変革に関する提言 |
| **接続する資料** | KAKEAIサービス資料 |
| **Why Now** | AIの急速な進化により、人事業務のあり方やHRパーソンの役割そのものが問い直されており、未来を見据えた戦略的な視点が必要とされているため。 |
