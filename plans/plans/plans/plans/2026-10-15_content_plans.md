## A. ブランディングコンテンツ（第一想起獲得・専門性訴求）

### A-1. 「評価者研修なし」が5割の衝撃！1on1で「評価の納得感」を高めるマネジャーの役割とは

| 項目 | 内容 |
|------|------|
| **想定読者** | 人事担当者、マネジャー・管理職 |
| **切り口** | 多くの企業で評価者研修が不足している現状を指摘し、評価の納得感を高める上で1on1がいかに重要か、具体的な対話のポイントを解説します。 |
| **使用するネタ** | 管理職・マネジャー向け評価者研修の実施状況調査 |
| **接続する資料** | マネジャーのための1on1完全ガイド |
| **Why Now** | 評価に対する不満が組織エンゲージメントを低下させる中、マネジャーの評価スキル向上は喫緊の課題です。 |

| 項目 | 内容 |
|------|------|
| **想定読者** | 経営層、人事担当者、マネジャー・管理職 |
| **切り口** | 管理職が「損」と感じる現状の背景を分析し、KAKEAIが提唱する「心理的安全性に基づいた対話」が管理職の負担を軽減し、エンゲージメントを高める新しいリーダーシップ像を提示します。 |
| **使用するネタ** | 管理職という仕事に対する意識調査結果 |
| **接続する資料** | 1on1総研 調査レポート（各種） |
| **Why Now** | 管理職志向の低下は組織の将来を危うくするため、その原因を深掘りし、解決策を提示することが重要です。 |

### A-3. AI時代に「スキルを磨けば安泰」は幻想？転職無限ループから抜け出す「キャリアの地政学」と1on1の役割

| 項目 | 内容 |
|------|------|
| **想定読者** | 人事担当者、マネジャー・管理職、経営層 |

| **使用するネタ** | AI時代におけるキャリア戦略の考察 |
| **接続する資料** | メンバーのための1on1完全ガイド |
| **Why Now** | AIの進化が加速する中、個人のキャリア戦略と企業の育成戦略は再考が迫られています。 |

### A-4. 「答えない人」が示す組織のサインとは？従業員サーベイの無回答者から読み解く組織の課題と1on1の重要性

| **使用するネタ** | 従業員サーベイの無回答者に関する分析 |
