## A. ブランディングコンテンツ（第一想起獲得・専門性訴求）

### A-1. 「成長錯覚」を生むマイクロマネジメントの罠—部下の自律を阻む上司の無意識

| 項目 | 内容 |
|------|------|
| **想定読者** | 経営層、人事担当者、マネジャー |
| **切り口** | パーソル総合研究所の調査が指摘する「成長錯覚」は、上司のマイクロマネジメントが原因で部下が成長したと錯覚し、上司は育成不足と感じる現象。この認識のズレが組織に与える影響と、自律を促すマネジメントの重要性を深掘りします。 |
| **使用するネタ** | マイクロマネジメントで広がる部下の「成長錯覚」に関する調査 |
| **接続する資料** | 1on1総研 調査レポート（各種） |
| **Why Now** | 働き方や価値観の多様化が進む現代において、部下の自律的な成長を促すマネジメントの重要性が高まっているため。 |

### A-2. 静かな退職の裏側—エンゲージメント調査が「形骸化」する組織の課題と解決策

| 項目 | 内容 |

| **使用するネタ** | 静かな退職とエンゲージメントに関する調査 / なぜエンゲージメント施策は形骸化するのか「感情設計」 |
| **接続する資料** | 1on1総研 調査レポート（各種） |
| **Why Now** | 従業員エンゲージメントの向上と静かな退職への対策が、企業の持続的成長に不可欠な経営課題となっているため。 |
