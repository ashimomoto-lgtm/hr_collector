## A. ブランディングコンテンツ（第一想起獲得・専門性訴求）

### A-1. 管理職は「罰ゲーム」なのか？—8割がなりたくない現代マネジャーの処方箋

| 項目 | 内容 |
|------|------|
| **想定読者** | 経営層、人事担当者 |
| **切り口** | 一般社員の8割が管理職になりたくないと回答する現状を受け、現代の管理職が抱える課題（評価者研修不足、報連相できない部下、メンタル不調者対応など）を構造的に分析し、その「罰ゲーム化」を解消するための組織的なアプローチと、KAKEAIが提唱するマネジメント変革の必要性を訴求します。 |
| **使用するネタ** | 一般社員の約8割が管理職になりたくないと回答 / 管理職・マネジャー向け評価者研修の実施率が5割未満 / 指示待ちや報連相ができない部下に関するマネジャーの悩み / メンタル不調時、約6割の正社員が職場に相談できない実態 |
| **接続する資料** | 1on1総研 調査レポート（各種） |
| **Why Now** | 管理職離れが深刻化する中で、組織の中核を担うマネジャー層をどう再活性化するかが喫緊の課題となっています。 |

### A-2. 「働き方改革」のその先へ—真の競争優位性を生む「人への投資」とは

| 項目 | 内容 |
|------|------|
| **想定読者** | 経営層、人事担当者 |
| **切り口** | 働き方改革から10年が経ち、長時間労働は是正されたものの、新たな課題も浮上している現状を分析。日本企業が真の競争優位性を確立するために、形式的な時間短縮ではなく、社員のエンゲージメントや自律性を高める「人への投資」（特にマネジメント領域）をどう推進すべきか、KAKEAIの視点から提言します。 |
| **使用するネタ** | 働き方改革から10年が経過し、新たな課題が浮上 / 日本人の働き方に関する企業の競争優位性の問いかけ / 働きがいに悪影響を与える社内慣行として「ムダな会議」が指摘 / 人への投資が成長につながるJIMI企業の事例 |
| **接続する資料** | 1on1総研 調査レポート（各種） |
| **Why Now** | 働き方改革の成果と課題が顕在化し、次のステップとして人的資本経営への注目が高まる中で、本質的な「人への投資」のあり方を問う時期です。 |

### A-3. 戦略人事の壁を破る！事業と人事を連動させるCHROの「臨床知」

| 項目 | 内容 |
|------|------|
| **想定読者** | 経営層、人事担当者（特にHRBP） |
| **切り口** | 7割の人事部員が戦略人事に必要なスキルが不足しているという調査結果や、事業戦略と人事の連動スコアが低い現状を深掘り。ソフトバンクやMUFGのCHROの事例を参考に、科学知だけでは捉えきれない「現場で駆動する臨床知」の重要性を説き、経営に貢献する人事の役割と具体的な実践論をKAKEAIの視点から提示します。 |
| **使用するネタ** | 戦略人事に必要な能力・スキルが人事部員に不足しているという調査結果 / 事業戦略と人事の整合性を測る「事業戦略・人事連動スコア」の公表 / ソフトバンクCHROによるAI時代のモチベーション・組織開発の重要性に関する言及 / MUFG CHROによる論理的思考と「人の心に火をつける」ことの両輪の重要性の提唱 / 人材開発・組織開発における「臨床知」の書籍紹介 |
| **接続する資料** | 1on1総研 調査レポート（各種） |
| **Why Now** | 人的資本経営の要として戦略人事の実現が求められる中、その実践における具体的な課題と解決策への関心が高いからです。 |

### A-4. 「前例がない」がイノベーションを阻む？心理的安全性を高める組織文化の作り方

| 項目 | 内容 |
|------|------|
| **想定読者** | 経営層、人事担当者、マネジャー |
| **切り口** | 新しい企画や提案が「前例がない」という理由で却下される企業が3割に上る現状を問題提起。社員が臆することなくアイデアを出し、挑戦できる心理的安全性の高い組織文化をいかに醸成するか、具体的なマネジメントの介入点や1on1の活用法について考察します。オンデーズのユニークな人事制度も参考に、挑戦を促す文化のヒントを探ります。 |
| **使用するネタ** | 新しい企画や提案が「前例がない」理由で却下される企業が3割存在 / OWNDAYSの「エリアマネージャー解散総選挙」など、挑戦を促すユニークな人事制度の事例 |
| **接続する資料** | 上司・部下の信頼関係16段階シート |
| **Why Now** | VUCA時代において企業のイノベーション創出が不可欠であり、その土台となる心理的安全性の重要性が認識されているからです。 |

### A-5. 「学びたい」が「学ぶ」につながらない壁—自律的な学びを促すマネジメント戦略

| 項目 | 内容 |
|------|------|
| **想定読者** | 人事担当者、マネジャー |

| **使用するネタ** | 「学びたい」という意欲が「学ぶ」行動につながらない課題 / リスキリングや自律型人材育成における読書の再評価と学習効果の引き出し方 |
| **接続する資料** | メンバーのための1on1完全ガイド |
| **Why Now** | リスキリングやキャリア自律が叫ばれる中、個人の学習意欲を組織の成長につなげるマネジメントの役割が重要視されています。 |

### A-6. 【事例に学ぶ】「スキル型人事制度」で社員のエネルギーを引き出す1on1の設計図

|------|------|
| **想定読者** | 人事担当者、経営層 |
