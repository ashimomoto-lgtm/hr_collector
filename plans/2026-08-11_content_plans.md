## A. ブランディングコンテンツ（第一想起獲得・専門性訴求）

### A-1. AIが変えるマネジメントの本質：業務効率化を超え、メンバーとの「向き合い方」を再定義する

| 項目 | 内容 |
|------|------|
| **想定読者** | 経営層、人事担当者、マネジャー・管理職 |
| **切り口** | 生成AIの普及は、マネジャーの役割やメンバーとの関係性に変革を促しています。単なる業務効率化に留まらず、AI時代にマネジャーがメンバーの成長支援やエンゲージメント向上にどう向き合うべきか、その本質的な変化と可能性を考察します。 |
| **使用するネタ** | 生成AIがマネジメントにもたらす本質的変化 / AI時代におけるHRの役割再定義 / AI導入の成否と組織OSの関係 |
| **接続する資料** | 1on1総研 調査レポート（各種） |
| **Why Now** | 生成AIの普及により、マネジメントのあり方が根本的に問われているため。 |

### A-2. 「職場の低体温化」の深層：働き方改革で残業が減っても活力が失われる理由とマネジメントの処方箋

|------|------|

| **使用するネタ** | 働き方改革後の職場の活力低下 / 職場の低体温化の実態 / 冷めた職場を熱を取り戻す方法 |
| **接続する資料** | 1on1総研 調査レポート（各種） |
| **Why Now** | 残業削減だけでは解決しない、職場の本質的な課題が顕在化しているため。 |

### A-3. OJTの質を高める1on1の力：若手の「受け身傾向」を打破し、行動変容を促す指導とは

### A-4. HRは「組織変革の指揮者」へ：人的資本経営時代に求められる人事部門の戦略的役割

| **使用するネタ** | AI時代におけるHRの役割再定義 / 戦略人事が進まない理由とHRの構想力不足 / HRBP設置状況と人事部門の兼務実態 / 人的資本可視化指針の改訂 |
| **接続する資料** | KAKEAIサービス資料 |
| **Why Now** | 人的資本経営が本格化し、HR部門の役割と能力変革が急務となっているため。 |
