## A. ブランディングコンテンツ（第一想起獲得・専門性訴求）

### A-1. ジョブ型導入「効果実感できず」5割の衝撃—形骸化を防ぐマネジャーの役割とは？

| 項目 | 内容 |
|------|------|
| **想定読者** | 人事担当者、経営層、ジョブ型導入を検討・実施中のマネジャー |
| **切り口** | ジョブ型人事制度が期待通りの成果を出せない背景を、日経ビジネスの調査結果から深掘りします。特に、制度の「魂入れ」となるマネジャーの役割に焦点を当て、形骸化を防ぎ、真のキャリア自律を促すためのマネジメント変革の必要性を考察します。 |
| **使用するネタ** | ジョブ型導入、明確な効果を実感できない企業が多数 / ジョブ型人事制度導入で失敗する4つのパターン / ジョブ型移行における経営者の本質理解不足 |
| **接続する資料** | 1on1総研 調査レポート（各種） |
| **Why Now** | ジョブ型人事制度の導入が広がる一方で、その効果に疑問符が投げかけられており、実態と理想のギャップを埋めるための議論が急務だからです。 |

### A-2. AI時代に「人間らしさ」が企業の競争力になる—HRとマネジメントに求められる「翻訳」の力

| 項目 | 内容 |
|------|------|
| **想定読者** | 人事担当者、経営層、未来のマネジメントに関心のある読者 |
| **切り口** | AI技術の進化が加速する現代において、企業の競争力を左右するのはテクノロジーそのものではなく、人の感情や意志を組織の力に変える「Humanity（人間らしさ）」であると提言します。AIが進化するからこそ、HR部門が経営課題を人材課題に「翻訳」し、組織の変革を指揮する役割の重要性を考察します。 |
| **使用するネタ** | AI時代の人事戦略に求められる「翻訳」と「錨を上げる」能力 / AI時代のHRの役割が「組織の管理者」から「組織変革の指揮者」へ |
| **接続する資料** | 1on1総研 調査レポート（各種） |
| **Why Now** | AIの活用が広がる一方で、人間ならではの価値や役割が再認識されており、人事・マネジメントのあり方が問われているからです。 |

### A-3. 残業減でも「職場の低体温化」が進行？1on1が組織の活力を取り戻す鍵

| 項目 | 内容 |
|------|------|
| **想定読者** | 経営層、人事担当者、組織の活性化に課題を感じるマネジャー |
| **切り口** | 働き方改革で残業時間が減少した一方で、仕事へのやりがいや情熱が薄れる「職場の低体温化」が進行している実態を深掘りします。この静かな冷え込みに対し、個々の社員のエンゲージメントを高め、自律的な成長を促す1on1がどのように組織の活力を取り戻せるのかを考察します。 |
| **使用するネタ** | 働き方改革で残業が減ったのに職場の活力が低下する「低体温化」の実態 / 冷めた職場が熱を取り戻すための働き方改革の考察 |
| **接続する資料** | 1on1総研 調査レポート（各種） |
| **Why Now** | 働き方改革が進む中で、単なる労働時間削減だけでなく、社員のモチベーションや組織の活力をいかに維持・向上させるかが新たな課題となっているからです。 |

## B. リード化コンテンツ（資料DLにつなげる）

### B-1. ジョブ型で「キャリア自律」を促す！マネジャーのための1on1実践ガイド

| 項目 | 内容 |
|------|------|
| **想定読者** | マネジャー・管理職、キャリア自律支援に課題を感じる人事担当者 |
| **切り口** | ジョブ型人事制度下で、メンバーが自律的にキャリアを形成できるよう、マネジャーが1on1でどのように支援すべきかを解説します。職務定義書と個人の成長意欲を繋げ、具体的な目標設定やフィードバックを通じて、メンバーの納得感を高める対話術を提供します。 |
| **使用するネタ** | 富士通がキャリア自律を促すために600ポストを公募 / ジョブ型導入企業に共通する職務定義書の活用課題 / キャリア自律度と組織の成長支援環境に関する調査 |
| **接続する資料** | マネジャーのための1on1完全ガイド |
| **Why Now** | ジョブ型導入企業が増える中で、制度だけではなく、現場のマネジャーが個人のキャリア自律をどう支援するかが喫緊の課題となっているからです。 |

### B-2. キャリア入社者の早期離職を防ぐ！信頼関係を築く1on1オンボーディング実践チェックリスト

| 項目 | 内容 |
|------|------|
| **想定読者** | キャリア採用を強化する人事担当者、中途入社者の受け入れマネジャー |
| **切り口** | キャリア入社者が組織にスムーズに定着し、早期に活躍するためのオンボーディングにおける1on1の重要性を解説します。入社直後の信頼関係構築から、期待値調整、文化への適応支援まで、マネジャーが実践すべき具体的な対話のステップとチェックリストを提示します。 |
| **使用するネタ** | キャリア入社者のオンボーディングが経営課題化 / オンボーディング研修から組織課題解決型への転換事例 |
| **接続する資料** | 上司・部下の信頼関係16段階シート |
| **Why Now** | 大手企業を中心にキャリア採用が加速する中で、オンボーディングの失敗による早期離職が経営課題として顕在化しているからです。 |

### B-3. 管理職の6割が陥る「育成キャンセル」を乗り越える！部下の主体性を引き出す1on1質問集

| 項目 | 内容 |
|------|------|
| **想定読者** | マネジャー・管理職、管理職育成に課題を感じる人事担当者 |
| **切り口** | 若手社員が「率直な指導」を希望しているにも関わらず、ハラスメントを恐れて管理職が育成を避ける「育成キャンセル」問題に焦点を当てます。部下の主体性を尊重しつつ、成長を促すための具体的な1on1質問例と、指導とハラスメントの境界線を見極めるヒントを提供します。 |
| **使用するネタ** | 管理職の6割が育成キャンセルに陥る実態 / 若手社員の約8割が率直な指導を希望 / 若手社員に求める能力として「主体性」が最多 |
| **接続する資料** | マネジャー向け1on1質問集 |
| **Why Now** | ハラスメントリスクへの意識の高まりから、管理職が部下への指導に及び腰になる傾向があり、育成停滞が組織課題となっているからです。 |
