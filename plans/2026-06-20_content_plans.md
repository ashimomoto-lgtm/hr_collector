## A. ブランディングコンテンツ（第一想起獲得・専門性訴求）

### A-1. 若手の「仕事の意義」と「天職」：1on1がキャリア自律を促す鍵

| 項目 | 内容 |
|------|------|
| **想定読者** | 人事担当者、マネジャー・管理職 |
| **切り口** | 若手社員が仕事に求める「好き・興味」や「生活の安定」といった価値観が多様化しています。これらの価値観を理解し、個々の「天職」意識と企業の成長をどう結びつけるか、1on1を通じたキャリア自律支援の重要性を深掘りします。 |
| **使用するネタ** | 天職のとらえ方に関する調査 / 新入社員の働く価値観調査で成長意欲が減少傾向 |
| **接続する資料** | 1on1総研 調査レポート（各種） |
| **Why Now** | 若手社員のキャリア観が多様化し、企業がその価値観を理解し支援する必要性が高まっているためです。 |

### A-2. 「低体温化する職場」を救う1on1：働き方改革の副作用とマネジメントの役割

| 項目 | 内容 |
|------|------|
| **想定読者** | 人事担当者、経営層、マネジャー・管理職 |
| **切り口** | 働き方改革による残業減少の裏で、「仕事の過密化」や「職場の低体温化（没入・挑戦の低下）」が進み、仕事への意義を見失う社員が増えています。エンゲージメント低下を防ぎ、社員の「没入・挑戦」を促すための1on1の役割を考察します。 |
| **使用するネタ** | 働き方改革による就業と意識の変化に関する定量調査 / 職場の低体温化と仕事の意義に関する調査 |
| **接続する資料** | 1on1総研 調査レポート（各種） |
| **Why Now** | 働き方改革が進む一方で、職場のエンゲージメント低下や仕事への意義喪失が課題となっているためです。 |

### A-3. AI時代の人材戦略：人的資本経営と「人間らしい対話」の再評価

| 項目 | 内容 |
|------|------|
| **想定読者** | 経営層、人事担当者 |
| **切り口** | AI技術の急速な発展により、採用から業務までAI活用が進む中で、学生や社員は「没個性化」への不安を抱きつつも「AI面接」には前向きな側面も見られます。人的資本経営においてAIが代替できない「人間らしい対話」、特に1on1を通じたキャリア開発や共感の重要性を再評価します。 |
| **使用するネタ** | 人的資本経営調査レポート / 学生のAI面接に関する意識調査 / AI活用とキャリア意識に関する調査 |
| **接続する資料** | 0から始める！1on1導入ガイドライン |
| **Why Now** | AI技術の急速な発展により、企業は人的資本経営において「人の力」をどう引き出すか、その本質的な問いに直面しているためです。 |
