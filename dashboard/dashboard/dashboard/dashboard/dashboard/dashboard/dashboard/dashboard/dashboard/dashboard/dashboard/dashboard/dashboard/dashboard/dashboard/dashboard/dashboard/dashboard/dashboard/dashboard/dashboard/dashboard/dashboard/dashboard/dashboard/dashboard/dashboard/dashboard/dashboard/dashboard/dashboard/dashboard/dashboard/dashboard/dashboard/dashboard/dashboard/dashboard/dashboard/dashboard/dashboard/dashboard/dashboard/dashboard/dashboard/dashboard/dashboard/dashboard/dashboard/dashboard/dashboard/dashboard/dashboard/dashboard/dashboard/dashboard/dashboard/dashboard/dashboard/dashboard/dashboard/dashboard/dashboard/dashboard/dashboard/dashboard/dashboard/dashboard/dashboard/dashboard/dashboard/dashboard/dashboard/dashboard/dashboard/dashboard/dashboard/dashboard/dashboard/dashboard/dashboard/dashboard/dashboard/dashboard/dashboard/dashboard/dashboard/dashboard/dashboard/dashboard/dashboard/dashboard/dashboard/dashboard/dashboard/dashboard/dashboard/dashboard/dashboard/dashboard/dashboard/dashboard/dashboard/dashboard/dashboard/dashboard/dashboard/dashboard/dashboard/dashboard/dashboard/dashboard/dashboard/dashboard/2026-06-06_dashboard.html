1on1・マネジメント領域

1on1の運用における課題解決や効果的な対話手法への関心が高まっています。「パーソル総合研究所」のコラムでは、1on1が機能しない「壁」や、部下の考える力を育てる対話の再設計が議論されています。また、多様性時代におけるリーダーシップのあり方として、「AUBEモデル調査」に基づくリーダー行動の考察や、フォロワーシップの醸成が重要視されています。「ダイヤモンド・オンライン」の記事群では、上司のコミュニケーション能力や部下の本音を引き出す共感術が注目されており、指示待ち部下を自ら動くチームに変えるマネジメント転換術も提示されています。さらに、「三菱UFJリサーチ&コンサルティング」の調査では、経営理念浸透が組織風土改革に繋がるとされており、組織全体のコミュニケーションとエンゲージメント向上が焦点となっています。

人事制度・採用・育成

人事制度・採用・育成領域では、多様な働き方やキャリア自律を支援する動きが活発です。「カルビー」が約17年ぶりに人事制度を刷新したように、企業は従業員のエンゲージメントと生産性向上を目指し、制度の見直しを進めています。「日本の人事部」の調査では、新入社員の初任給や夏季賞与の水準、メンタル不調の実態、女性のヘルスケア意識など、従業員のウェルビーイングに関する関心が高まっています。採用においては「overflow」がハイクラスエンジニア採用の予算最適化プランを提供し、「みん就調べ」による新卒就職人気企業ランキングも発表されるなど、採用市場の動向が注目されています。また、「パーソル総合研究所」のコラムでは、管理職によるキャリア開発支援の重要性や、NTTドコモのキャリア開発施策が紹介されており、キャリア自律を促す育成が重視されています。

HRテック・AI活用

HRテック・AI活用領域では、生成AIの業務適用とそれに伴う組織変革が急速に進んでいます。「HRzine」の記事では、目標設定や評価における生成AIの活用事例が紹介され、「PeopleX」は相性や一過性の成果によらない人材評価を支援するAI製品を発表しています。採用活動においても「ミイダス AIバディー」が採用専門家7職種の業務をAIで一気通貫化し、「Wantedly Hire」はハイパフォーマーをもとにAIが選考基準を提案するなど、AIによる効率化と高度化が進展しています。「メルカリ」ではCTOがCHRO兼CAIOに就任し、AIネイティブ企業への組織変革を推進する動きも見られます。一方で、「パーソル総合研究所」の調査では、生成AIが職場に広がらない要因や、利用率では測れない活用の実態が指摘されており、AI導入における課題解決も重要なテーマとなっています。
