2 HR界隈トレンド分析

1on1・マネジメント領域

1on1の重要性が改めて注目される一方で、その運用における課題や機能不全が指摘されており、パーソル総合研究所のコラム「なぜ1on1は機能しないのか？」や「1on1という『旅』の途中で上司がぶつかる３つの『壁』」がその実態を分析しています。効果的な対話やフィードバックのあり方、部下のキャリア自律を促す管理職の役割が模索されており、パーソル総合研究所の「フォロワーシップをいかに醸成するか」や「キャリア開発風土醸成へ―管理職の役割と求められる教育」がその方向性を示しています。また、ヒューマンの調査では「コミュニケーション研修」が強化したい研修のトップに挙げられ、多様なリーダーシップ行動や建設的なコンフリクトを通じた組織風土改革の必要性が強調されています。ダイヤモンド・オンラインの記事「何を考えているかわからない部下」に効果的な声かけとは、など、具体的なマネジメントスキル向上への関心も高いです。三菱UFJリサーチ&コンサルティングの調査では「経営理念浸透」が「組織風土」改革につながると示されており、組織全体のエンゲージメント向上に向けた取り組みが活発です。

人事制度・採用・育成

人事制度においては、カルビーが約17年ぶりに人事制度を抜本的に刷新するなど、企業が環境変化に対応するための見直しを積極的に行っています。採用領域では、マブチモーターが「MyRefer」を導入しリファラル採用を強化するほか、インフィニティエージェントが「Infinity-Recruiting」で採用マーケティング支援を提供するなど、多様な手法で優秀な人材獲得を目指しています。育成面では、ヒューマンの調査で「コミュニケーション研修」が強化したい研修のトップに挙げられ、NTTドコモがキャリア開発施策を実践するなど、従業員の自律的な成長支援が重視されています。また、学情の調査では20代キャリア採用における「応募～内定が3週間以内」が約5割を占め、スピード感のある採用活動が求められていることが示されています。大東建託が全社員9000名を対象としたグループ会社への転籍制度を導入するなど、人材の流動性を高め、多様なキャリアパスを提供する動きも見られます。

HRテック・AI活用

HRテック領域では、AIの活用が急速に進展しており、KPMGジャパンが「対人対話ナビゲーションエージェント」を提供し対話の質を高めるなど、多岐にわたるソリューションが登場しています。採用においては、パーソルキャリアがAIプロダクトで求人票作成を効率化し、MIXIもAIを面接に組み込むことで候補者体験と採用の質向上を図っています。jinjerの「HR Signals」や東芝の「Generalist/HR/PR」における人財検索AI機能のように、組織や社員のデータをAIで分析し、人事異動の意思決定や退職アラートなどマネジメント業務の高速化・高度化に貢献しています。丸紅が「しくじりデータベース」を公開しAI活用で教訓化する事例や、トラスコ中山がAI活用で人事異動の意思決定プロセスを約98％削減した事例も報告されています。一方で、パーソル総合研究所のコラム「生成AIはなぜ職場に広がらないのか」が示すように、AIの職場への普及には課題も存在し、GMO天秤AIがAIリスキリング研修を提供するなど、人材育成を通じた活用促進も進められています。
