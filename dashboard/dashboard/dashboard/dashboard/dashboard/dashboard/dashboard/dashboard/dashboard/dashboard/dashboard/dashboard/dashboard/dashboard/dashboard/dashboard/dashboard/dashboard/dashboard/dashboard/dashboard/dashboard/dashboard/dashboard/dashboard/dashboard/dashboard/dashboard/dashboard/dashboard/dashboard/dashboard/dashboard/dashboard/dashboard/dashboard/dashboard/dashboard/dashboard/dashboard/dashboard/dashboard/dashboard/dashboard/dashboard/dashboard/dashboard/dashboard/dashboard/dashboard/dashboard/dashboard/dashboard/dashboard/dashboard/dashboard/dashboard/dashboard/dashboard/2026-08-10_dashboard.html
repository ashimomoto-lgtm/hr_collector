1on1・マネジメント領域

1on1は、上司が直面する「壁」があるにもかかわらず、部下の主体性を引き出し、成長を促す上でその重要性が再認識されています（パーソル総合研究所「なぜ私たちは、それでも1on1をあきらめないのか？②」「なぜ私たちは、それでも1on1をあきらめないのか？③」）。多様な働き方や価値観に対応するため、管理職にはマイクロマネジメントを避け、部下のフォロワーシップを醸成するマネジメントへの転換が求められています（パーソル総合研究所「その成長実感は本物か―マイクロマネジメントで広がる、部下の「成長錯覚」」「フォロワーシップをいかに醸成するか」）。また、組織の「縦割り」意識や「使えない社畜」を生む上司の特徴が課題として指摘されており（日本の人事部、ダイヤモンド・オンライン『リーダーの仮面』）、自社のマネジメント課題を診断するサービス「マネジメントカルテ」なども登場しています。

人事制度・採用・育成

人事制度・採用・育成領域では、従業員の「キャリア自律」支援が喫緊の課題とされており、管理職によるキャリア面談の重要性が強調されています（パーソル総合研究所「キャリア開発風土醸成へ」）。若手社員、特にZ世代エンジニアに対するOJT指導の難易度が指摘される一方で、研修の「行動変容」を促す取り組みや「経験学習」の加速が模索されています（日本の人事部、HRzine）。また、女性のキャリア支援（エスエス製薬と森永製菓のクロスメンタリング）や障がいのある社員の活躍推進（SHIROの「全社業務推進グループ」）、仕事と介護の両立支援（日立製作所）など、多様な人材が活躍できる環境整備が進んでいます。企業は人的資本可視化指針の改訂を受け、経営戦略と連動した人材戦略の実行力を高めることに注力しています（パーソル総合研究所）。

HRテック・AI活用

HRテック領域では、AI、特に生成AIの活用が急速に進んでおり、「AI面接」は採用の質を高める可能性を秘めています（日本の人事部）。レゾナックが生成AIを活用した管理職向けエンゲージメント改善支援アプリを自社開発するなど、マネジメント業務への応用も活発です。しかし、人事部門での生成AI活用には「情報漏洩・プライバシー保護への不安」が最大の課題として挙げられており（日本の人事部）、普及の障壁となっています。一方で、SmartHRやWHIの「COMPANY」、HRBrainといった統合人事システムや、パーソルビジネスプロセスデザインの採用レポート高速化サービス「レポラビ」の導入が進み、人事労務業務の効率化とデータ活用基盤の強化が図られています。
