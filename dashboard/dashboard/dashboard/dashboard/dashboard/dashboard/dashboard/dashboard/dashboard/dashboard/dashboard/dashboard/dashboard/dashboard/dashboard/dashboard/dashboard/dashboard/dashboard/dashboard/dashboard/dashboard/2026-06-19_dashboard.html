2 HR界隈トレンド分析

1on1・マネジメント領域

マネジメント領域では、上司と部下の対話、特に「1on1」の質向上が重要なテーマとなっています。パーソル総合研究所のコラムでは、「1on1という『旅』の途中で上司がぶつかる３つの『壁』」や「なぜ1on1は機能しないのか？」といった課題が指摘されつつも、その重要性が再確認されています。また、管理職だけに責任を負わせず、部下の「フォロワーシップ」を醸成することで、組織全体の主体性を高める動きが注目されており、パーソル総合研究所は「もう管理職だけに背負わせない、部下のフォロワーシップの時代へ」と提言しています。リーダーシップにおいては、日経ビジネスの「イエスマンは不要」と語る東京海上・城田社長のように、多様な意見を尊重し、社員との対話を重視する姿勢が求められています。さらに、キャリア開発における管理職の役割や、ハラスメント対策など、多角的な視点でのマネジメント能力強化が図られています。

人事制度・採用・育成

人事制度・採用・育成領域では、労働市場の変化に対応するための多様な取り組みが見られます。人手不足とAI時代を見据え、三菱UFJリサーチ&コンサルティングは「リスキリング・リカレント教育の意義」を強調しており、イトーキ湊社長は「社員研修は選択制。自由度与え、自ら考えさせる」ことで自律的な学習を促しています。採用においては、HRzineが「採用広報」のKPI設定と効果測定の重要性を説くとともに、26卒新入社員の意識調査やインターンシップのあり方に関する調査も活発です。また、法定雇用率の引き上げに向けた障がい者雇用や、男性向け育休研修が家庭の役割分担に与える影響など、多様性推進とウェルビーイングへの配慮も進んでいます。福利厚生についても、ベネフィット・ワンの調査から「支出削減目的の利用が浮き彫りに」なるなど、従業員のニーズに合わせた見直しが求められています。

HRテック・AI活用

HRテック・AI活用の領域では、AIが人事の様々な業務に導入され、効率化と高度化を推進しています。リクレングスは「AIが内定辞退の予兆を検知したり内定辞退を防ぐ制度改善案を提案したりする機能」をリリースし、採用活動を支援しています。カオナビは「AI職務要件アシスト」機能を追加し、職務要件の生成を効率化しており、ウォンテッドリーの福利厚生サービスPerkでは「AIが提案する機能」で従業員の関心に応じた特典を提供しています。一方で、学情の調査によると「キャリア採用に生成AIを利用している企業は約3割」に留まり、「面接」では人間の対応を重視する傾向が明らかになるなど、AIと人の協働のあり方が模索されています。ＪＸ金属とハウス食品は「データドリブンな人的資本経営」を実践し、「AI時代に『人の力』をどう活かすか」が問われています。
