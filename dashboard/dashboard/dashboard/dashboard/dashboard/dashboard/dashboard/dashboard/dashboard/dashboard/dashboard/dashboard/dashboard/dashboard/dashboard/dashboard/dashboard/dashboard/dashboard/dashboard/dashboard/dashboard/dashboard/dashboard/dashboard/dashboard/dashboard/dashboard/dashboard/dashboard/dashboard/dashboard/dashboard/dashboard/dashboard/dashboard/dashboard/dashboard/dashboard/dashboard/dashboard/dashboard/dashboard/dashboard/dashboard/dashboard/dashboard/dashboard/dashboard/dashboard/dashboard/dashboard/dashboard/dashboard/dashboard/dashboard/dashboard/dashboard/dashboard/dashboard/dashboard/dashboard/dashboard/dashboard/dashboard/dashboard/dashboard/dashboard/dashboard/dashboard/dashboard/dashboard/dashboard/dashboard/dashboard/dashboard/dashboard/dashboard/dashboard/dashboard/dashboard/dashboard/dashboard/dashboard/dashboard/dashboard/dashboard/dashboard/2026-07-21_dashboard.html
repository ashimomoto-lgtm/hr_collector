1on1・マネジメント領域

1on1は依然として重要なマネジメント手法であるものの、パーソル総合研究所のコラム「なぜ私たちは、それでも1on1をあきらめないのか？」シリーズが示すように、機能不全や上司が直面する「壁」が課題として認識されており、部下の考える力を育てる対話の再設計が求められています。多様な働き方や価値観に対応するため、マネジャーの役割が変化しており、パーソル総合研究所の「令和の時代に求められるマネジャーの役割とは？」では、管理職支援の必要性が強調されています。HRzineの「若手の成長機会を奪い、職場規律を崩壊させる管理職の『ハラスメント萎縮』の解決策」やパーソル総合研究所の「パワハラと指導の違いとは？」が示すように、ハラスメント問題への意識が高まり、適切なマネジメント行動が追求されています。組織の多様性を活かすためのリーダー行動として、パーソル総合研究所は「AUBEモデル」を提唱し、フォロワーシップの醸成を通じて部下の主体性を引き出すマネジメント転換術が注目されています。アステラス製薬では管理職層の削減も進められており、効率的な組織運営とマネジメントの質の向上が両立する道が模索されています。

人事制度・採用・育成

人事制度・採用・育成領域では、人事部門の業務効率化と戦略的な人材活用が喫緊の課題となっています。日本の人事部の調査によると、「人事部門で最も時間と手間がかかっているのは『採用業務』で6割超」とされ、採用活動の負担軽減が求められています。新卒採用においては、日経ビジネスの「疲弊する新卒採用の現場 『生成AIの書いた作文』を読まされる担当者」が示すように、AIの普及が新たな課題を生み出しています。一方で、ミサワホームが「HRBrain」の360度評価を導入するなど、人事評価制度の改革を通じて組織の透明性と公平性を高める動きも見られます。キャリア開発においては、パーソル総合研究所の「キャリア開発風土醸成へ―管理職の役割と求められる教育」シリーズが管理職による支援の重要性を説き、NTTドコモのような企業が「自分らしさ」と「会社の成長」を両立させる施策を実践しています。

HRテック・AI活用

HRテックとAI活用は、人事領域に大きな変革をもたらしています。AGCの平井社長が「AI活用で文系でも科学的発明ができるようになる」と語るように、AIは業務の可能性を広げる一方で、東洋経済オンラインの「『AIに提案書』を丸投げする若手営業の危うい末路」が指摘するように、その安易な活用にはリスクも伴います。パーソル総合研究所の調査では「生成AIはなぜ職場に広がらないのか」という問いに対し、現場での活用にはまだ課題があることが示唆されています。しかし、jinjerが「国内HRテックNo.1」を目指し新AIプロダクト戦略を発表したり、NTT東日本グループがリーディングマークの「ミキワメAI」を導入して組織開発に活用するなど、HRテック企業はAIを活用したソリューション開発を加速させています。タレントマネジメントシステムへのAI導入や、プルークスによる「Z世代の採用・AIO対策に特化した『採用ショート動画制作プラン』」提供など、採用から育成、組織開発まで幅広い分野でAIの活用が進んでいます。
