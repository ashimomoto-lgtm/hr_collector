1on1・マネジメント領域

1on1・マネジメント領域では、部下の主体性を引き出し、自律的なチームを育成するマネジメントへの転換が求められています。パーソル総合研究所のコラム「なぜ私たちは、それでも1on1をあきらめないのか？」が示すように、1on1の継続的な実施とその中での課題解決が重要視されています。また、ニッセイ基礎研究所の調査では、上司のサポートがワークエンゲージメントに大きく影響することが明らかになり、管理職のスキル不足が働きがい向上の障壁とされています。三菱電機が「自走型リーダー創出プログラム」を導入するなど、管理職によるキャリア開発支援やフィードバック文化の醸成が、多様な働き方に対応するマネジメントの鍵となっています。

人事制度・採用・育成

人事制度・採用・育成領域では、「ジョブ型雇用」の導入効果が5割の企業で実感できていない（日経ビジネス）など、その運用に課題が見られます。一方で、富士通や日立製作所、ソニーグループ、KDDI、ビズリーチは、キャリア自律支援やシニア活性化、キャリア開発ツールの提供で対応を進めています。採用においては、28卒の内々定出しが「3年生の12月」に突出する早期化（学情調べ）や、SNSを活用した採用支援（日本の人事部「SNS採用ブースト」）が加速しています。また、エスエス製薬による女性のクロスメンタリングやSHIRO、manaby altとSEALsによる障がい者雇用支援など、多様な人材の活躍を促す取り組みや、キャリア入社者のオンボーディング強化（HRzine）が経営課題として認識されています。

HRテック・AI活用

HRテック・AI活用の動向では、採用プロセスにおけるAIの導入が本格化しており、品川区役所が「エンPeopleX AI面接」を導入した事例があります。研修分野ではAI活用伴走サービス『アイカタ』、営業支援では日産が「amptalk coach」を導入するなど、具体的な業務支援ツールとしてのAI普及が進んでいます。しかし、アクセンチュアの調査では、日本企業のAI投資成果と従業員実感はグローバル平均を下回っており、AI導入効果の最大化が課題です。これに対し、パーソル総研が組織のAX（AIトランスフォーメーション）状況診断サービスを提供するなど、AI活用を推進しつつ、人材データによる適材適所（チームスピリット「TeamSpirit プロジェクトマネジメント」）やメンタルヘルス支援（コロプラ「マイシェルパ」）といったHR領域でのデータドリブンな意思決定と従業員ウェルビーイングへのテクノロジー活用が加速しています。
