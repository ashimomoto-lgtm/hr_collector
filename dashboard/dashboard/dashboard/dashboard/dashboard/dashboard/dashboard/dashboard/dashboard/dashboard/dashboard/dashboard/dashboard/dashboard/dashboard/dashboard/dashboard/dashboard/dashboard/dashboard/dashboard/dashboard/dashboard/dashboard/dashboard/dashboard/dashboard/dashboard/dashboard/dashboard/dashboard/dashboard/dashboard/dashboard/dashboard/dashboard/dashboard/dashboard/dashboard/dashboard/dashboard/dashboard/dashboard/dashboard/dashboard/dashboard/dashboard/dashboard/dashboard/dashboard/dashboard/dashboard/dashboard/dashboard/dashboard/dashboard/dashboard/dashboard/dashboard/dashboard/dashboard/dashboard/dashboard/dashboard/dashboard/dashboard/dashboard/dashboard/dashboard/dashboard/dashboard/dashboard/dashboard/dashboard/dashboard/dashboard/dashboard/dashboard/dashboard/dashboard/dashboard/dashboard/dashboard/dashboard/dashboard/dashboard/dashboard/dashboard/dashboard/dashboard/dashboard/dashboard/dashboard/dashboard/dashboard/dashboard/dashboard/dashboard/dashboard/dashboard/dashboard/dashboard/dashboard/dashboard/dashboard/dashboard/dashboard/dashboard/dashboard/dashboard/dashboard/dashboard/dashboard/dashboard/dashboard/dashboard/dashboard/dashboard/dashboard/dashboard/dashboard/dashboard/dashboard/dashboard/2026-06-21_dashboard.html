2 HR界隈トレンド分析

1on1・マネジメント領域

1on1の実施とその効果的な運用が引き続き重要なテーマであり、パーソル総合研究所のコラムでは「なぜ1on1は機能しないのか？」や「1on1という『旅』の途中で上司がぶつかる３つの『壁』」といった課題提起とともに、部下の考える力を育てる対話の再設計が求められています。マネジメントにおいては、上司が一方的に背負うのではなく、部下の「フォロワーシップ」を醸成し、主体性を引き出す重要性が強調されており（パーソル総合研究所「もう管理職だけに背負わせない、部下のフォロワーシップの時代へ」）、多様性を活かすためのリーダー行動のアップデートや建設的なコンフリクトの育成も焦点です。また、20代正社員の「上司の遠慮に関する意識調査」や「仕事における失敗経験」に関する調査も行われ、若手社員の意識を理解したマネジメントの必要性が示唆されています。

人事制度・採用・育成

リスキリング・リカレント教育の重要性が人手不足とAI時代において高まっており（三菱UFJリサーチ&コンサルティング）、企業が提供する学習の定着と業務活用に関する実態調査も行われています。採用においては、2026年度の新入社員初任給調査や26卒新入社員の意識調査、転職活動における「SNS・口コミの影響」調査が実施され、採用広報のKPI設定と効果測定の重要性も指摘されています。育成面では、イトーキの「社員研修は選択制」のように従業員の自律性を促す施策や、パナソニックグループが導入した「社内版ビズリーチ by HRMOS」による新制度「eマッチング」など、キャリア開発支援の取り組みが活発です。また、男性向け育休研修の影響や法定雇用率引き上げに向けた障がい者雇用実態調査、福利厚生の意識調査など、多様な働き方や従業員のウェルビーイングを支援する人事制度への関心も高まっています。

HRテック・AI活用

HRテックおよびAI活用は、人事領域の効率化と高度化を牽引しています。日テレHR総合研究所は「AIエージェントリース」を提供し、リクレングスはAIが内定辞退の予兆を検知する機能をリリースするなど、採用・育成におけるAIの活用が具体化しています。リコージャパンが「AIネイティブ研修」を導入し、ユームテクノロジージャパンが「組織のAI変革をリードする実践力を養うプログラム」を公開するなど、AI時代に対応した人材育成も進められています。SmartHRの調査では「人事施策の効果と経営成果の関係性を可視化できている企業は約9割」と報告されており、データドリブンな人的資本経営への関心が高いことが伺えます。一方で、パーソル総合研究所の調査「生成AIはなぜ職場に広がらないのか」が示すように、AIの職場への普及にはまだ課題も存在し、その利用実態に関する調査も行われています。
