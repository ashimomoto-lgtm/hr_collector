1on1・マネジメント領域

マネジメント領域では、多様な働き方や価値観に対応する管理職の役割が重要視されています。特に、AI時代における若手社員とのコミュニケーションや、パワハラを恐れる管理職の意識改革が課題として「AI時代に｢意図の見えない若手社員｣が増える背景」などで指摘されています。1on1やキャリア面談を通じて部下の自律的な成長を促す「キャリア開発風土醸成」が求められる一方、「マイクロマネジメントで広がる、部下の「成長錯覚」」といった負の側面も警鐘が鳴らされています。また、「逸脱させるマネジメント」や「抱え込む上司はいらない」といった書籍紹介から、権限委譲や個人の「はみ出し」を育てる新しいマネジメント手法への関心が高まっていることが伺えます。組織の心理的安全性向上や「良い衝突」を促す実践型eラーニングも登場し、変化への対応力や後進育成力がシニア社員に求められるなど、組織全体のマネジメント力向上が図られています。

人事制度・採用・育成

人事制度・採用・育成領域では、多様な人材の確保と定着、そしてキャリア形成支援が主要な動向です。新卒採用では「コミュニケーション能力」が重視され、ミスミのように「若手ポテンシャル採用コース」を一本化し入社時期を柔軟にする動きが見られます。また、大林組が「Cradle」を導入して多様な勤務形態に対応するウェルビーイング支援を行うなど、従業員の働きがいや定着を促す制度設計が進んでいます。育休復帰後の女性のキャリア意識変化や、ニッセイ基礎研究所の調査で「シニアの就業率」の上昇に陰りが見え始めるなど、多様な従業員のライフステージに合わせた制度設計の重要性が増しています。初任給の引き上げや、部門をまたがる異動配置における人事主導の低さも課題として挙げられており、戦略的な人材配置と育成が求められています。

HRテック・AI活用

HRテック・AI活用領域では、採用からタレントマネジメント、労務管理に至るまで、AIの導入が急速に進んでいます。ヒューマネージの「AI面接インテリジェンス」やPreferred Networksの「タレスカAI面接」のように、採用選考におけるAI活用が一般化しつつあります。また、kickflowによる「AIタレントマネジメントシステム「Talentify」」やLayerXの「AI人事労務サービス「バクラク人事労務」」など、人事・労務業務の効率化・高度化を図るサービスが相次いでリリースされています。NECが「無人部署」でAIエージェントを導入した事例に見られるように、AIによる業務自動化の進展は著しいものの、KiteRa調べでは「AIエージェント活用に対する社内ルール・ガバナンスの整備遅れ」が経営課題として認識されており、適切な活用に向けたガバナンス構築が今後の焦点となります。「AIを使うほど、賢くなくなる」という"認知負債"のリスクも指摘されており、AIと人間の協働におけるバランスが重要視されています。
