1on1・マネジメント領域

現代のマネジメントは、従業員のキャリア自律支援と主体性向上に重点を置いています。パーソル総合研究所のコラム「キャリア開発風土醸成へ」が示すように、管理職にはキャリア面談を通じた部下の成長支援が求められ、マイクロマネジメントは「成長錯覚」を引き起こすリスクがあると指摘されています（「その成長実感は本物か―マイクロマネジメントで広がる、部下の「成長錯覚」」）。多様な働き方や価値観に対応するため、リーダー行動のアップデートや、シンギュレイトが提供するような「伴走型のマネジメント育成プログラム」の導入が進んでいます。また、チームの生産性向上のため、「良い衝突でチームを動かす実践型eラーニング『攻めの心理的安全性』」のように心理的安全性を確保し、メンバーが自律的に動く環境を整備することが重要視されています。

人事制度・採用・育成

人事制度・採用・育成領域では、人材確保の難化と多様な働き方への対応が顕著です。新卒採用では「3割以上が「新卒採用で計画人数を充足できなかった」」とあり、カルビーが「内定者の家族向けセミナー」を開催するなど、多角的なアプローチが試みられています。育成面では、TOPPANホールディングスが「GX検定」を活用した大規模なGX人材育成を行うなど、特定分野の専門人材育成が強化されています。従業員のエンゲージメント向上やキャリア自律支援も重要視され、カオナビの「カオナビエンゲージメント」やLIXILの内製サーベイ活用事例に見られるように、データに基づいた組織開発が推進されています。さらに、外国人雇用における人権リスク対応や、カスハラ・就活ハラスメント対策など、法改正や社会の変化に対応した制度整備も進んでいます。

HRテック・AI活用

HRテック・AI活用は急速に進展していますが、導入と定着には課題も存在します。採用領域では、アウンコンサルティングが「AI採用広報支援サービス「AIO for HR」」を提供開始するなど、AIを活用した効率化が進む一方で、GIGの調査では「中途求職者の52.8%がAIの回答で「応募見送り」経験」と、AI活用への慎重な姿勢も伺えます。人事評価におけるAI活用は「2％に満たない」とまだ限定的ですが、三菱電機が「AI活用による「グローバル人財情報基盤」を整備」するなど、データ基盤構築への期待は高いです。生成AIの業務定着にはまだ課題が多く、「AIを使うほど、賢くなくなる」という「認知負債」のリスクも指摘されており（パーソル総合研究所のコラム）、AIの適切な活用方法が模索されています。
