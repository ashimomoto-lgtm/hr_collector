2 HR界隈トレンド分析

1on1・マネジメント領域

1on1やキャリア面談は、部下の主体性や成長を促す上で依然として重要視されています。パーソル総合研究所のコラム「なぜ私たちは、それでも1on1をあきらめないのか？」シリーズが示すように、上司が直面する「壁」や「指示待ち部下」の問題も顕在化し、マネジメントの難易度は高まっています。ニッセイ基礎研究所の調査では、ワークエンゲージメント向上には「成長機会をくれる上司」のサポートが不可欠である一方、「人事白書2026」では管理職のスキル不足が働きがい向上の障壁とされています。三菱電機が「自走型リーダー創出（PLB）プログラム」を導入するなど、多様な働き方や価値観に対応し、部下のフォロワーシップを引き出すマネジメントへの転換が求められています。また、パーソル総合研究所のコラムでは、マイクロマネジメントが部下の「成長錯覚」を招く可能性も指摘されており、自律的なチーム作りが課題です。

人事制度・採用・育成

人事制度・採用・育成領域では、ジョブ型雇用の導入が進む一方で、日経ビジネスの「ジョブ型雇用の落とし穴」シリーズが指摘するように、カルビーやオリンパス子会社での「明確な効果実感の欠如」や「ジョブ型リストラ」といった課題が浮き彫りになっています。企業は富士通やソニーグループのように、キャリア自律支援やシニア活性化策を通じて、ジョブ型導入の「落とし穴」を回避しようとしています。採用においては、学情の調査で「28卒の内々定出しの早期化」が顕著であり、テックビズが「採用コンサルティングサービス」を提供するなど、競争激化に対応するための戦略的なアプローチが求められています。また、アクティオホールディングスが「内定者メンタルヘルス対応ライン」を導入し、コロプラが「マイシェルパ」を導入するなど、入社前・後のメンタルヘルス支援やオンボーディングの重要性が高まっています。エスエス製薬と森永製菓による女性のキャリア支援や、SHIROの「全社業務推進グループ」新設に見られるように、多様な人材の活躍を促す取り組みも進んでいます。

HRテック・AI活用

HRテック・AI活用の動向として、採用プロセスにおけるAIの導入が加速しています。品川区役所が自治体DX推進のために「エンPeopleX AI面接」を導入した事例や、「中途の転職事情とAI面接に関する意識調査」が示すように、AI面接は効率化と客観性向上への期待が高まっています。また、営業領域ではamptalkが「amptalk coach」を日産販社に導入し、AIを活用したロープレ支援が進んでいます。しかし、アクセンチュアの調査では「日本企業のAI投資成果と従業員実感」がグローバル平均を下回っており、単なる導入に留まらないAI活用の深化が課題です。パーソル総研が「組織のAX状況を診断するサービス」を提供するなど、AIやテクノロジーを組織変革（AX）に繋げるための支援も登場しており、チームスピリットの「TeamSpirit プロジェクトマネジメント」のように、人材データを活用した適材適所の実現も注目されています。
