1on1・マネジメント領域

1on1は、パーソル総合研究所のコラム群が指摘するように、機能不全に陥りやすいものの、部下の考える力を育み、キャリア自律を促す対話としてその重要性が再認識されている動向が見られます。多様な働き方や価値観に対応するため、管理職には「令和の時代に求められるマネジャーの役割」として、従来の指示命令型からフォロワーシップを醸成し、フィードバックを求め合えるチームを作るリーダーシップへの転換が求められています。また、ダイヤモンド・オンラインの記事「『パワハラがやめられない男性』を管理職に置き続ける会社の罪」が示すように、ハラスメント対策や倫理的なマネジメントも引き続き重要な課題です。組織のマネジメント課題を診断する『マネジメントカルテ』の提供開始など、マネジメント改善への需要は高いです。

人事制度・採用・育成

人事制度・採用・育成領域では、多様性推進が加速しており、オンワードホールディングスが「男性育休取得率100％達成」を掲げるなど具体的な成果が見られる一方、東洋経済オンラインの「数字合わせの女性管理職登用が組織を潰す『多様性社会のパラドックス』」が指摘するように、実効性のある多様性推進が課題となっています。採用市場では「初任給バブル」が見られるものの、若手の早期離職が課題であり、パーソル総合研究所のコラム「苦労の末採用した新入社員が、会社を去る理由」が示すように、入社1年目からのキャリア自律支援が重要視されています。人手不足とAI時代に対応するため、三菱UFJリサーチ&コンサルティングが提唱するリスキリングや、NTTドコモが実践するキャリア開発施策など、従業員の成長を促す育成プログラムが注目を集めています。

HRテック・AI活用

HRテック領域では、タレントマネジメントシステム「カオナビ」の国際基督教大学への導入事例に見られるように、人材情報の統合と活用が進んでいます。特にAIの活用が急速に進展しており、「SmartHR」が人事データと連携したAIプロダクトを発表し、「AirCourse」が「AI研修アシスタント」を提供開始するなど、研修企画の効率化や人材戦略支援への応用が活発化しています。大手企業では「AIエージェント活用」の実態調査が行われ、「SHIFT」がAIを活用した新卒育成戦略を発表するなど、AIが採用・育成・組織再編にまで影響を及ぼし始めています。しかし、パーソル総合研究所のコラム「生成AIはなぜ職場に広がらないのか」が示すように、職場での生成AI普及にはまだ課題も存在しています。
