1on1・マネジメント領域

1on1は、上司が直面する「壁」や機能不全が指摘されつつも、「なぜ私たちは、それでも1on1をあきらめないのか？」とパーソル総合研究所が問いかけるように、その重要性は依然として高く、部下の考える力を育てる対話の再設計が求められています。多様な働き方や価値観の中で、マネジャーの役割は「令和の時代に求められるマネジャーの役割とは？」と問われ、個と組織を活かす「AUBEモデル」や、フォロワーシップの醸成が注目されています。「ダイヤモンド・オンライン」が指摘する「部下が『この上司はムリ』と思う瞬間」や「優秀な人ほど『やる気がなくなる』組織の共通点」に見られるように、リーダーのふるまいや組織文化が部下のエンゲージメントに大きく影響しています。「日本の人事部」の「マネジメントに関する意識調査」や『マネジメントカルテ』の提供開始は、マネジメント課題の可視化と改善への意識の高まりを示しています。ハラスメント対策やキャリア開発支援における管理職の役割再定義も進んでおり、組織変革を推進する「チェンジエージェント養成プログラム」も提供されています。

人事制度・採用・育成

新入社員の意識や定着に関する調査が活発に行われており、「日本の人事部」の「新入社員意識調査2026」や「新入社員育成・定着課題調査2026」からは、若手社員の定着に向けた企業の関心が高いことが伺えます。働き方改革の効果として「残業減少格差」が指摘される一方で、「ECOTONE」の調査ではウェルビーイングな働き方とのギャップが「回復」にあるとされ、社員の心身の健康への配慮が重要視されています。LIXILの「D&Iはトップダウンから『現場主導』へ前進」に見られるように、多様性推進は現場からの主体的な取り組みへとシフトしており、育休復帰支援や障がい者雇用など、包摂的な職場環境づくりが進められています。キャリア開発においては、NTTドコモが「自分らしさ」と「会社の成長」を両立させる施策を実践し、管理職によるキャリア開発支援の重要性も高まっています。採用活動では「27卒 内々定の獲得状況に関するアンケート結果」が発表されるなど、継続的な動向把握と、若手社員の定着を促すための施策が求められています。

HRテック・AI活用

HR領域におけるAI活用は急速に進展しており、「HRzine」の「AI×タレントマネジメント」の現在地や「AI時代に人事が向き合うべき『真の役割』」といったテーマで議論が活発化しています。米オラクルが「Oracle Manager Edge」でAIによる人事リーダー育成支援を開始し、「jinjer」が「国内HRテックNo.1」を目指すなど、HRテックベンダー各社がAIプロダクト戦略を強化しています。採用活動においても、プルークスが「Z世代の採用・AIO対策に特化した『採用ショート動画制作プラン』」を提供し、NODIAが「面接代行オンラインプラットフォーム『INTERVIA』」を開始するなど、AIやテクノロジーを活用した効率化が進んでいます。しかし、「パーソル総合研究所」の調査では「生成AIはなぜ職場に広がらないのか」という課題も指摘されており、組織での生成AI活用には「環境整備と定着のポイント」が重要とされています。NTT東日本グループが「ミキワメAI」を導入して組織開発に活用するなど、データに基づく人事戦略への転換が加速しており、「日本の人事部」の「AX（AIトランスフォーメーション）推進に関する実態調査」もその動向を裏付けています。
