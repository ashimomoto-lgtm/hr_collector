2 HR界隈トレンド分析

1on1・マネジメント領域

1on1やキャリア面談を通じた管理職の役割が改めて注目されており、「パーソル総合研究所」のコラムでは、1on1における上司の「壁」や、キャリア開発風土醸成のための管理職教育の重要性が語られています。「日本の人事部」の調査では、「働きがい向上」の障壁として管理職のスキル不足が指摘され、「日経ビジネス」は管理職の孤立を防ぎリーダーシップを引き上げる組織サポートの必要性を強調しています。多様な働き方や価値観に対応するため、マイクロマネジメントを避け、部下の主体性を引き出すマネジメントへの転換が求められています。ハラスメント対策や、会議における意思決定の質を高めることも、現代のマネージャーに課せられた重要な課題です。

人事制度・採用・育成

人事制度・採用・育成領域では、多様な人材の活躍支援が加速しており、「HRTheory」の「onBoardly for Parents」のような育休復職支援や、「SHIRO」の障がい者雇用促進など、個別ニーズに対応するサービスや制度が展開されています。採用においては、「back check」の調査が示すように、本人情報だけでは不十分との認識から、多角的な情報活用が進む一方、「ベーシックコア」の「SAIKA」のような人事評価システムの導入で、人材データ活用基盤の強化を図る動きが見られます。育成面では、若手社員の「主体性」を重視する傾向が強く、「川崎重工業」の事例のように研修後の行動変容を促す取り組みや、OJT指導の実態調査を通じて効果的な育成手法が模索されています。さらに、「三菱電機」の「Global Career Passport」のようなグローバルな転職制度や、人的資本可視化の動きが、キャリア自律と組織戦略の連携を深めています。

HRテック・AI活用

HRテック・AI活用の動向として、採用領域では「日本の人事部」が「AI面接」の活用法や「TG-WEB mee」のようなAI適性検査サービスの提供を紹介しており、採用プロセスにおけるAIの導入が進んでいます。マネジメント領域では、「レゾナック」が生成AIを活用した管理職向けエンゲージメント改善支援アプリを自社開発するなど、生成AIが業務効率化だけでなく「メンバーへの向き合い方」に本質的な変化をもたらすと期待されています。研修においても、「アイカタ」のようなAI活用伴走サービスが登場し、学習効果の最大化が図られています。しかし、「東洋経済オンライン」の記事がAI利用者の残業時間増加を示唆するように、AI導入が必ずしも効率化に直結しない課題や、「パーソル総合研究所」が指摘する生成AIの職場普及の遅れといった課題も浮上しており、その効果的な活用方法が模索されています。
