1on1・マネジメント領域

1on1面談は引き続き重要視されるものの、パーソル総合研究所のコラムが「1on1という『旅』の途中で上司がぶつかる３つの『壁』」や「なぜ1on1は機能しないのか？」と指摘するように、その効果的な運用が課題となっています。マネジメント層には、部下の主体性を引き出す「フォロワーシップ」の醸成が強く求められており、パーソル総合研究所は「部下のフォロワーシップの時代へ」と提言しています。また、ヒューマンの調査では「コミュニケーション研修」が強化したい研修のトップに挙げられ、フィードバックを求め合えるチーム作りや多様性を活かすリーダー行動のアップデートが注目されています。三菱UFJリサーチ&コンサルティングは「経営理念浸透」が「組織風土」改革につながると分析しており、組織全体の対話とエンゲージメント向上への関心が高まっています。

人事制度・採用・育成

人事制度・採用・育成領域では、多様な働き方やキャリア形成を支援する動きが顕著です。NTTドコモが「期待の社員をレンタル移籍」制度を導入し、大東建託がグループ会社への転籍制度を導入するなど、人材の流動性を高める施策が見られます。採用においては、マブチモーターが「MyRefer」を導入してリファラル採用を強化し、インフィニティエージェントが「Infinity-Recruiting」を提供開始するなど、採用マーケティングやタレントアクイジションの専門性が重視されています。カルビーが約17年ぶりに人事制度を刷新したように、企業は従業員エンゲージメントやキャリア自律を促す制度の見直しを進めており、学情の調査では20代キャリア採用の迅速化も課題となっています。

HRテック・AI活用

HRテックとAIの活用は、人事領域の効率化と高度化を大きく推進しています。KPMGジャパンはAIでリアルタイムに対話の質を高める「対人対話ナビゲーションエージェント」を提供し、MIXIはAIを面接に組み込むことで採用の質と候補者体験を向上させています。パーソルキャリアは社内AIプロダクトで求人票作成を効率化し、トラスコ中山はAI活用で人事異動の意思決定プロセスを約98％高速化するなど、具体的な業務改善事例が多数報告されています。jinjerの「HR Signals」シリーズや東芝の「人財検索AI機能」のように、組織や社員の隠れたシグナルを可視化し、タレントマネジメントを強化する動きも活発化しており、日立製作所は10万人規模のAIプロフェッショナル人材育成を計画しています。
