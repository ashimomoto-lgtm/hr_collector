2 HR界隈トレンド分析

1on1・マネジメント領域

1on1は依然として重要なマネジメント手法であるものの、その機能不全や上司が直面する「壁」が指摘されており（パーソル総合研究所「なぜ1on1は機能しないのか？」）、部下の考える力を育てる対話の再設計が求められています。「フィードバック経営」が戦略として発表され（U-ZERO）、多様性時代においては「フィードバックを求め合えるチーム」のリーダー行動が重視されています。管理職には、部下のキャリア開発支援やフォロワーシップの醸成、そして「指示待ち部下」を自ら動くチームに変えるマネジメント転換術が強く求められています（パーソル総合研究所「『指示待ち部下』は上司が原因？」）。「いい人ばかりなのに、なぜか働きにくい職場」といった組織の違和感や、リーダーシップの誤解（日経ビジネス「あなたは部下を『無言で断罪』していないか」）に対する問題意識も高まっています。

人事制度・採用・育成

人事制度においては、王子HDが「退職一時金を廃止」するなど、退職給付制度の改革が進んでおり、2026年10月の「同一労働同一賃金ガイドライン」改正（HRzine）など法改正への対応も喫緊の課題となっています。採用活動では「SNS採用ブースト」（日本の人事部）や「採用ブランディングサービス」（イノーバ）の活用が進む一方で、新入社員の早期離職防止に向けた「キャリア自律」支援の重要性が高まっています（パーソル総合研究所「苦労の末採用した新入社員が、会社を去る理由」）。育成面では、東急バスが「外国人材」資本経営として外国人運転士の研修に密着する（日経ビジネス）など多様な人材の活用・育成が注目され、オンワードホールディングスのように「男性育休取得率は100％達成」といったダイバーシティ推進の成果も具体的に示されています。中途採用市場では「35歳限界説」が後退し、中高年や女性にも転職機会が広がっている（ニッセイ基礎研究所）一方で、新入社員の「今の会社で働き続けたい」という意識は情報通信業で増加傾向にあり（ALL DIFFERENT）、定着に向けた取り組みが重要視されています。

HRテック・AI活用

HRテック領域では、AI、特に生成AIの活用が急速に進展しており、「AIエージェント時代の人事白書 2026」（AICX協会）が公開されるなど、その動向が注目されています。具体的な導入事例として、米オラクルが「Oracle Manager Edge」で人事リーダー育成支援を強化し、KIYOラーニングがAirCourseで「AI研修アシスタント」を提供開始するなど、AIが人事・育成業務の効率化に貢献しています。LINEヤフーが「AIで人事総務の工数が半分に」なった経験を共有し、NTT東日本グループが「ミキワメAI」を導入して組織開発に活用するなど、AI導入による業務変革が大手企業で進んでいます。一方で、生成AIの職場への普及には課題も指摘されており（パーソル総合研究所「生成AIはなぜ職場に広がらないのか」）、組織でのAI活用には環境整備と定着のポイントが重要視されています（HRzine）。採用面では、AI面接に関する意識調査（日本の人事部）や面接代行オンラインプラットフォーム「INTERVIA」（NODIA）の登場など、採用プロセスにおけるAIの活用も広がっています。
