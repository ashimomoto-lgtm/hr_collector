1on1・マネジメント領域

1on1は依然として重要なマネジメント手法であるものの、「なぜ1on1は機能しないのか？」や「上司がぶつかる３つの『壁』」といった課題が指摘され、その効果的な運用や対話の再設計が模索されています（パーソル総合研究所）。部下のキャリア自律を促すための管理職の役割や、キャリア面談の効果を高める方法にも注目が集まっています。また、「フォロワーシップ」の醸成が組織全体の活性化に不可欠であるとされ、「もう管理職だけに背負わせない」という意識が広がりつつあります（パーソル総合研究所）。「EVeMマネ型トレーニング」のようなマネジメントワークショップの提供も開始されており、多様な時代に対応するリーダー行動や組織風土改革への関心が高まっています。

人事制度・採用・育成

人事制度・採用・育成領域では、初任給引き上げ（メットライフ生命、労務行政研究所調査）や有給休暇制度の拡充（IDOM）など、報酬・福利厚生の改善が進んでいます。従業員のエンゲージメント向上、特に「オンボーディング」の重要性や若手・シニア層のモチベーション低下（日経ビジネス）への対応が課題です。キャリア形成支援では、NTTドコモの取り組みのように「自分らしさ」と「会社の成長」を両立させる施策や、OJTによる新卒エンジニア育成（伊藤忠テクノソリューションズ）が注目されています。また、女性のヘルスケアや共働き世帯の意識調査、カスハラ・就活セクハラ対策義務化など、多様な働き方に対応した制度設計やハラスメント対策も重視されています。

HRテック・AI活用

HRテック分野では、AIを活用した採用分析レポートの高度化（タレントアンドアセスメント「SHaiN」）や、人事評価と給与計算を連携させる「給与改定シミュレーション」機能（jinjer「ジンジャー人事評価」）など、業務効率化とデータ活用が進んでいます。AIエージェント「WorkOn」が労務・勤怠・給与計算機能を追加するなど、AIがHR業務全般を支援する動きが加速しています。一方で、「生成AIはなぜ職場に広がらないのか」といった調査（パーソル総合研究所）が示すように、AIの職場での普及には課題も存在し、利用率だけでは測れない実態が明らかになっています。障がい者の業務におけるAI利用に関する調査も行われており、多様な働き方におけるAIの活用可能性も探られています。
