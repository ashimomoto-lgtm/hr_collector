2 HR界隈トレンド分析

1on1・マネジメント領域

1on1やキャリア面談の重要性が高まる一方で、管理職の業務過多による対話不足が課題となっています（mento調べ「1on1でキャリアについて十分に話せている管理職は35.6%」）。管理職には部下のキャリア開発風土醸成や自律的な行動を促すマネジメント、権限委譲のスキルが強く求められています（パーソル総合研究所コラム「キャリア開発風土醸成へ―管理職の役割と求められる教育」、岩崎徹也氏著『抱え込む上司はいらない』）。また、「人事白書2026 調査結果」では、働きがい向上の最大の障壁が管理職のスキル不足とされており、マイクロマネジメントによる「成長錯覚」への警鐘も鳴らされています（パーソル総合研究所コラム）。ハラスメント対策や部門間の「縦割り」意識の解消も、現代のマネジャーに求められる重要な役割です。

人事制度・採用・育成

採用においては、新卒選考でコミュニケーション能力が重視される傾向が続き（日本の人事部記事）、27卒採用では「集客」から「つなぎ止め・マッチング」への課題変化が指摘されています（ワークス・ジャパン調べ）。学生の就職活動早期化と二極化も進み（学情）、内定獲得後も「納得感」を求めて再挑戦する動きも見られます（ABABA総研調べ）。人事制度面では、人材マネジメントの国際規格「ISO30201」が正式発行され、人的資本開示やグローバル人材の可視化の重要性が増しています。富士通や日立製作所がジョブ型雇用を導入し、キャリア自律を促す動きが加速する一方、LINEヤフーでは育休中のAI研修など、多様な働き方に対応した育成・支援策が展開されています。

HRテック・AI活用

HRテック領域では、AIの活用が急速に進展しており、研修のプロが提供するAI活用伴走サービス『アイカタ』が登場しています。米オラクルは人事向けの「Fusion Agentic ApplicationsとAIエージェント」を発表し、Legal Nodeはパワハラ・セクハラ社内調査支援AIエージェントの提供を開始するなど、多様な業務でのAI活用が具体化しています。また、KDDIが統合人事システム「COMPANY」を、福井県敦賀市が「HRBrain タレントマネジメント」を導入するなど、大手企業や自治体でのHRプラットフォーム導入が進み、データドリブン経営への移行を加速させています。一方で、東洋経済オンラインの記事「AIを使いすぎると『バカになる』は真実」が示すように、AIの過度な利用による認知負債への懸念も提起されており、適切な活用が今後の課題となるでしょう。
