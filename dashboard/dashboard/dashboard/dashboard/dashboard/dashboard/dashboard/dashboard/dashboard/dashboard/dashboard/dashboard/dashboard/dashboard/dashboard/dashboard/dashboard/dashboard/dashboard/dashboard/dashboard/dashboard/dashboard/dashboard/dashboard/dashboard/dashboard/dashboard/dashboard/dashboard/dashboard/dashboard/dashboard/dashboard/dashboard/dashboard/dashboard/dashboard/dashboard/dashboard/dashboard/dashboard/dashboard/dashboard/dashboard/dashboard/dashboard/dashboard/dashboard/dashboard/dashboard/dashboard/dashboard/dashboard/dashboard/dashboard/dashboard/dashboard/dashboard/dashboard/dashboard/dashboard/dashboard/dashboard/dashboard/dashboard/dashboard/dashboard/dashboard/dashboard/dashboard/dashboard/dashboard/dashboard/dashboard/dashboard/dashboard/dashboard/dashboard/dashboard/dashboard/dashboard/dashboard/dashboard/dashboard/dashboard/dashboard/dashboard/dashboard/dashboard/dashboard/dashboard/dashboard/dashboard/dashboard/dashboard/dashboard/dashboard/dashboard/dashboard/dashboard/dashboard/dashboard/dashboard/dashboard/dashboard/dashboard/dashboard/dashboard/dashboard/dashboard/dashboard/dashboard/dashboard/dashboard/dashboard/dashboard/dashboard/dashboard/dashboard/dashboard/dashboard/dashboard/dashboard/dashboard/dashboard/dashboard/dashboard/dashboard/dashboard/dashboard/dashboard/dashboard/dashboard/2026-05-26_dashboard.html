2 HR界隈トレンド分析

1on1・マネジメント領域

1on1は依然として重要なマネジメント手法であるものの、「パーソル総合研究所」のコラム群が示すように「機能しない壁」に直面しており、部下の考える力を育む対話の再設計が求められています。多様な働き方に対応するため、従来の管理職任せではなく、部下の主体性を引き出す「フォロワーシップ」の醸成が注目され、「パーソル総合研究所」は「リーダーの右腕」の力を組織変革の鍵と捉えています。また、管理職には部下のキャリア開発支援の役割が強く求められており、「日本の人事部」の調査では「管理職志向」に関する意識も探られています。職場環境においては、「東洋経済オンライン」が報じる「お局さま」問題や「リクルートワークス研究所」による「ブルシット・ジョブ」の存在が指摘され、健全な組織風土の醸成が喫緊の課題となっています。

人事制度・採用・育成

人事制度領域では、カルビーが約17年ぶりに人事制度を刷新するなど、企業が抜本的な改革を進めています。採用においては、「HRzine」が報じる「インターン=新卒採用の前倒し」ではないという認識や、マブチモーターによる「MyRefer」導入でリファラル採用を強化する動きが見られます。20代キャリア採用では「学情調べ」によると応募から内定まで3週間以内が約5割と迅速化が進んでおり、タレントアクイジションにおけるプロのスカウト力やエンプロイヤーブランドの向上が重要視されています。育成面では、NTTドコモがキャリア開発施策を実践し、川崎重工が経営層を巻き込んだマネジメント研修を行うなど、キャリア自律と経営リーダー育成に注力しています。また、「日本の人事部」の調査からは、従業員エンゲージメントの向上や「クォーターライフクライシス」への対応、育児と仕事の両立支援が引き続き重要な課題であることが伺えます。

HRテック・AI活用

HRテックの導入は加速しており、「日本経済新聞社調べ」によると大企業の半数以上が採用分野で活用し、星野リゾートも「Workday HCM」を導入して人材マネジメントの高度化を図っています。AIは採用プロセスの効率化と質の向上に大きく貢献しており、「VARIETAS」の「AI技術者基礎力面接官」やMIXIの面接へのAI組み込み、「パーソルキャリア」の求人票作成支援、そして「トラスコ中山」が富士通と協働した人事異動の意思決定プロセスの高速化（約98%の工数削減）が具体的な事例です。「KPMGジャパン」は「対人対話ナビゲーションエージェント」でリアルタイムな対話支援も提供しています。生成AIの活用も進む一方で、「パーソル総合研究所」のコラムが指摘するように、職場での普及や生産性向上にはまだ課題が見られます。また、「jinjer」の「HR Signals」のように、社員の隠れたシグナルを可視化し、データに基づいた人事戦略を支援する動きも活発です。
