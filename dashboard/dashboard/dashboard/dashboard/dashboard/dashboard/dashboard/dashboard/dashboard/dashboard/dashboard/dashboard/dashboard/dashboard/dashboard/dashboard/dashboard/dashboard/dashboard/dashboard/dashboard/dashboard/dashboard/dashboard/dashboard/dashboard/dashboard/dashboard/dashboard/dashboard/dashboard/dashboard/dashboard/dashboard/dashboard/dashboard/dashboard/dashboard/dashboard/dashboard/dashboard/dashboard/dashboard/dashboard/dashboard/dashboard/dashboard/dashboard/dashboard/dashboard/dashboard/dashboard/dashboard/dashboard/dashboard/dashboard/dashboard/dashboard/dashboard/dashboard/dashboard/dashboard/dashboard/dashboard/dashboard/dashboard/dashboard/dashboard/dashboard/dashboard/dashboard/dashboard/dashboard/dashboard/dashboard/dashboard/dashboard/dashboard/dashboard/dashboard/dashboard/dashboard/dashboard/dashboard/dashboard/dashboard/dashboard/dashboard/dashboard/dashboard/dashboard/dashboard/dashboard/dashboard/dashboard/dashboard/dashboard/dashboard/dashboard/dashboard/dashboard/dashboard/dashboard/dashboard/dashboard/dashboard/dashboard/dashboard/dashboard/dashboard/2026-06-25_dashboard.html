1on1・マネジメント領域

1on1は依然として重要なマネジメント手法であるものの、その機能不全や上司が抱える「壁」が指摘されており、部下の「考える力」を育てる対話の「再設計」が求められています（パーソル総合研究所）。また、上司だけでなく部下の「フォロワーシップ」の醸成が強調され、「もう管理職だけに背負わせない」マネジメントへの転換が提唱されています（パーソル総合研究所）。多様な働き方の中で、ハラスメントを恐れ「ねぎらいの言葉をかけられない」上司の意識調査（Unipos調べ）や、社員の「沈黙」の正体（HRzine）が明らかになるなど、心理的安全性の確保やコミュニケーションの質向上が課題となっています。さらに、管理職のキャリア開発支援における役割や、経営理念浸透による組織風土改革の重要性も指摘されています（三菱UFJリサーチ&コンサルティング）。

人事制度・採用・育成

若手の「離職実態」が課題となる中（日本の人事部）、企業は「公募制度」や「社内スカウト」といった制度導入で離職を防ぎ、社員の活躍を促そうとしています（HRzine、パナソニックグループ）。採用においては、労働条件が横並びの時代に学生が自社の「働き方」に共感するかがカギとなり（日経ビジネス）、島津製作所のように「タレントブック・ストーリー」を活用した学生層への認知強化も進んでいます（talentbook）。育成面では、人手不足とAI時代における「リスキリング・リカレント教育」の意義が再認識され（三菱UFJリサーチ&コンサルティング）、企業が提供する学習の「定着と業務活用」が実態調査で明らかになっています（日本の人事部）。また、MIXIが「人的資本経営のロジックモデル」を公開するなど、人的資本開示とデータ活用への関心が高まり、福利厚生も「支出削減目的」の利用が浮き彫りになるなど、実効性が重視されています（ベネフィット・ワン）。

HRテック・AI活用

HRテック領域では、人事データの「勘や経験」からの脱却（カオナビ）や、就職面接の「機能不全」をAIが解決する可能性（WSJ PickUp）が議論されています。AI活用は国の政策と融合し、人事戦略において「自社は何のために存在し人はどう働くのか」という問いを軸に考える必要性が指摘されています（HRzine）。LINEヤフー人事の事例のように、AI導入における「草の根活動で失敗」から学び、具体的な打ち手を進める企業も現れています。Smart相談室の「AIコンシェルジュ」機能のように、AIが専門家推薦を支援するサービスも登場しており、富士通は「Fujitsu Technology and Service Vision 2026」でAI時代の未来ビジョンを発表しています。一方で、「生成AIはなぜ職場に広がらないのか」という実態調査（パーソル総合研究所）も行われ、AIの普及における課題も浮き彫りになっています。
