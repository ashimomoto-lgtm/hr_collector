1on1・マネジメント領域

1on1は引き続き重要なマネジメント手法ですが、「パーソル総合研究所」のコラムでは上司が直面する「壁」や、それを乗り越えるための「あきらめない」工夫が語られています。管理職のスキル不足が「働きがい向上」の最大の障壁と指摘されており（「日本の人事部」）、管理職の孤立を防ぎ、リーダーシップを引き上げる組織サポートの必要性が「日経ビジネス」で強調されています。多様な働き方や価値観に対応するため、マイクロマネジメントを避け、部下の主体性を引き出すフォロワーシップの醸成や、キャリア開発支援を含むマネジャーの役割変革が求められています。また、「日本の人事部」の記事では、働き方改革による残業減にもかかわらず「職場の低体温化」が進む実態も示されています。

人事制度・採用・育成

人事制度・採用・育成領域では、キャリア開発支援が重視されており、「パーソル総合研究所」のコラムでは管理職によるキャリア面談の重要性が繰り返し指摘されています。採用においては、「日本の人事部」の調査で人事の約8割が「本人情報だけでは足りない」と回答しており、「back check」のような外部情報を活用する動きが見られます。育成面では、集合研修やOJTの実態調査に加え、「Z世代エンジニア」へのOJT指導の難易度も課題となっており、川崎重工業の事例（「HRzine」）のように研修後の行動変容を促す取り組みが注目されます。また、エスエス製薬と森永製菓による女性のキャリア支援「クロスメンタリング」や、三菱電機の「Global Career Passport」のような多様な働き方を支援する制度導入、障がい者雇用（SHIRO）や仕事と介護の両立支援（日立製作所）など、包摂的な人事制度への関心が高まっています。

HRテック・AI活用

HRテック・AIの活用は人事領域で急速に進展しており、「日本の人事部」の記事では「AI面接」が採用プロセスを「人間らしく」変える可能性が示唆されています。生成AIはマネジメント領域にも導入され、「レゾナック」が従業員エンゲージメント改善支援アプリを自社開発するなど、業務効率化だけでなく「メンバーへの向き合い方」の本質的変化をもたらすと期待されています（「HRzine」）。一方で、人事部門での生成AI活用には「情報漏洩・プライバシー保護への不安」が最大の課題として挙げられており（「日本の人事部」）、普及への障壁となっている実態も「パーソル総合研究所」の調査で明らかになっています。タレントマネジメントシステム「HRBrain」の導入（小岩井乳業）や新卒採用向け適性検査「Track Talent Assessment」（ギブリー）のリリースなど、データに基づいた人材活用や採用の効率化ツールも進化を続けています。
