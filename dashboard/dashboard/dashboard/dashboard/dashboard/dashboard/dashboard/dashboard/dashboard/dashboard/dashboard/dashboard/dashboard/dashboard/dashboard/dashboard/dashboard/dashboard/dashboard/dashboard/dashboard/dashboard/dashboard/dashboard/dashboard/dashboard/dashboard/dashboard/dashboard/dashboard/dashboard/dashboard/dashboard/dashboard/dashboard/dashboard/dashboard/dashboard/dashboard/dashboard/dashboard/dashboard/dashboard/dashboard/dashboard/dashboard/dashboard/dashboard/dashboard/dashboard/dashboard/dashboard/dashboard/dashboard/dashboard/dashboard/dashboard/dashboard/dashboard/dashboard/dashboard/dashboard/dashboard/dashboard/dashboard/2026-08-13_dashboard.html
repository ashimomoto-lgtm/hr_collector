2 HR界隈トレンド分析

1on1・マネジメント領域

1on1は、上司が直面する「壁」を乗り越え、部下のキャリア開発支援やフォロワーシップ醸成に注力する重要性が「パーソル総合研究所」の複数のコラムで強調されている。「日本の人事部」の「マネジメントに関する意識調査」からも、多様な働き方や価値観に対応するため、マイクロマネジメントを避け、部下の主体性を引き出すマネジメント転換術が求められていることがわかる。「HRzine」は、生成AIがマネジメントにもたらす変化は業務効率化だけでなく「メンバーへの向き合い方」の本質的変化であると指摘しており、新たな視点が加わっている。また、「パーソル総合研究所」の「職場の低体温化」の実態調査や、部門間の「縦割り」意識に関する「日本の人事部」の調査からは、組織の活力低下やコミュニケーション課題への対応も急務であることが示唆される。

人事制度・採用・育成

採用においては、「back check」の調査で人事の約8割が「本人情報だけでは足りない」と回答しており、多角的な情報に基づく判断の必要性が高まっている。育成面では、若手社員に「主体性」が求められ（「日本の人事部」）、研修の「やりっぱなし」を防ぎ「行動変容」を促す取り組み（「川崎重工業」の事例）や、AI時代の経験学習加速術が「HRzine」で紹介されるなど、より実践的なアプローチが重視されている。キャリア自律の支援は重要性を増しており、「NTTドコモ」がキャリア開発施策を実践し、「パーソル総合研究所」は「人的資本可視化指針」改訂から経営戦略と人材戦略の連動を提言している。多様な人材が活躍できる人事制度の整備も進み、「森永製菓」と「エスエス製薬」による女性のキャリア支援や、「三菱電機」の「Global Career Passport」導入、「日立製作所」の「仕事と介護の両立推進サービス」提供など、個別ニーズへの対応が広がっている。

HRテック・AI活用

HRテックの導入は加速しており、「小岩井乳業」が「HRBrain タレントマネジメント」を、「日本原子力防護システム」が「SmartHR」を、「ヤマト運輸」が「COMPANY」を導入するなど、人材データ活用や人事労務業務の効率化が進展している。AI活用は採用・育成・マネジメントの各領域で注目され、「日本の人事部」は「AI面接」が採用を「人間らしく」する可能性を示唆し、「レゾナック」は生成AIを活用した管理職向けエンゲージメント改善支援アプリを自社開発している。育成分野では、「日本の人事部」がAI活用伴走サービス『アイカタ』を提供開始するなど、具体的なサービス展開が見られる。一方で、「日本の人事部」の調査では、人事部門での生成AI活用における「情報漏洩・プライバシー保護への不安」が最多であり、「パーソル総合研究所」も生成AIが職場に広がらない要因を探るなど、導入における課題と対策も同時に議論されている。「パーソルビジネスプロセスデザイン」の「レポラビ」のような採用レポート高速化サービスや、ストレスチェックデータ分析レポートなど、HR業務の効率化・高度化を支援するテックサービスが多岐にわたって提供されている。
