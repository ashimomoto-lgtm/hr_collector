2 HR界隈トレンド分析

1on1・マネジメント領域

1on1の重要性は引き続き高く、パーソル総合研究所のコラムでは「なぜ私たちは、それでも1on1をあきらめないのか？」と題して、上司が直面する「壁」や部下を「主役」にするアプローチが議論されています。多様な働き方や価値観の中で、管理職にはキャリア開発支援やフォロワーシップの醸成が強く求められており、パーソル総合研究所のコラム「キャリア開発風土醸成へ」シリーズや「フォロワーシップをいかに醸成するか」でその役割が強調されています。一方で、製造業の現場リーダーの約6割が管理業務に追われている（X Mile調べ）といった負担の実態や、マイクロマネジメントによる部下の「成長錯覚」（パーソル総合研究所）といった課題も指摘されています。組織の縦割り意識（日本の人事部）や会議の非効率性（パーソル総合研究所）も課題として挙げられ、マネジメントの質向上が急務です。また、「マネジメントに関する意識調査」（日本の人事部）が実施されるなど、マネジメント層への関心が高まっています。

人事制度・採用・育成

人事制度・採用・育成領域では、採用力強化のために過半数の企業が「報酬の改定」（日本の人事部）を実施するなど、待遇改善が活発です。東京エレクトロン デバイスが4期連続の賃上げを発表した事例もその一端です。働きやすい職場環境の整備も進み、「有休奨励」が最多施策である一方、リモートワークには地域格差が見られます（日本の人事部）。福利厚生サービス「ライフプラス」（CCH）や社員向けアプリ「D-Link」（大和証券、ヤプリ）の導入など、従業員エンゲージメントや定着支援の取り組みも多様化しています。採用においては「採用業務の「見えない工数」実態調査2026」（日本の人事部）に見られる効率化の必要性や、JTBのタレントアクイジションのようにビジネス改革を見据えたキャリア採用が注目されています。

HRテック・AI活用

HRテック・AI活用は人事領域で急速に進展しており、「AI面接」が採用の質を高める可能性が「日本の人事部」の記事で示されています。ラグザスの調査では、生成AIのヘビーユーザーの割合が「人事・採用職」で65.1％と最も高く、人事領域でのAI活用が進んでいることが伺えます。松尾研究所とビズリーチは「AI時代の人的資本経営と人事の役割」について語り、Sansanやメルカリでは「CHRO兼AI責任者」が登場するなど、AIを経営戦略に組み込む動きが見られます。採用オウンドメディア「MyTalent Brand」（三菱ケミカル、TalentX）や説明会自動化サービス「リクルートミル」（一条工務店、MIL）など、具体的な採用プロセスでのHRテック導入も活発です。一方で、パーソル総合研究所のコラム「生成AIはなぜ職場に広がらないのか」が示すように、普及への課題も存在します。
