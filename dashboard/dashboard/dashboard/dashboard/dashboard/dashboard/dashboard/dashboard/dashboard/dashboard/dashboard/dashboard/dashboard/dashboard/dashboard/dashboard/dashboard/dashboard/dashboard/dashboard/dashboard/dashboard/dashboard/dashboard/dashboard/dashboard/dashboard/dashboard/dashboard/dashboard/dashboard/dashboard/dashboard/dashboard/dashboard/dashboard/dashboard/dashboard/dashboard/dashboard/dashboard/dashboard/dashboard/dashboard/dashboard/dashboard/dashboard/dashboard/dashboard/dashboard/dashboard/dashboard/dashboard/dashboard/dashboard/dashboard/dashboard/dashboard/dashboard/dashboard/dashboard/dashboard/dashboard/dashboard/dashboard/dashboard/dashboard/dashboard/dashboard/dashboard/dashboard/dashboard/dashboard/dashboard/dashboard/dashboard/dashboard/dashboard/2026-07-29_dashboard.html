2 HR界隈トレンド分析

1on1・マネジメント領域

1on1やマネジメント領域では、上司と部下の関係性強化が重視されています。HRzineの「1on1が空回りする理由」が示すように、1on1の質向上にはフィードバック文化の醸成が不可欠であり、パーソル総合研究所のコラムでは上司が直面する「壁」への対応が論じられています。また、多様な働き方に対応するため、マイクロマネジメントを避け、部下の主体性を引き出すフォロワーシップの育成が注目されており（パーソル総合研究所「フォロワーシップをいかに醸成するか」）、管理職によるキャリア開発支援の重要性も高まっています。組織の活性化には、建設的なコンフリクトの育成や会議の質の向上が不可欠であり、日本の人事部からは組織マネジメント課題を診断する「マネジメントカルテ」も提供されています。

人事制度・採用・育成

人事制度・採用・育成領域では、戦略的な人材確保と定着が喫緊の課題となっています。採用活動では、日本の人事部「採用管理システム（ATS）利用実態調査2026」に見られるようにATSの活用が進み、日経ビジネス「新卒採用に『学業』という評価軸が登場」が示すように評価軸も多様化しています。育成・定着においては、HRzine「『立ち上がりが遅い』の正体を探る」がオンボーディングの重要性を指摘し、Z世代エンジニアへのOJT指導の難しさも浮上しています。人事制度面では、東京エレクトロン デバイスやマイナビの調査が示すように、初任給を含む継続的な賃上げが行われ、福利厚生サービスの拡充や、弥生の「弥生労務 Next」のようなクラウド労務管理システムの導入が進んでいます。JTBのタレントアクイジションやNTTドコモのキャリア開発施策など、人的資本経営の観点から戦略的な人材確保と育成への注目が高まっています。

HRテック・AI活用

HRテック・AI活用の動向では、AIが採用活動やタレントマネジメントに深く浸透しています。採用では、AIによるスカウトメールの受け入れ意向が調査され（HRzine「採用候補者の約9割がAIによるスカウトメールを『内容次第』で受け入れる」）、ヒューマネージのAI面接サービス「TG-WEB mee」も登場し効率化が進んでいます。タレントマネジメントシステムも進化し、マイナビの「マイナビ TalentBase」のように独自の職業スキルタクソノミーを搭載し、Skillnoteも「スキルデータのインフラ」推進を掲げています。労務管理や勤怠管理では、チームスピリットの「TeamSpirit for SAP S/4HANA」などがデータ連携を強化しています。一方で、東洋経済オンライン「AIを雑用ツールにしてはいけない」が指摘するように、AI活用は単なる効率化に留まらず、HRzine「AI時代こそ『Humanity』を経営インフラへ」が提唱するように、人間中心の視点と戦略的な推進が求められています。
