1on1・マネジメント領域

1on1は依然として重要視される一方で、パーソル総合研究所のコラム群では、その機能不全や「壁」が認識され、部下の自律を促す対話の再設計が求められています。U-ZEROが「フィードバック経営」戦略を発表し、富士通やSmartsheet社とパートナーシップを結ぶなど、フィードバックの質と量が組織成長に不可欠とされています。管理職には、多様な働き方や価値観に対応し、部下のキャリア開発支援やフォロワーシップの醸成を通じて、個と組織を活かす「AUBEモデル」のようなリーダー行動が期待されています。また、「日本の人事部」が提供開始した「マネジメントカルテ」のように、自社のマネジメント課題を可視化するツールも登場しています。ハラスメント対策や妊娠報告時の対応など、個別具体的なマネジメントスキルも重視される動向が見られます。

人事制度・採用・育成

人的資本経営が重視される中、ウェルビーイングやD&I推進が主要なテーマであり、LIXILのようにトップダウンから「現場主導」で組織開発を進める事例も見られます。新入社員の意識や定着に関する調査（「新入社員意識調査2026」など）が活発に行われ、特にZ世代の価値観を理解した採用・育成が課題となっています。転職市場では「35歳限界説」が後退し、ニッセイ基礎研究所の調査が示すように中高年や女性にも機会が広がっており、企業は多様な人材の獲得と定着に注力しています。キャリア開発支援は管理職の重要な役割とされ、NTTドコモが実践するような「自分らしさ」と「会社の成長」を両立させる施策が注目されています。ストレスチェックや育休復帰支援など、従業員の心身の健康と両立支援を通じた働きやすい環境整備が進められています。

HRテック・AI活用

HRテック分野ではAI活用が急速に進展しており、米オラクルが「Oracle Manager Edge」で人事リーダー育成支援を強化するなど、タレントマネジメントや組織開発へのAI導入が加速しています。jinjerは2030年に「国内HRテックNo.1」を目指す新AIプロダクト戦略を発表し、採用分野ではプルークスがZ世代向けの「採用ショート動画制作プラン」を提供するなど、AIを活用した採用活動も活発化しています。AICX協会が「AIエージェント時代の人事白書 2026」を公開するなど、AI時代における人事の「真の役割」や「Talent Intelligence」の概念が議論され、データに基づく人事への転換が求められています。NTT東日本グループがリーディングマークの「ミキワメAI」を導入し、約3万名の組織開発に活用するなど、大規模組織でのAI導入事例も増えています。一方で、生成AIが職場に広がらない課題も指摘されており、AIを効果的に活用するための環境整備や定着のポイントが模索されています。
