1on1・マネジメント領域

1on1の形骸化が課題視され、「なぜ1on1は機能しないのか？ ～部下の考える力を育てる対話の再設計〜」（パーソル総合研究所）という問いに対し、対話の再設計が求められています。マネジメントにおいては、上司と部下の関係性だけでなく、「フォロワーシップをいかに醸成するか」（パーソル総合研究所）といった部下の主体性やチーム全体の協調性を高める視点が重要です。また、「EVeMマネ型トレーニング」（EVeM）のような実践的なワークショップを通じて、管理職のスキルアップやキャリア開発支援の役割が強化されています。多様な働き方の中で、「パワハラと指導の違い」（パーソル総合研究所）を明確にし、健全な組織風土を醸成するためのリーダー行動が注目されています。

人事制度・採用・育成

人事制度においては、カルビーが約17年ぶりに人事制度を抜本的に刷新するなど、企業の変革期に合わせた見直しが進んでいます。多様な人材の活躍を促すため、森永製菓が「56歳」役職定年を廃止し、シニア層のキャリア形成支援が強化される一方、「ブルーカラー職の将来キャリア・シニア就労」に関する調査も行われています。採用市場では、新卒の「内々定率は77.7％」（学情）と高い水準を維持しつつも、ハイクラスエンジニア採用の「予算型リテーナー」（overflow）など専門職へのアプローチが多様化しています。また、外国人材の育成からマッチングまで一貫して支援する「LivCo」のような取り組みや、女性のヘルスケア、障がい者のAI利用実態など、個々の従業員に寄り添う施策が注目されています。

HRテック・AI活用

HRテック領域では、AIの活用が採用から労務管理まで広範に進んでいます。「ミイダス AIバディー」（ミイダス）のように採用専門家7職種の業務をAIで一気通貫化するサービスが登場し、「Wantedly Hire」（ウォンテッドリー）ではハイパフォーマーを基にAIが選考基準を提案するなど、採用プロセスの効率化・高度化が進んでいます。メルカリではCTOがCHRO兼CAIOに就任し、AIネイティブ企業への組織変革を推進するなど、経営戦略の中心にAIが据えられています。一方で、「生成AIはなぜ職場に広がらないのか」（パーソル総合研究所）といった課題意識も存在し、AIの導入だけでなく、その実態と効果的な活用方法が模索されています。
