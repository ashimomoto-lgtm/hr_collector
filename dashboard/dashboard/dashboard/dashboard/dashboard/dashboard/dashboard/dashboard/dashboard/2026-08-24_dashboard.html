1on1・マネジメント領域

1on1やキャリア面談を通じた部下の主体性・成長支援が重視される一方、マネージャー層のスキル不足やマイクロマネジメントの弊害が課題として挙げられています。パーソル総合研究所のコラムでは、「なぜ私たちは、それでも1on1をあきらめないのか？」シリーズで1on1の「壁」を乗り越える重要性を説き、「指示待ち部下」は上司が原因である可能性も指摘しています。多様な働き方や価値観に対応するため、管理職にはキャリア開発支援やフォロワーシップの醸成、フィードバックを求め合えるチーム作りが求められています。三菱電機が「自走型リーダー創出（PLB）プログラム」を導入するなど、自律的な組織運営に向けたマネージャー育成が活発です。

人事制度・採用・育成

人事制度においては、ジョブ型雇用への移行が進む一方で、「メンテ不足」や「年配忖度」といった「4つの落とし穴」が日経ビジネスで指摘されるなど、運用の課題が顕在化しています。採用市場では、学情の調査で「28卒の内々定出しが3年生の12月に突出」し、早期化が加速しています。新入社員の「配属ガチャ」による早期離職や「就職活動をやり直したい」と考える若手が増加しており、オンボーディングやメンタルヘルスケアの重要性が増しています。アクティオホールディングスが「内定者メンタルヘルス対応ライン」を導入し、コロプラがメンタルヘルス支援サービス「マイシェルパ」を導入するなど、企業は入社前からの手厚いサポートに注力しています。また、塩野義製薬が定年を実質廃止するなど、多様な働き方に対応した制度改革も進んでいます。

HRテック・AI活用

HRテック領域では、AIの活用が急速に進展しており、人事評価や採用プロセスでの導入が目立ちます。HRBrainは人事評価に「目標の振り返りAIレビュー機能」をリリースし、PeopleXの「AI面接」は品川区役所が採用するなど、AIが採用・評価の効率化と客観性向上に寄与しています。また、amptalkの「amptalk coach」が日産販社に導入されるなど、AIを活用した研修・育成ツールも広がりを見せています。一方で、アクセンチュアの調査では「日本企業のAI投資成果と従業員実感はグローバル平均を下回る」と指摘されており、AI導入後の効果を最大化するための伴走支援サービス『アイカタ』なども登場しています。基幹システムでは、ひとまいるグループが「COMPANY」を、小田急グループが「SmartHR」を導入するなど、HRISの導入による業務効率化も引き続き活発です。
