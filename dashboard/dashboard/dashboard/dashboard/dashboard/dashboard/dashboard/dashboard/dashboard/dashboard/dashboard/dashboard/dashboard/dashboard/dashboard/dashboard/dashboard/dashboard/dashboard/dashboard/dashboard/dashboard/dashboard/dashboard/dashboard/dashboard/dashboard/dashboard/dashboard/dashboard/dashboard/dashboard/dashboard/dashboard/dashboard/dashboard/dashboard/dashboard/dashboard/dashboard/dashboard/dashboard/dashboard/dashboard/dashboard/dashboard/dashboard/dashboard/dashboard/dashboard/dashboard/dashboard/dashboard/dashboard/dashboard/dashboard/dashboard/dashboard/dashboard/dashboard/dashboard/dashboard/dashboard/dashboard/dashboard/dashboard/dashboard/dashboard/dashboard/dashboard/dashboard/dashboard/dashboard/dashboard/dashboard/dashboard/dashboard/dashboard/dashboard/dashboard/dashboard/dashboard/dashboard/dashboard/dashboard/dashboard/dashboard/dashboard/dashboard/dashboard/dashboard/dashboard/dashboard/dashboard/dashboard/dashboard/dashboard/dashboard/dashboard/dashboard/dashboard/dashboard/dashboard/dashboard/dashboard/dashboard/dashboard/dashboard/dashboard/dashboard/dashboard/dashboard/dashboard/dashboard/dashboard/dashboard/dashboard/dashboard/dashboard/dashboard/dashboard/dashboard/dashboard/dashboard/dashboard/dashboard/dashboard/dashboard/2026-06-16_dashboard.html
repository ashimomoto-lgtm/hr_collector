1on1・マネジメント領域

1on1の実施は広がる一方で、その機能不全や上司が抱える「壁」が指摘されており、部下の考える力を育む対話の再設計が求められています（パーソル総合研究所「なぜ1on1は機能しないのか？」「1on1という『旅』の途中で上司がぶつかる３つの『壁』」）。多様性を受け入れ、個と組織を活かすマネジメントが重視され、「AUBEモデル」のようなリーダー行動のアップデートや、建設的なコンフリクトを育む重要性が提唱されています（パーソル総合研究所「多様性時代の全員活躍マネジメント」「建設的なコンフリクトをどう育てるか」）。上司のコミュニケーションスキルや、部下の主体性を引き出す「フォロワーシップ」の醸成が注目されており、「指示待ち部下」を解消し自ら動くチームを作るマネジメント転換術も議論されています（ダイヤモンド・オンライン「仕事ができる人は『言ったよね』と言わない」、パーソル総合研究所「もう管理職だけに背負わせない、部下のフォロワーシップの時代へ」）。管理職は部下のキャリア開発支援における役割が大きく、キャリア面談の効果を高めるための教育が重要視されています（パーソル総合研究所「上司と部下のキャリア面談の効果をより高めるには？」「キャリア開発風土醸成へ―管理職の役割と求められる教育」）。

人事制度・採用・育成

企業は「人的資本経営」への取り組みを強化しており、JTが定年年齢の引き上げや年齢に左右されない人事制度改正を実施するなど、多様な人材が活躍できる制度設計が進んでいます（日本の人事部「人的資本経営調査」、HRzine「定年年齢の引き上げほか、年齢に左右されない人材マネジメントのための人事制度改正を実施—JT」）。採用においては、味の素が新卒とキャリア採用を繋ぐサービス「AJINOMOTO CO., INC. 『BOOKMARK』」を開始するなど、長期的な視点での人材獲得戦略が見られます。また、学生のAI面接への意識調査や、転職活動におけるSNS・口コミの影響も注目されています（日本の人事部「学生の『AI面接』に関する意識調査」「転職活動における『SNS・口コミの影響』に関するアンケート調査」）。育成面では、企業が提供する学習の定着と業務活用、研修状況に関する実態調査が実施されており、明治安田が「レンタル移籍」を導入し主体的な人材育成を目指すなど、実践的なキャリア開発支援が広がっています（日本の人事部「企業が提供する学習の定着と業務活用」、HRzine「明治安田が『レンタル移籍』を導入」）。働き方改革は進む一方、職場の「低体温化」といった課題も指摘されており、丸井や日立製作所が男性育休取得の障壁解消に取り組むなど、制度と実態の乖離を埋める動きが見られます（HRzine「働き方改革の結果、バーンアウトは減少した一方、職場の『低体温化』などが進行—パーソル総研調べ」、日経ビジネス「丸井、日立製作所　男性が育休渋る理由『迷惑かかる』『収入減る』を解消へ」）。

HRテック・AI活用

HR領域におけるAI活用が急速に進展しており、パソナが1次面接の負担軽減と評価支援を行うAIプロダクトを展開し、ミイダスが中小企業向けのAI採用戦略立案サービス「ミイダス AI採用バディー」を提供するなど、採用業務の効率化・高度化が図られています（HRzine「自社開発のAIプロダクトを展開—パソナ」「中小企業の採用戦略立案を支援するAIサービス『ミイダス AI採用バディー』を提供開始—ミイダス」）。AIは「適所適材」人事の実現にも活用され始めており、オリックス生命が配属先との相性分析にAIを導入するなど、データに基づいた人材配置が注目されています（日経ビジネス「人事の難題『適所適材』をAIが大変革　オリックス生命は配属先との相性分析」）。一方で、AI導入のROIを証明できる企業がわずか6％であるという調査結果や、生成AIが職場に広がらない背景に関する調査も行われており、AIの本格的な普及には課題も残されています（HRzine「AI導入のROIを証明できる企業は『6％』—アトラシアン」、パーソル総合研究所「生成AIはなぜ職場に広がらないのか」）。AIエージェントの活用や、AIとの対話を通じて組織課題を紐解く「COMPANY Talent Management」の新機能リリースなど、タレントマネジメントや組織運営におけるAIの役割も拡大しています（HRzine「AIが組織課題を紐解く新機能をリリース—WHI Holdings」、HRzine「AIとの対話で課題を明らかにし人事フリーランスを提案する『即プロ人事』を提供開始—Hajimari」）。
