1on1・マネジメント領域

1on1の重要性は認識されつつも、「パーソル総合研究所」のコラムが示すように上司が直面する「壁」が課題となっています。管理職のスキル不足が「人事白書2026 調査結果」で働きがい向上の障壁とされ、「日経ビジネス」もリーダーシップの低水準を指摘するなど、マネジメント層の強化が急務です。多様な働き方に対応するため、管理職にはキャリア開発支援やフィードバックを求め合えるチーム作りが求められ、マイクロマネジメントによる「成長錯覚」や「指示待ち部下」の問題解決も焦点です。また、「日本の人事部」が指摘する組織内の縦割り意識や、会議の非効率性もマネジメントの課題として浮上しています。「ダイヤモンド・オンライン」は出世する若手の特徴や降格させるべきリーダーの特徴を提示し、より効果的な人材配置と育成の必要性を示唆しています。

人事制度・採用・育成

採用活動では「学情」の調査が示すように28卒の内々定出しの早期化が顕著であり、「back check」の調査では本人情報だけでは採用判断が不十分という声が多く、多角的な評価が求められています。育成面では、若手社員に「主体性」が求められ、OJTや集合研修の実態調査が進む中で、「日本の人事部」が指摘するZ世代エンジニアへの指導難易度も課題となっています。キャリア開発支援は重要性を増しており、「パーソル総合研究所」は管理職によるキャリア面談の目的や教育の必要性を提唱し、「NTTドコモ」や「三菱電機」は独自のキャリア開発・転職制度を導入しています。女性のキャリア支援では「エスエス製薬」が企業横断のメンタリングを実施し、「HRTheory」が育休後の復職不安解消サービスを提供するなど、多様な人材の活躍を後押しする動きが活発化しています。働きがい向上や働きやすい職場環境の整備も引き続き重視され、「第三の賃上げ」など賃金以外の側面からの従業員エンゲージメント向上策も模索されています。

HRテック・AI活用

AI活用は採用・育成・マネジメントの各領域で進展しており、「日本の人事部」が紹介する「TG-WEB mee」のようなAI面接サービスや、「レゾナック」による生成AIを活用した管理職向けエンゲージメント改善支援アプリなどが登場しています。HRテックの導入により、人材データの活用が強化され、「HRBrain タレントマネジメント」を「住友ファーマ」や「小岩井乳業」が導入し、適材適所を実現する「TeamSpirit プロジェクトマネジメント」もリリースされています。生成AIは業務効率化だけでなく、マネジメントにおける「メンバーへの向き合い方」の本質的変化をもたらすと期待される一方、「パーソル総合研究所」の調査では職場への普及に課題も指摘されています。営業向けAIロープレツール「amptalk coach」が「日産」の全国販社に導入されるなど、特定の業務におけるAI活用も具体化しています。組織の見える化やデータ活用を促進する動きは、HRテックの導入と密接に連携し、より戦略的な人事運営を可能にしています。
