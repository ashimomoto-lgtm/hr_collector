1on1・マネジメント領域

1on1は依然として重要なマネジメント手法ですが、「なぜ機能しないのか？」「上司がぶつかる３つの『壁』」といった課題が指摘されており、部下の考える力を育てる対話の再設計が求められています（パーソル総合研究所「なぜ私たちは、それでも1on1をあきらめないのか？」シリーズ）。管理職の役割は多様化・複雑化しており、「ヤバイ管理職」や「プレイングマネジャー」といった負の側面が強調され、ハラスメント対策や部下の主体性を引き出すフォロワーシップの醸成が急務となっています（プレジデントオンライン、ダイヤモンド・オンライン）。U-ZEROによる「フィードバック経営」戦略の発表や、マネジメント課題を無料診断する『マネジメントカルテ』の提供開始など、フィードバック文化の定着やマネジメント課題の可視化・解決を支援する動きが見られます。多様な働き方や価値観に対応するため、管理職だけでなく組織全体で個と組織を活かす「AUBEモデル」のような全員活躍マネジメントへの関心が高まっています（パーソル総合研究所）。

人事制度・採用・育成

人的資本経営の推進が加速する中で、LIXILの「現場主導」のD&I推進やオンワードホールディングスの男性育休取得率100%達成など、多様性を尊重し包摂的な人事制度への転換が進んでいます。採用活動においては、「SNS採用ブースト」やNODIAによる面接代行オンラインプラットフォーム「INTERVIA」の登場、東急バスにおける外国人材の活用など、多様なチャネルと効率化ツールが導入されています。育成・キャリア開発では、パーソル総合研究所のコラムが示すように、管理職によるキャリア面談の重要性やNTTドコモのキャリア開発施策など、個人の成長と自律的なキャリア形成を支援する動きが活発化しています。新入社員の意識調査や育成・定着課題への関心も高く、若手社員のエンゲージメント向上や現場実践型の人材変革プログラム「SATOBITO」の本格始動など、定着と成長を促す取り組みが強化されています。

HRテック・AI活用

HRテック領域では、AIの活用が人事のあらゆるプロセスに浸透しつつあり、米オラクルが「Oracle Manager Edge」で人事リーダー育成支援を強化するなど、AIによる人材開発が注目されています。LINEヤフーがAI導入で人事総務の工数を半減させた事例や、KIYOラーニングが「AI研修アシスタント」を提供開始するなど、業務効率化や研修企画支援におけるAIの活用が進展しています。リーディングマークの「ミキワメAI」をNTT東日本グループが導入し組織開発に活用する事例や、「AIエージェント時代の人事白書 2026」の公開に見られるように、AIが人事戦略の中核を担う「Talent Intelligence」への期待が高まっています。一方で、パーソル総合研究所のコラムが示す生成AIの職場への普及課題や、データに基づく人事の「罠」といった指摘もあり、AIトランスフォーメーション（AX）推進には慎重な環境整備と定着のポイントが求められています。
