1on1・マネジメント領域

1on1は依然として重要なマネジメント手法であるものの、「パーソル総合研究所」のコラム「1on1という『旅』の途中で上司がぶつかる３つの『壁』」や「なぜ1on1は機能しないのか？」が示すように、その機能不全や課題が指摘され、対話の再設計が求められています。多様化する働き方に対応するため、「パーソル総合研究所」の「AUBEモデル調査」に基づく「多様性時代の全員活躍マネジメント」やリーダー行動のアップデートが推進されており、フィードバックを求め合えるチーム作りが重視されています。また、管理職には部下のキャリア開発支援の役割が強く求められ、「管理職志向」に関する調査も行われる中で、部下の主体性を引き出す「フォロワーシップ」の醸成が新たなマネジメントの焦点となっています。組織風土改革においては、経営理念の浸透や「健全な対立」を育む「風通しの良い組織」作りが重要視されています。

人事制度・採用・育成

人事制度・採用領域では、インフレや労働市場の変化に対応するため、初任給の動向調査が実施され、「メットライフ生命」のように大卒初任給を40万円に引き上げる企業も現れています。特にシニア層の活躍推進が喫緊の課題であり、「日経ビジネス」の「シニア覚醒」特集では、「静かな退職」を防ぐための「大和ハウス」や「森永製菓」など各社の多様な人事戦略が紹介されています。育成面では、キャリア自律を促す施策が重要視され、「NTTドコモ」のキャリア開発施策や「伊藤忠テクノソリューションズ」によるOJTツール「amoibe OJT」の導入などが見られます。また、「カルビー」が約17年ぶりに人事制度を抜本的に刷新するなど、企業の変革期における人事制度の再構築が進んでおり、エンゲージメント向上や従業員のウェルビーイング、ハラスメント対策も重要なテーマとなっています。

HRテック・AI活用

HRテック・AI活用領域では、AIが採用プロセスや業務効率化に導入されつつある一方で、「日経ビジネス」の「AI面接官で"二度手間地獄"」が示すように、その効果と課題が顕在化しています。タレントマネジメントシステムでは、「星野リゾート」が「Workday HCM」を導入して人材マネジメントの高度化を図り、「プラスアルファ・コンサルティング」の「タレントパレット」にはAIによるスキル定義自動生成機能が追加されるなど、AIを活用した機能強化が進んでいます。しかし、生成AIの職場での普及はまだ途上であり、「パーソル総合研究所」のコラム「生成AIはなぜ職場に広がらないのか」や「生成AIを仕事で使っても、なぜ私たちは忙しいままなのか」が示すように、利用率だけでは測れない実態や普及への課題が指摘されています。その他、人事評価システム「ジンジャー人事評価」の給与改定シミュレーション機能や、福利厚生、社内規程のDXサービス導入など、多様なHRテックソリューションが展開されています。
