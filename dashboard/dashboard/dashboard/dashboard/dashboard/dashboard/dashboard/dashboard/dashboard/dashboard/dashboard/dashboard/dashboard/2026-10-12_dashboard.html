人事制度・採用・育成

人事制度・採用・育成領域では、人的資本経営への意識の高まりから、人事部門の予算が増加傾向にあります。採用においては、ウエルシアHDや成豊建設が取り組むように、採用ブランディングやタレントアクイジションとタレントマネジメントの連携が重視され、27卒の就職活動実態調査も活発に行われています。育成面では、山陰合同銀行が「Monoxer」を導入して資格学習の定着度を可視化するなど、効果的な研修設計が模索されています。また、日経ビジネスの「三州製菓、パートにも賞与『年3回』」のように、同一労働同一賃金への対応や、ＳＯＭＰＯホールディングスによる「本人同意に基づく転居転勤運用」への転換など、多様な働き方を支える人事制度の柔軟化が進んでいます。

HRテック・AI活用

HRテック・AI活用は、人事領域のあらゆるプロセスで深化しています。KAKEAIの「Kakeai AI 1on1」やPeopleXの「PeopleX AI面接」のように、1on1や採用選考におけるAI活用が進展し、Job総研の調査では人事評価へのAI導入に高い関心が示されています。HRBrainは組織診断サーベイの結果からAIが改善アクションを提案する新機能をリリースし、IGSは「GROW-AX」で業務タスクの「人とAIの最適配置」を可視化するなど、AIは意思決定支援や業務効率化に不可欠な存在となっています。一方で、パーソル総合研究所のコラム「AIは人を賢くするのか―AI活用による『育成阻害』」や「『AIを使うほど、賢くなくなる』——"認知負債"という組織リスク」が指摘するように、AI活用による負の側面や、個人の時短が組織成果につながらない可能性への警鐘も鳴らされており、慎重な導入と運用の重要性が示唆されています。
