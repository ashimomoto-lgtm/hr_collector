1on1・マネジメント領域

1on1の重要性が強調されつつも、機能不全に陥る「壁」や、部下の考える力を育てる対話の再設計が課題として挙げられています（パーソル総合研究所「なぜ私たちは、それでも1on1をあきらめないのか？」シリーズ）。管理職だけでなく、部下の主体性を引き出す「フォロワーシップ」の醸成が多様性時代のマネジメントにおいて不可欠とされており（パーソル総合研究所「もう管理職だけに背負わせない、部下のフォロワーシップの時代へ」）、キャリア開発支援における管理職の役割も重視されています。また、多様性を活かすためのリーダー行動のアップデートや、建設的なコンフリクトを育む「AUBEモデル」の考察が進められています（パーソル総合研究所）。ハラスメント対策や風通しの良い組織作り、職場での陰口・うわさ話といった「致命的な構造」への対処も、健全な職場環境を保つための重要な動向です。

人事制度・採用・育成

ジョブ型・スキル型から「ケイパビリティ型」への人材マネジメントの転換が議論されており（HRzine）、インフレ・人材不足時代における「給与の未来展望」が離職防止の鍵とされています（パーソル総合研究所）。新入社員や若手の離職実態、心身の不調、育成・定着に関する調査結果が多数発表されており（日本の人事部「新入社員意識調査2026」「若手の離職実態調査2026」など）、早期離職対策が急務です。AI時代の人手不足に対応するため、リスキリング・リカレント教育の意義が再認識され（三菱UFJリサーチ&コンサルティング）、ANAグループが従業員教育訓練に「Monoxer」を導入するなど、具体的な取り組みも進んでいます。また、エヌエヌ生命保険の「選択的勤務日数制度」や三菱電機の「仕事と育児・介護の両立ハンドブック」リニューアルなど、多様な働き方や従業員支援の制度整備も進んでいます。

HRテック・AI活用

AIのHR領域への活用が急速に進展しており、SmartHRが「AIスキル定義読み取り」機能を提供開始するなど、従業員スキル管理の効率化が図られています。freee Eラーニングでは「AI研修アシスタント機能」が提供され、研修設計におけるAI活用も本格化しています。積水化学はTalentXの「MyTalent Platform」を導入し、AIネイティブ採用を実現するなど、採用プロセスでのAI活用も進んでいます。一方で、AI普及による採用への影響（レバレジーズ調べ）や、生成AIが職場に広がらない要因の分析（パーソル総合研究所）も行われており、AIの導入と定着には課題も存在します。人事職の8割以上が専門的定型業務の外部ツールへの委任を合理的と認識しており（ゴウリカ調べ）、データドリブンな人事戦略へのAI活用が加速しています。
