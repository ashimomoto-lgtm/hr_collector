1on1・マネジメント領域

1on1の機能不全と改善が引き続き重要なテーマであり、パーソル総合研究所のコラム「なぜ1on1は機能しないのか？」など、部下の自律を促す対話の再設計が模索されています。また、U-ZEROが「フィードバック経営」戦略を発表し、富士通やSmartsheet社とのパートナーシップを通じてフィードバック文化の醸成とリーダーシップの役割が強調されています。多様な働き方や価値観に対応するため、管理職にはキャリア開発支援やフォロワーシップの醸成が求められており、パーソル総合研究所の「キャリア開発風土醸成へ—管理職の役割と求められる教育」シリーズがその動向を示しています。さらに、マネジメント課題を診断する「マネジメントカルテ」の提供開始など、マネジメントの質の向上を支援する動きも見られます。会議における意思決定の質についても「合意形成が速い会議」ほど良い決断を生まない可能性が指摘されています。

人事制度・採用・育成

人事制度においては、オンワードホールディングスの男性育休取得率100％達成や女性管理職比率向上に見られるように、多様性とインクルージョンの推進が重視されています。採用領域では、イノーバが「採用ブランディングサービス」を提供するなど、戦略的なブランディングとデータに基づいた新卒・中途採用活動が活発化しています。育成面では、三菱UFJリサーチ&コンサルティングが提唱する「人手不足×AI時代におけるリスキリング・リカレント教育の意義」のように、キャリア自律と継続的な学習の重要性が高まっており、NTTドコモのキャリア開発施策も注目されます。国際基督教大学がタレントマネジメントシステム「カオナビ」を導入したようにシステムの活用が進む一方で、「ジョブ型・スキル型の人材マネジメントはなぜ限界を迎えるのか」という問いかけに見られるように、ケイパビリティ型への移行も議論されています。また、人材確保の切り札として「社宅」が息を吹き返すなど、多様なアプローチが試みられています。

HRテック・AI活用

HRテック領域では、AI活用による業務効率化が急速に進展しており、NTT系が生成AIで中国現地社員の行動を見える化し「ホウレンソウ」不要を実現したり、LINEヤフーがAI導入で人事総務の工数を半減させたりした事例が報じられています。KIYOラーニングの「AI研修アシスタント」提供開始やjinjerの「AI Assistant」機能提供、SmartHRの「人事データ」で人材戦略を支援するAIプロダクト戦略発表など、HRテックベンダー各社がAI機能を積極的に導入し、多様なHR業務を支援しています。さらに、LINEヤフー元会長が「"部下はAI"の1人起業」に挑戦するなど、AIが組織構造や働き方そのものを変革する可能性も議論されており、大手企業の「AIエージェント活用」に関する実態調査も行われています。しかし、パーソル総合研究所のコラム「生成AIはなぜ職場に広がらないのか」が示すように、現場での普及にはまだ課題も存在します。
