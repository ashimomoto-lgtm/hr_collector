2 HR界隈トレンド分析

1on1・マネジメント領域

1on1は上司が直面する「壁」を乗り越え、部下を「主役」として成長させるための重要な手段と認識されており（パーソル総合研究所「なぜ私たちは、それでも1on1をあきらめないのか？」）、その実践方法が模索されています。多様な働き方や価値観の中で、マネージャーには部下の主体性を引き出し、フォロワーシップを醸成する役割が強く求められています（パーソル総合研究所「令和の時代に求められるマネジャーの役割とは？」）。また、マイクロマネジメントによる「成長錯覚」を防ぎ、フィードバックを求め合えるチーム作りが重要視されており（パーソル総合研究所「その成長実感は本物か」「フィードバックを求め合えるチームのリーダーが実践していること」）、マネジメント課題を診断するサービスも登場しています（日本の人事部「マネジメントカルテ」）。

人事制度・採用・育成

キャリア自律の促進が重視され、管理職によるキャリア面談の重要性が高まっています（パーソル総合研究所「キャリア開発風土醸成へ―管理職の役割と求められる教育」）。女性のキャリア支援、障がいのある社員の活躍推進、仕事と介護の両立支援といった多様な人材への対応が人事制度の課題となっています（HRzine「女性のキャリア支援で森永製菓と企業横断のクロスメンタリングを実施」「障がいのある社員が適性を活かして組織を支える『全社業務推進グループ』を新設」「『仕事と介護の両立推進サービス』を提供」）。採用においては、本人情報だけでなく多角的な情報が求められ（back check調べ「採用判断、人事の約8割が『本人情報だけでは足りない』」）、新卒採用向け適性検査の登場や、海外連結子会社への転職制度導入など、採用・配置の多様化が進んでいます（ギブリー「Track Talent Assessment」リリース、三菱電機「Global Career Passport」導入）。

HRテック・AI活用

HRテック領域では、生成AIの活用が急速に進展しており、採用における「AI面接」やレゾナックによる管理職向けエンゲージメント改善支援アプリなどが登場しています（日本の人事部「AI面接」で採用を「人間らしく」する）。AIは単なる業務効率化に留まらず、マネジメントにおける「メンバーへの向き合い方」を変える本質的な変化をもたらすと期待されています（HRzine「生成AIがマネジメントにもたらす本質的変化」）。一方で、人事部門での生成AI活用には「情報漏洩・プライバシー保護への不安」が最大の課題として挙げられており（日本の人事部「人事部門での生成AI活用の課題」）、普及にはまだ課題があることも示唆されています（パーソル総合研究所「生成AIはなぜ職場に広がらないのか」）。タレントマネジメントシステム「HRBrain」やバックオフィスシステム「SmartHR」の導入事例も増え、人材データ活用や業務効率化への投資が活発です。
