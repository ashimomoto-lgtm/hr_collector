2 HR界隈トレンド分析

1on1・マネジメント領域

管理職の役割は複雑化しており、その負担感や「罰ゲーム化」が指摘されています（「HRzine」）。しかし、部下の意欲向上には上司の関わりが不可欠であり（エン調べ）、特に「パーソル総合研究所（コラム）」が提唱するキャリア面談力の向上は、部下の主体性や成長を促す上で重要です。一方で、マイクロマネジメントは部下の「成長錯覚」を引き起こすリスクがあるため（「パーソル総合研究所」）、リーダーには部下を自律させるマネジメントが求められています。チームの心理的安全性も注目され、「日本の人事部（サービス）」では『攻めの心理的安全性』eラーニングがリリースされるなど、対話を通じた組織開発が重視されています。

人事制度・採用・育成

人事制度・採用・育成領域では、戦略人事の重要性が高まり、人的資本開示への注目が集まっています（「株式会社大和総研」の書籍）。採用においては、「微経験人材」の活用や、内定者の家族向けセミナー（カルビー）など、多様な人材の獲得と定着に向けた取り組みが見られます。育成面では、TOPPANホールディングスが「GX検定」を活用して1000名規模のGX人材育成を進めるなど、特定のスキルを持つ人材の強化が図られています。また、WECARSが固定残業時間の短縮や有休増など人事制度改革を実施したように、従業員の働きがいやエンゲージメントを高めるための制度見直しも活発です。シニア社員の就業率や、戦略人事に必要な能力の不足も課題として認識されています（「ニッセイ基礎研究所」「日本の人事部」）。

HRテック・AI活用

HRテック・AI活用は急速に進展しており、採用領域ではフォワードが採用AI「エースジョブ」に判定特化AI「Jev」を導入し、アウンコンサルティングもAI採用広報支援サービス「AIO for HR」を提供するなど、効率化と高度化が進んでいます。育成面でも、ビズリーチのOnboard AIが営業職育成に「トーク分析」などを追加し、AIを活用したスキル開発が注目されています。一方で、生成AIの業務定着には課題も多く、「エクサウィザーズ」は「AX推進支援パッケージ」で活用停滞の解消を支援しています。また、「パーソル総合研究所（コラム）」は「AIを使うほど、賢くなくなる」と警鐘を鳴らすなど、AI依存による「認知負債」という組織リスクへの意識も高まっています。人材データと健康データの一元化（中国銀行の事例、プラスアルファ・コンサルティング）など、データ活用によるHRMの高度化も進展しています。
