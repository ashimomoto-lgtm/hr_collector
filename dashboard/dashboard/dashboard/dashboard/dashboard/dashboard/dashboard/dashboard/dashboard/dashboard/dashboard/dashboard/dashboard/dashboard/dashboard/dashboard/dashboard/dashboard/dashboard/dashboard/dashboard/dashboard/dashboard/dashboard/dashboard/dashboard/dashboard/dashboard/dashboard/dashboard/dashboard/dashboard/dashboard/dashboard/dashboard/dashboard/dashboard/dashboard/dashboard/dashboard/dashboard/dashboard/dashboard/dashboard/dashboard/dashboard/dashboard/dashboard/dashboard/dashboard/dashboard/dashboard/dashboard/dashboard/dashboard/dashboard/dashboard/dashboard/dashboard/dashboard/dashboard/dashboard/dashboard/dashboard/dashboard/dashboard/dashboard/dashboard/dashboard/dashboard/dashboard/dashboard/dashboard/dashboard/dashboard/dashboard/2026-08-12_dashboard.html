1on1・マネジメント領域

1on1は、上司が部下の主体性を引き出し、成長を支援する重要な手段として注目されていますが、パーソル総合研究所のコラム「1on1という『旅』の途中で上司がぶつかる３つの『壁』」が示すように、その実践には課題も存在します。多様な働き方や価値観に対応するため、マネージャーにはマイクロマネジメントを避け、部下の「成長錯覚」を招かないよう、個と組織を活かす「AUBEモデル」のような全員活躍マネジメントが求められています。また、パーソル総合研究所のコラム「フォロワーシップをいかに醸成するか」では、部下のフォロワーシップを醸成し、チーム全体でフィードバックを求め合える関係性の構築がリーダーの重要な役割とされています。ハラスメント対策も重要視され、パーソル総合研究所のコラム「パワハラと指導の違いとは？」のように、潜在的ハラスメントを防ぐための正しい対策が求められています。

人事制度・採用・育成領域では、従業員のキャリア自律支援が重要視されており、管理職によるキャリア面談や教育の強化が求められています。森永製菓とエスエス製薬による女性のキャリア支援「クロスメンタリング」や、三菱電機の海外連結子会社約100社を対象とした転職制度「Global Career Passport」のように、多様な人材の活躍を促す取り組みが進んでいます。採用においては、back checkの調査で約8割の人事が「本人情報だけでは足りない」と回答しており、ギブリーの「Track Talent Assessment」のような新卒採用向け適性検査の活用が進む一方、若手社員には「主体性」が求められています。また、人的資本可視化指針の改訂を受け、パーソル総合研究所のコラム「経営戦略を"実行力"に変える人材戦略」が示すように、経営戦略と連動した人材戦略の重要性が高まっています。

HRテック・AI活用

HRテック・AI活用領域では、生成AIが人事・マネジメント業務に大きな変革をもたらしています。レゾナックは「生成AIを活用した管理職向け従業員エンゲージメント改善支援アプリ」を自社開発し、マネジメントの本質的な変化を促しています。採用においては「AI面接」が対話の質を高める活用法として注目され、パーソルビジネスプロセスデザインの「レポラビ」のような採用レポート高速化サービスも登場しています。一方で、日本の人事部の記事「人事部門での生成AI活用の課題は『情報漏洩・プライバシー保護への不安』が最多」が示すように、人事部門での生成AI活用には課題も挙げられており、パーソル総合研究所のコラム「生成AIはなぜ職場に広がらないのか」では職場への普及の遅れも指摘されています。タレントマネジメントシステムでは、小岩井乳業が「HRBrain」を導入し、日本原子力防護システムが「SmartHR」を、ヤマト運輸が「COMPANY」を採用するなど、人材データ活用やバックオフィス業務効率化の動きが活発です。
