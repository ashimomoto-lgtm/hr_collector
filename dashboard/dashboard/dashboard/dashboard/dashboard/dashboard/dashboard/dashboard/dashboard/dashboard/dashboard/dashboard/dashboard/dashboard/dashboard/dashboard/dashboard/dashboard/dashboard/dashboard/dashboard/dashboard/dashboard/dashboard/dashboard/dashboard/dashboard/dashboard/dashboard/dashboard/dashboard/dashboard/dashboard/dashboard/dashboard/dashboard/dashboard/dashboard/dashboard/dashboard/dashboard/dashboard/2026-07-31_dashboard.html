1on1・マネジメント領域

1on1は、上司が「壁」にぶつかりながらも部下の主体性を引き出し、キャリア開発を支援する重要な手段として注目されています（パーソル総合研究所「なぜ私たちは、それでも1on1をあきらめないのか？」シリーズ）。多様な働き方や価値観に対応するため、管理職にはマイクロマネジメントを避け、部下の「成長錯覚」を解消し、フォロワーシップを醸成する役割が強く求められています（パーソル総合研究所「その成長実感は本物か」「フォロワーシップをいかに醸成するか」）。製造業の現場リーダーが管理業務に追われる実態（X Mile調べ）や、組織の無駄を解消し、エンゲージメントを高めるためのマネジメント転換術（パーソル総合研究所「指示待ち部下」は上司が原因？）が模索されています。組織の多様性を力に変え、個と組織を活かす「AUBEモデル」のような新しいマネジメント手法も提唱されており（パーソル総合研究所「多様性時代の全員活躍マネジメント」）、マネジメント課題の無料診断サービス「マネジメントカルテ」も登場しています。

人事制度・採用・育成

採用力強化のため「報酬の改定」が過半数の企業で実施され（日本の人事部「過半数の企業が『報酬の改定』で採用力強化」）、東京エレクトロン デバイスのように平均5％の賃上げを発表する企業も現れています。働きやすい職場づくりの施策では有休奨励が最多ですが、リモートワークには地域格差が見られます（日本の人事部「『働きやすい職場』施策、最多は有休奨励」）。Z世代エンジニアのOJT指導の難易度や指導担当者の負担（日本の人事部「Z世代エンジニアに対するOJT指導の難易度と指導担当者の負担の実態」）、新入社員の育成・定着が課題となっており、JTBはタレントアクイジションによるキャリア採用を強化しています。戦略人事の推進には「経営課題を人材課題・組織課題へ翻訳する力」が求められ（パーソル総合研究所「戦略人事はなぜ進まないのか」）、NTTドコモのようにキャリア開発施策を実践する企業も増えています。

HRテック・AI活用

HR領域におけるAI活用が急速に進展しており、「AI面接」で採用の対話の質を高める試みが見られます（日本の人事部「AI面接」で採用を「人間らしく」する）。特に人事・採用職は生成AIのヘビーユーザーが65.1％と最も高い割合を占めており（ラグザス調べ）、Sansanやメルカリでは「CHRO兼AI責任者」が登場するなど、AIが人的資本経営の中核を担いつつあります（日経ビジネス「Sansan、メルカリ『CHRO兼AI責任者』登場」）。採用管理システム（ATS）の利用が広がる中、一条工務店が説明会自動化サービス「リクルートミル」を導入し、三菱ケミカルが採用オウンドメディア「MyTalent Brand」を公開するなど、採用プロセスにおけるテクノロジー活用が進んでいます。また、クラウド労務管理サービス「弥生労務 Next」やタレントマネジメントシステム「マイナビ TalentBase」の機能拡充、ストレスチェックと産業保健業務代行サービスの提供開始など、HRテックが人事業務全般を支援する動きが活発です。
