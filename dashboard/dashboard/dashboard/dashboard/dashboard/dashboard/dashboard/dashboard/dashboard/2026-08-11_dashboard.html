1on1・マネジメント領域

1on1やマネジメント領域では、上司と部下の関係性強化と部下の主体性引き出しが重要なテーマとなっています。パーソル総合研究所のコラム「なぜ私たちは、それでも1on1をあきらめないのか？」シリーズでは、1on1の課題と継続の重要性が示され、多様な価値観を持つメンバーを活かす「AUBEモデル」や「フォロワーシップ」の醸成が考察されています。また、「日本の人事部」の「マネジメントに関する意識調査」からもマネジメントのあり方への関心が高いことが伺え、マイクロマネジメントによる「成長錯覚」への警鐘やパワハラと指導の違いに関する議論も活発です。令和の時代に求められるマネジャーの役割が再定義され、部下の主体性を引き出すための具体的な行動が模索されています。

人事制度・採用・育成

人事制度・採用・育成領域では、多様な働き方や個人のキャリア自律を支援する動きが加速しています。森永製菓とエスエス製薬による「女性のキャリア支援」や日立製作所の「仕事と介護の両立推進サービス」は、多様な人材の活躍を後押しする具体例です。採用においては「back check」の調査で本人情報以外の採用判断の重要性が指摘され、「ギブリー」が新卒採用向け適性検査「Track Talent Assessment」をリリースするなど、採用手法の進化が見られます。育成面では、パーソル総合研究所の「キャリア開発風土醸成」コラムが管理職によるキャリア面談の重要性を説き、三菱電機は海外子会社向けの転職制度「Global Career Passport」を導入し、グローバルな人材流動性を高めています。人的資本可視化指針の改訂を背景に、経営戦略と連動した人材戦略の重要性が高まっていることも注目されます。

HRテック・AI活用

HRテック・AI活用の動向では、生成AIが人事領域に大きな変革をもたらしつつあります。日本の人事部が報じた「AI面接」は採用プロセスの効率化と質の向上に貢献し、「レゾナック」は生成AIを活用した管理職向けエンゲージメント改善支援アプリを開発するなど、マネジメント支援への応用も進んでいます。HRzineでは、生成AIがマネジメントにもたらす本質的変化は「メンバーへの向き合い方」であると指摘されており、業務効率化に留まらない活用が期待されます。一方で、日本の人事部の記事「人事部門での生成AI活用の課題は『情報漏洩・プライバシー保護への不安』が最多」が示すように、情報セキュリティやプライバシー保護への懸念も課題として認識されています。また、「SmartHR」のようなバックオフィスシステムの導入も進んでおり、HR業務全体のデジタル化が加速しています。
