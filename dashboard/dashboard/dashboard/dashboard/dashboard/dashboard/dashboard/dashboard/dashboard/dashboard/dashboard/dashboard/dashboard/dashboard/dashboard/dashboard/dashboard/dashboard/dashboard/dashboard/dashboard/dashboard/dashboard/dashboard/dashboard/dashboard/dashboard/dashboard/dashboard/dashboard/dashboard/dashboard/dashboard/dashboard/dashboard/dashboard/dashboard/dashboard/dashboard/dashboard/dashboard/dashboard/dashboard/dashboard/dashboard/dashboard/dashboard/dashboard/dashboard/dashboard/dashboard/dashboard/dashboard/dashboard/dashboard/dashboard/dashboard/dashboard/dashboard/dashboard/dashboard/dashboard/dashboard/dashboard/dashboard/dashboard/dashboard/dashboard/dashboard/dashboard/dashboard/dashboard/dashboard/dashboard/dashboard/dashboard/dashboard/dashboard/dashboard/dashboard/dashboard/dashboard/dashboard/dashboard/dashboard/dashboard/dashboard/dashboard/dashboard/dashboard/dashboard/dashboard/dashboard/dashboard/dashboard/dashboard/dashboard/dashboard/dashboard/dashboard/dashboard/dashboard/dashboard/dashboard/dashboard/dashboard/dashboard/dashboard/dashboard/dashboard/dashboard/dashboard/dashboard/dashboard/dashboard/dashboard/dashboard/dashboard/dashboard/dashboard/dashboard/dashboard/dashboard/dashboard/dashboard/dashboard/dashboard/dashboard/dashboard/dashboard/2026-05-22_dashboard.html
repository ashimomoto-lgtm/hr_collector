2 HR界隈トレンド分析

1on1・マネジメント領域

1on1は依然として重要なマネジメント手法でありながら、「パーソル総合研究所」のコラムが示すように、その機能不全や上司が直面する「壁」が課題として認識されています。コミュニケーション研修の強化（「ヒューマン」の調査）やフィードバックを求め合えるチーム作りが重視され、多様なリーダー行動が模索されています。管理職の負担軽減とマネジメントの質の向上を目指し、「STELAQ」の「AI副課長」や「KPMGジャパン」の「対人対話ナビゲーションエージェント」のように、AIを活用した対話支援や判断支援の動きが活発化しています。また、フォロワーシップの醸成も重要なテーマとして注目されており、管理職だけでなく組織全体で部下の主体性を引き出す試みが広がっています。

人事制度・採用・育成

人事制度においては、「カルビー」が約17年ぶりに制度を刷新するなど、企業変革に対応した抜本的な見直しが進んでいます。育児離職やエンゲージメント、社員の声に関する調査が活発に行われ、多様な働き方や従業員のウェルビーイングへの配慮が重視されています。採用領域では、「インフィニティエージェント」が採用マーケティング支援サービスを提供し、「学情」の調査が示すように20代キャリア採用の難化が顕著であり、応募から内定までのスピードが重視されています。育成面では、「日立製作所」が10万人規模のAIプロフェッショナル人材育成に乗り出すなど、AI時代に対応したリスキリングやキャリア開発が喫緊の課題となっています。「丸紅」が「しくじりデータベース」を公開しAIで教訓化するなど、失敗事例を活かした学習も注目されています。

HRテック・AI活用

HRテック領域では、AIの活用が人事・マネジメント業務の多岐にわたる場面で急速に進展しています。採用では、「GMOインターネットグループ」が「PeopleX AI面接」を導入し、「MIXI」もAI面接を組み込むなど、候補者体験向上と効率化が図られています。マネジメント支援では、「KPMGジャパン」が「対人対話ナビゲーションエージェント」を提供し、「STELAQ」が「AI副課長」を開発するなど、対話の質向上や判断支援にAIが活用されています。「トラスコ中山」がAIで人事異動プロセスを高速化し、約98%の工数削減を実現した事例や、「jinjer」が「退職アラート」機能を提供するなど、データに基づいた人材管理への応用も進んでいます。「東芝」の統合人事給与システム「Generalist/HR/PR」には人財検索AI機能が搭載されるなど、既存システムへのAI組み込みも活発です。一方で、「パーソル総合研究所」のコラムが指摘するように、生成AIの職場での普及にはまだ課題も存在しています。
