2 HR界隈トレンド分析

1on1・マネジメント領域

マネジメント領域では、キャリア開発支援における管理職の役割が重視されており、パーソル総合研究所のコラムでは「キャリア面談の進め方」や「目的」が詳しく解説されています。また、同研究所の調査では、マイクロマネジメントが部下の「成長錯覚」を招くリスクが指摘されており、メンバーの主体性を引き出す「伴走型マネジメント」の重要性が高まっています。シンギュレイトはHRインスティテュートと共同で伴走型マネジメント育成プログラムを提供しており、多様な働き方に対応し、心理的安全性を通じてチームを動かすリーダーシップが求められています。

人事制度・採用・育成

人事制度・採用・育成領域では、新卒採用において約8割の企業がコミュニケーション能力を重視する一方で、日本の人事部の記事によると「3割以上が新卒採用で計画人数を充足できなかった」と、人材確保の難しさが浮き彫りになっています。育成面では、TOPPANホールディングスがBeyontの「GX検定」を活用して大規模なGX人材育成を進めるなど、特定のスキルを持つ人材開発が活発です。また、dodaの調査では定年まで勤める前提のない大学生が8割超に上り、カルビーが内定者の家族向けセミナーを開催するなど、若手のキャリア観の変化に対応したエンゲージメント施策や家族支援も注目されています。

HRテック・AI活用

HRテックとAI活用は急速に進化しており、アウンコンサルティングは「AIO for HR」というAI採用広報支援サービスを提供開始しました。日経ビジネスの独自調査では経営層の8割がAIを日常利用していると報じられていますが、パーソル総合研究所のコラムでは「AIを使うほど、賢くなくなる」という"認知負債"のリスクも指摘されています。カオナビの「カオナビエンゲージメント」のように人材データとサーベイを連携させ改善案を提示するサービスや、三菱電機が「グローバル人財情報基盤」にAIを活用するなど、戦略的なデータ活用が進む一方で、GIGの調査では中途求職者の52.8%がAIの回答で「応募見送り」を経験しており、AI活用における人間中心のアプローチの重要性が示唆されています。
