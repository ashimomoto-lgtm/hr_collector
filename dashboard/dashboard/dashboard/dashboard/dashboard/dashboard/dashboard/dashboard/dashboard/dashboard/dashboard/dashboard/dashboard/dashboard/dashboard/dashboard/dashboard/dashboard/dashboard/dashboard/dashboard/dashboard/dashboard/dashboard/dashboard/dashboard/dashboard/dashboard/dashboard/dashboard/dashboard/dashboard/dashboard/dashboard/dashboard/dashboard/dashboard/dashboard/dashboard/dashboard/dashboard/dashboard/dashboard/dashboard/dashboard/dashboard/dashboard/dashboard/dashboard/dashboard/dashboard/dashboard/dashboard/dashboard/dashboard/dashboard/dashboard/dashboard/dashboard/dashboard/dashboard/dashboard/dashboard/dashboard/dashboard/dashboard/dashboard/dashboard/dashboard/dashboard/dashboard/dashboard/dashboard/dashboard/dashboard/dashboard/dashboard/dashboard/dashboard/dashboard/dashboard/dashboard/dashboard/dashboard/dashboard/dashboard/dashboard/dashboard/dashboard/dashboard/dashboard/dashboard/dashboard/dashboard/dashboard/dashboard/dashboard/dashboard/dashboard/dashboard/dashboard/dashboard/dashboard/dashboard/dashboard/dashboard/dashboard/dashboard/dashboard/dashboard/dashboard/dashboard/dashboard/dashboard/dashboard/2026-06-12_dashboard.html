1on1・マネジメント領域

1on1やキャリア面談の重要性が再認識される一方で、その機能不全や上司が直面する「壁」が課題として浮上しています（パーソル総合研究所「1on1という『旅』の途中で上司がぶつかる３つの『壁』」など）。マネジメントにおいては、上司が部下の主体性を引き出し、自ら動くチームを作るための「フォロワーシップ」醸成が注目されており（パーソル総合研究所「もう管理職だけに背負わせない、部下のフォロワーシップの時代へ」）、従来の指示待ち型からの転換が求められています。また、多様な人材が活躍するための「AUBEモデル」のような全員活躍マネジメントや、ハラスメント対策を含む健全な組織風土の構築が重視されています。東京海上日動火災保険・城田宏明社長の事例のように「現場の声」を経営課題に活かす動きもあり、管理職のコミュニケーション能力やキャリア開発支援の役割がより一層重要になっています。

人事制度・採用・育成

人事制度においては、カルビーが約17年ぶりに人事制度を抜本的に刷新するなど、企業を取り巻く環境変化に対応した制度改革が進んでいます。採用・育成面では、新入社員の初任給調査やキャリア意識調査が実施され（労務行政研究所「2026年度 新入社員の初任給調査」など）、若年層の定着支援やキャリアオーナーシップを育む人財戦略が重視されています。明治安田が「レンタル移籍」を導入し主体的な人材育成を目指すなど、多様な育成手法が試みられています。また、働き方改革による「低体温化」やメンタル不調による休職・退職者実態調査など、従業員のウェルビーイングやエンゲージメント維持が喫緊の課題として認識されています。女性活躍推進や裁量労働制の適切な制度設計も引き続き重要なテーマです。
