1on1・マネジメント領域

1on1やマネジメント領域では、管理職が部下の主体性やキャリア自律を支援する役割が強く求められています。パーソル総合研究所のコラムでは、「1on1という『旅』の途中で上司がぶつかる３つの『壁』」や、部下のフォロワーシップを醸成する重要性が繰り返し強調されています。また、「マイクロマネジメントで広がる、部下の『成長錯覚』」への警鐘や、「指示待ち部下」をなくすマネジメント転換術など、多様な働き方や価値観に対応したマネジメントへの転換が図られています。日本の人事部が提供する「マネジメントカルテ」のように、組織のマネジメント課題を診断し、具体的な解決策を模索する動きも活発です。

人事制度・採用・育成

人事制度・採用・育成領域では、人的資本経営の推進が顕著で、企業は採用力強化のために「報酬の改定」を実施し、CxO、特にCHROの採用が増加しています。パーソル総合研究所は「戦略人事はなぜ進まないのか」と問いかけ、人事部に経営課題を人材課題へ翻訳する力を求めています。また、JTBが「タレントアクイジション」を推進し、三菱ケミカルが「MyTalent Brand」を導入するなど、採用ブランディングやキャリア採用の強化が進んでいます。福利厚生の充実（CCHの「ライフプラス」）や、オンボーディングの重要性、さらには「働きやすい職場」施策として有休奨励やリモートワーク環境整備が挙げられ、従業員の定着とエンゲージメント向上への取り組みが多角的に展開されています。さらに、ストレスチェックや育児・介護休業法への対応など、従業員のウェルビーイングと法令遵守も重要なテーマとなっています。

HRテック・AI活用

HRテック・AI活用は、人事領域におけるデジタルトランスフォーメーションを加速させています。日本の人事部が「AI面接」や「採用管理システム（ATS）利用実態調査」に関する記事を公開しており、採用プロセスでのAI活用が広がりを見せています。HRzineの調査では、「人事・採用職」が生成AIのヘビーユーザーの割合が最も高い職種であることが示され、フォワードの調査では「AIによるスカウトメール」も内容次第で受け入れられる傾向が明らかになりました。日経ビジネスではSansanやメルカリが「CHRO兼AI責任者」を任命した事例や、MUFGが「サカナAI」を活用してAI金融を推進する動きが報じられ、AIが経営戦略の中核を担う存在へと進化していることが伺えます。
