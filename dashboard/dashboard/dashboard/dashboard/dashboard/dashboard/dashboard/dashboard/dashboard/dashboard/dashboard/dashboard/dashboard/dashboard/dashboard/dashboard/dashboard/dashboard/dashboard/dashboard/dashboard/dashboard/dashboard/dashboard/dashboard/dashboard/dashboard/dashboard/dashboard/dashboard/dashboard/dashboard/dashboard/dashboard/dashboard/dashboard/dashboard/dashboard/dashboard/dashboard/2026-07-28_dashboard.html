1on1・マネジメント領域

1on1は引き続きマネジメントの要として注目されており、「プレジデントオンライン」が「正解」を提示しない対話の重要性を説くなど、その質向上への関心が高い。しかし、「HRzine」や「パーソル総合研究所」のコラムでは、1on1が空回りする理由や機能しないケースが指摘され、フィードバック文化の醸成や部下の主体性を引き出す対話の再設計が課題となっている。多様な働き方や価値観に対応するため、管理職には「パーソル総合研究所」が提唱するキャリア開発支援やフォロワーシップの醸成が求められており、従来の「指示待ち部下」を生むマネジメントからの転換が図られている。また、「日本の人事部」の調査からは、Z世代エンジニアへのOJT指導の難易度に関する実態も明らかになり、マネジメント層への支援の必要性が高まっている。

人事制度・採用・育成

採用領域では、AIを活用したスカウトメールが「HRzine」の調査で約9割の候補者に「内容次第」で受け入れられるなど、テクノロジーの導入が進展している。人材獲得競争の激化を受け、「日経ビジネス」が報じる新卒採用における「学業」評価軸の登場や、「マイナビ」の調査で27卒の初任給引き上げ企業が89.1%に達するなど、採用戦略の多様化と高度化が進む。人事制度においては、HRBPの導入予定がない企業が6割に上り、「日本の人事部」の調査では人事部門の兼務実態も明らかになるなど、専門人材の不足が課題として浮上。人的資本経営の推進が叫ばれる中、「日立」の中畑氏や「ソニー」の安部氏が「明確な経営戦略と連動した人材戦略」の重要性を強調しており、エンゲージメントサーベイの活用や福利厚生サービス「ライフプラス」の導入など、従業員体験向上への取り組みも進んでいる。

HRテック・AI活用

HRテック領域では、AIの活用が急速に進展しており、「HRzine」の調査ではAIによるスカウトメールが採用候補者に受け入れられつつあることが示されている。特に「ヒューマネージ」は500万人の適性検査データを活用したAI面接サービス「TG-WEB mee」を提供開始するなど、採用プロセスでのAI導入が顕著である。一方で、「パーソル総合研究所」の調査では、AI活用の業務成果には情報収集や優先順位付けといった「メタスキル」が影響することや、生成AIが職場に広がりきらない実態も指摘されており、単なるツール導入に留まらない活用戦略の重要性が増している。その他、組織マネジメント課題を診断する「マネジメントカルテ」や、「マイナビ TalentBase」のようなタレントマネジメントシステム、スキルデータをインフラ化する「Skillnote」など、多様なHRテックソリューションが登場し、人事・マネジメント業務の効率化と高度化を支援している。
