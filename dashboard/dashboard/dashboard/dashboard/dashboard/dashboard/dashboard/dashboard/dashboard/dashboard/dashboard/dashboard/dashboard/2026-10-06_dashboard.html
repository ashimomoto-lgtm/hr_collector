2 HR界隈トレンド分析

1on1・マネジメント領域

1on1・マネジメント領域では、AIを活用したマネジメント支援が進化しており、KAKEAIが「Kakeai AI 1on1」の提供を開始するなど、AIが管理職の業務をサポートする動きが活発です。また、管理職のキャリア開発や面談力向上への教育が重視されており、「パーソル総合研究所」のコラム群では、管理職の役割がキャリア開発風土醸成に不可欠であることが繰り返し述べられています。管理職向けマネジメント支援アプリ「『上司力』向上アプリ」の提供開始など、管理職のスキルアップを促進するツールも登場しています。さらに、「日本の人事部」の調査からは、管理職の仕事に対する意識やマネジメントの現状と課題が浮き彫りになり、後継者育成やリーダーシップのあり方についても議論が深まっています。

人事制度・採用・育成

人事制度・採用・育成領域では、人事評価に対する従業員の不満が高く、AI評価への期待が大きいことが「Job総研」の調査で示されています。大東建託が「社内FA制度」を導入するなど、従業員の自律的なキャリア形成を支援する人事制度が注目を集めています。採用においては、求人票の工夫（「日経ビジネス」の「応募が来る求人票は90文字が勝負」）や「微経験人材」の活用が模索され、経営層の理解醸成が課題となっています。人的資本開示の重要性が増しており、「『資本市場に向けた人的資本開示【改訂版】』」の刊行やSMBCの「HUMAN CAPITAL STORY 2026」発行がその動向を裏付けています。社員の学びを支援する学習プラットフォーム「学びサポートHQ」や、大日本印刷の「DNPグループ・アルムナイネットワーク」発足など、育成・定着への取り組みも活発化しています。

HRテック・AI活用

HRテック・AI活用の動向として、HR領域でのAI活用が急速に進展しており、KAKEAIの「Kakeai AI 1on1」やHRBrainの組織診断AI、On Technologiesの「LearningOn」など、多岐にわたるサービスが登場しています。採用プロセスでは、HERPの「HERP AI Recruiter」による書類選考の自動評価や、PeopleXの「PeopleX 面接支援AI」、ウォンテッドリーの「AI議事録」機能など、AIが選考・面接支援の効率化に貢献しています。人事・労務業務においても、jinjerの「ジンジャー人事労務」やマネーフォワードの「マネーフォワード クラウド健康管理」がAIによる自動化を進めています。一方で、「パーソル総合研究所」が「AIは人を賢くするのか―AI活用による『育成阻害』」や「AIを使うほど、賢くなくなる」といった警鐘を鳴らしており、AI活用がもたらす負の側面にも注目が集まっています。AIリテラシー向上への取り組みとして「生成AIパスポート」のシラバス改訂も行われており、HR領域におけるAIの導入と効果的な活用が今後の主要テーマとなっています。
