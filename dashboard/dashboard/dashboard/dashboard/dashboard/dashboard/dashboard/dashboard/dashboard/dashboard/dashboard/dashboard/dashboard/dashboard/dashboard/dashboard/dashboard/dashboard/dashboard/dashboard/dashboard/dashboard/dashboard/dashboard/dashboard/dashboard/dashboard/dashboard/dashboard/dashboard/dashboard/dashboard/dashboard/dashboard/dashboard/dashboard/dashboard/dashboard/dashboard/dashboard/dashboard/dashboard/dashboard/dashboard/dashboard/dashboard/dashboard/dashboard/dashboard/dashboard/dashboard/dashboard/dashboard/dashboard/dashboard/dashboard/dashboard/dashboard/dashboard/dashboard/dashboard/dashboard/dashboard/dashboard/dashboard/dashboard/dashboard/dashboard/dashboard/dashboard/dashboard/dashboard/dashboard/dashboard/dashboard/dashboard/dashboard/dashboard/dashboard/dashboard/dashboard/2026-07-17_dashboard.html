1on1・マネジメント領域

1on1やマネジメント領域では、多様な働き方や価値観に対応するため、マネージャーの役割変革が喫緊の課題となっています。パーソル総合研究所のコラム群では、1on1が機能しない原因や上司がぶつかる「壁」を深掘りしつつ、部下のキャリア自律支援やフォロワーシップ醸成の重要性を多角的に議論しています。U-ZEROによる「フィードバック経営」戦略の発表や、日本の人事部が提供する『マネジメントカルテ』のような組織課題診断ツールも登場し、具体的な手法やツールの活用が進展していることが伺えます。また、「AUBEモデル」調査に基づく多様性時代のリーダー行動の考察も進み、個と組織を活かすマネジメントが重視されています。

人事制度・採用・育成

人事制度・採用・育成領域では、新入社員の意識調査や早期離職に関する実態調査が継続的に行われ（「新入社員意識調査2026」、「新人・若手の早期離職に関する実態調査」）、育成・定着が重要な課題であることが示されています。転職市場では「35歳限界説」が後退し、中高年や女性にも機会が広がっていることがニッセイ基礎研究所の「変わる転職市場の年齢構造」で指摘されています。ウェルビーイングな働き方への関心が高まり、ECOTONEが働き手と経営者のギャップを指摘する一方、ストレスチェックのデータ分析も進んでいます。NTTドコモが実践するキャリア開発施策や、日本の人事部が本格始動した「SATOBITO」のような現場実践型の人材変革プログラムなど、具体的な育成・キャリア支援策も展開されています。

HRテック・AI活用

HRテック・AI活用の動向では、AIの活用が急速に進展しており、米オラクルが「Oracle Manager Edge」で人事リーダー育成支援を強化し、jinjerがAIプロダクト戦略を発表し「国内HRテックNo.1」を目指すなど、各社がAIを軸としたサービス展開を加速しています。採用活動においてもAIの活用が顕著で、プルークスが「採用ショート動画制作プラン」を提供し、NODIAが「INTERVIA」で面接代行プラットフォームを開始するなど、AIが採用プロセスに深く組み込まれています。組織開発では、NTT東日本グループがリーディングマークの「ミキワメAI」を導入した事例が見られます。一方で、パーソル総合研究所の「生成AIはなぜ職場に広がらないのか」というコラムが示すように、生成AIの職場への普及には課題も指摘されており、就活生がAIを面接や試験に利用する「不正」の線引きといった倫理的な側面も議論されています。
