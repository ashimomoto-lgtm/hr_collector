2 HR界隈トレンド分析

1on1・マネジメント領域

1on1は広く導入される一方で、その機能不全や上司が直面する「壁」が課題として顕在化しており、部下の考える力を育てる対話の再設計が求められています（パーソル総合研究所「なぜ1on1は機能しないのか？」「1on1という「旅」の途中で上司がぶつかる３つの「壁」」）。多様な人材が活躍する組織を実現するため、フィードバックを求め合えるチーム作りや、フォロワーシップの醸成が重要視され、「AUBEモデル」のようなリーダー行動のアップデートが提唱されています（パーソル総合研究所「多様性時代の全員活躍マネジメント」「フォロワーシップをいかに醸成するか」）。また、管理職のキャリア開発支援の役割が強調され、経営リーダー育成や組織風土改革への関心が高まっており（パーソル総合研究所「キャリア開発風土醸成へ」、HRzine「EVeMマネ型トレーニング」）、組織の陳腐化を防ぐための変革も議論されています（日経ビジネス「堀場製作所・堀場会長の経営教室」）。

人事制度・採用・育成

初任給の動向（日本の人事部「2026年度 新入社員の初任給調査」）や「AI時代の転職・採用」への関心が高まる中、多様な働き方やキャリア形成への支援が重視されています。特にシニア層の活用は喫緊の課題であり、大和ハウスや三谷産業、森永製菓などの事例から、定年延長、成果主義、研修による再活性化、アシストスーツ活用など、シニアを「戦力」と捉える人事戦略が注目されています（日経ビジネス「シニア覚醒　「静かな退職」を防ぐ人事戦略」）。また、従業員エンゲージメント向上やキャリア自律支援が重要視され、NTTドコモのキャリア開発施策やカルビーの人事制度刷新など、企業が従業員の「自分らしさ」と成長を両立させるための制度改革を進めています。カスハラ・就活セクハラ対策義務化など、法改正への対応も進む一方、若手のエンゲージメント低下やオンボーディングの重要性も指摘されています（HRzine「なぜ電気機器業界は「若手の従業員エンゲージメントが低い」のか」）。

HRテック・AI活用

HRテック領域では、AIの活用が採用・育成・マネジメントの各プロセスで急速に進展しています。AI面接官による業務効率化（日経ビジネス「AI面接官で"二度手間地獄"」）や、タレントパレットへのAIスキル定義自動生成機能追加（HRzine）など、具体的な導入事例が増加しています。一方で、職場での生成AIの普及には課題も指摘されており（パーソル総合研究所「生成AIはなぜ職場に広がらないのか」）、利用率だけでは測れない実態や、AIと協働する上での「ジョブ型の真実」が議論されています（日本の人事部「『ジョブ型の真実とAIと協働』」）。Workday HCMやAIエージェント「WorkOn」、社内規程DXサービス「KiteRa Biz」など、多様なHRテックソリューションが企業のデジタル変革を支援しており、障がい者の業務におけるAI利用調査も進むなど、その活用範囲は広がりを見せています。
