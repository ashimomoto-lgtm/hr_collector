2 HR界隈トレンド分析

1on1・マネジメント領域

1on1は部下の成長を促す重要な対話と認識されつつも、「機能しない」「壁にぶつかる」といった課題が指摘されており、対話の再設計や上司のスキル向上が求められています（パーソル総合研究所のコラム群）。多様な働き方や価値観に対応するため、管理職には部下のキャリア開発支援やフォロワーシップ醸成の役割が強調され、従来の「指示待ち部下」を脱却するマネジメント転換が求められています。また、組織マネジメント課題の無料診断サービス「マネジメントカルテ」が登場し、客観的な課題把握への関心が高まっています。上司の「コミュ力」や「伝え方」が部下の信頼獲得に不可欠である一方（ダイヤモンド・オンライン）、問題社員への対応や「功労者だから仕方ない」という組織の甘えが組織崩壊を招くという警鐘も鳴らされています。

人事制度・採用・育成

人事制度では、王子HDによる「退職一時金の廃止」や、2026年10月に改正される「パート・有期雇用労働法」における同一労働同一賃金ガイドラインの見直しなど、制度改革の動きが活発です。採用・育成においては、「新入社員意識調査2026」や「若手の離職実態調査2026」から新入社員の育成・定着課題が浮き彫りになり、入社1年目からの「キャリア自律」の重要性が強調されています。また、人手不足とAI時代を見据えたリスキリング・リカレント教育の意義が注目され（三菱UFJリサーチ&コンサルティング）、オンワードホールディングスのように男性育休取得率100%を達成するなど、多様な人材が活躍できる環境整備が進んでいます。転職市場では「35歳限界説」が後退し、中高年や女性にも転職機会が拡大しており（ニッセイ基礎研究所）、dodaの「転職市場予測2026下半期」では求人数増加が予測されるなど、流動性の高い市場が続いています。

HRテック・AI活用

HRテック領域では、AIの活用が人事総務業務の効率化を大きく推進しています。LINEヤフーはAI導入により人事総務の工数を半減させ、KIYOラーニングは「AI研修アシスタント」で研修企画の効率化を支援しています。SmartHRは人事データを活用したAIプロダクト戦略を発表し、NTT系では生成AIで中国現地社員の行動を見える化するなど、AIによるデータ活用と業務改善が加速しています。また、大手企業での「AIエージェント活用」に関する実態調査が行われ、jinjerも「AI Assistant」の提供を開始するなど、AIエージェントの導入が広がりつつあります。一方で、パーソル総合研究所の調査では「生成AIはなぜ職場に広がらないのか」という課題も提起されており、普及にはまだ障壁があることが示唆されています。国際基督教大学がタレントマネジメントシステム「カオナビ」を導入するなど、HRテックによる人材管理の高度化も進んでいます。
