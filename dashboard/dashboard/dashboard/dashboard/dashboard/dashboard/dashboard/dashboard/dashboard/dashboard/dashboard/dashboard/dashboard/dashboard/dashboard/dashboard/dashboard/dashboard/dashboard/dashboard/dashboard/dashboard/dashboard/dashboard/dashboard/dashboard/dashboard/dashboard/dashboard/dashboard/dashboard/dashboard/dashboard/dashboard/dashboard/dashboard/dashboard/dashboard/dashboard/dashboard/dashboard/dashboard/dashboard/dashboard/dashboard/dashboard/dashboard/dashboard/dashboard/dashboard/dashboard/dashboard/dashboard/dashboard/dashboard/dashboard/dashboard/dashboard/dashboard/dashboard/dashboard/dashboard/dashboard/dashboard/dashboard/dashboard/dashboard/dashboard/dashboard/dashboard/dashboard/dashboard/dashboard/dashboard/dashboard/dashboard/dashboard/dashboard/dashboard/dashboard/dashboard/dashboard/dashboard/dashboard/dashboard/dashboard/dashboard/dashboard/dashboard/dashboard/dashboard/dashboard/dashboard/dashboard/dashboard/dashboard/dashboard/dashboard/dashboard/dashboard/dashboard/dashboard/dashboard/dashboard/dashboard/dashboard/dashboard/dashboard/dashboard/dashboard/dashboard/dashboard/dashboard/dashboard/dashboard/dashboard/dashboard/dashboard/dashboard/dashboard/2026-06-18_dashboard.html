1on1・マネジメント領域

1on1の運用は依然として重要な課題であり、パーソル総合研究所の調査では「機能しない理由」や「上司がぶつかる壁」が指摘され、部下の考える力を育てる対話の再設計が求められています。多様性時代のマネジメントでは、東京海上・城田社長の「イエスマンは不要」という考え方のように、リーダーシップのあり方が変革し、部下の主体性やフォロワーシップを引き出す重要性が増しています。パーソル総合研究所の「AUBEモデル調査」は、フィードバックを求め合えるチーム作りや、管理職が部下のキャリア開発を支援する役割に注目しています。また、ハラスメント対策や「風通しの良い組織」作りも引き続き重要なテーマです。

人事制度・採用・育成

人事制度は、多様な働き方やキャリア形成を支援する方向へ進化しています。JTは定年年齢の引き上げや年齢に左右されない人材マネジメントのための制度改正を実施し、レオパレス21もキャリア形成と働きやすさを支援する制度改定を行いました。丸井や日立製作所は男性の育休取得を促進するための課題解消に取り組んでおり、女性活躍推進やダイバーシティ&インクルージョンが制度設計の重要な要素となっています。採用においては、味の素が「AJINOMOTO CO., INC. 『BOOKMARK』」で新卒採用とキャリア採用の連携を強化する一方、採用広報のKPI設定と効果測定の重要性も高まっています。人手不足を背景に、リスキリング・リカレント教育の意義が再認識され、障がい者雇用支援サービスも拡充されています。
