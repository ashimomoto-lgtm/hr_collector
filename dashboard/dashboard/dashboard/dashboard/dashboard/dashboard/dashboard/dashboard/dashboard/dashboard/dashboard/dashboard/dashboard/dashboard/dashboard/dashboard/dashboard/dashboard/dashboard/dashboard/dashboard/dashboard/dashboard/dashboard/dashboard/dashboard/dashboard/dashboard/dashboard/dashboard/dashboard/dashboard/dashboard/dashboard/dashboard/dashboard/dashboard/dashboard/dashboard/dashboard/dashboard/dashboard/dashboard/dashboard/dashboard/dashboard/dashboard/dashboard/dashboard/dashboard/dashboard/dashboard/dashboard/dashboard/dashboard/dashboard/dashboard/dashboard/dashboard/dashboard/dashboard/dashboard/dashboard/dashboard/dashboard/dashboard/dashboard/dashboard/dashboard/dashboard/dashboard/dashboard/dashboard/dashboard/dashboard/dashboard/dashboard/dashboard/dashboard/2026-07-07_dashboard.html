1on1・マネジメント領域

1on1やマネジメント領域では、効果的な対話の重要性が再認識されており、「パーソル総合研究所」のコラム群（「なぜ1on1は機能しないのか？」「1on1という「旅」の途中で上司がぶつかる３つの「壁」」など）は、1on1の課題とその深化を模索する動向を示しています。また、管理職によるキャリア開発支援や「フォロワーシップ」の醸成（「日本の人事部」の「もう管理職だけに背負わせない、部下のフォロワーシップの時代へ」）が注目され、部下の主体性を引き出すマネジメントへの転換が求められています。Z世代社員とのコミュニケーションの難しさ（「東洋経済オンライン」の「Z世代社員を叱ったところ､50代上司困惑…」）や、ハラスメント回避と適切な指導の両立（「HRzine」の「ハラスメント回避行動が新たなリスクに」）も重要なテーマです。多様な人材が活躍できる「AUBEモデル」（「パーソル総合研究所」）のような、個と組織を活かすマネジメント手法への関心も高まっています。

人事制度・採用・育成

人事制度・採用・育成領域では、人材マネジメントのモデルが進化しており、「HRzine」の「ジョブ型・スキル型の人材マネジメントはなぜ限界を迎えるのか」が示すように、ケイパビリティ型への移行が議論されています。採用においては、新入社員の意識や離職実態（「日本の人事部」の「新入社員意識調査2026」「若手の離職実態調査2026」）が詳細に分析され、企業は「ナビサイトなどの就職企業人気ランキングの影響度」を注視しています。また、インフレ・人材不足時代における「給与の未来不安」が離職につながるとして、給与制度の見直し（「日本の人事部」の「インフレ・人材不足時代に人材をつなぎとめる「給与の未来展望」」）が喫緊の課題です。従業員のエンゲージメント向上（「HRzine」の「日本企業のエンゲージメントは膠着状態」）や、エヌエヌ生命保険の「選択的勤務日数制度」のような多様な働き方の導入、三菱電機の「仕事と育児・介護の両立ハンドブック」リニューアルなど、従業員体験を重視した制度設計が進んでいます。

HRテック・AI活用

HRテック・AI活用の領域では、AIが人事の様々な側面に深く浸透し始めています。「HRzine」が報じる「国際基督教大学がタレントマネジメントシステム「カオナビ」を導入」のように、タレントマネジメントシステムの導入は引き続き活発です。採用においては、「AI面接」（「東洋経済オンライン」の「AI面接に踏み切る企業のホンネ」）や、積水化学が導入した「MyTalent Platform」による「AIネイティブ採用」など、AIを活用した効率化と高度化が進展しています。育成面では、「freee Eラーニング」が「AI研修アシスタント機能」を提供開始し、NTTドコモソリューションズが生成AIを活用した新卒エンジニア研修を刷新するなど、AIによる研修設計・実施支援が注目されています。一方で、「ダイヤモンド・オンライン」の「AIは若手社員の敵か？ 味方か？」が示すように、AIが人材育成に与える影響や、「パーソル総合研究所」が指摘する「生成AIはなぜ職場に広がらないのか」といった導入・活用における課題も顕在化しています。
