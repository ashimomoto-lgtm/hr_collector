2 HR界隈トレンド分析

1on1・マネジメント領域

1on1の効果的な実施が引き続き重要視されており、「パーソル総合研究所」のコラムでは、機能しない1on1の課題や上司がぶつかる「壁」が指摘されています。多様なリーダー行動の考察や、管理職だけに頼らない「フォロワーシップ」の醸成がトレンドであり、「パーソル総合研究所」は部下の主体性を引き出す方法を提案しています。「日経ビジネス」の「ボスマネ」力チェックのように、管理職自身のスキルアップや意識改革への関心も高く、キャリア開発風土の醸成における管理職の役割が注目されています。「日本の人事部」の調査では「AI活用が変える職場とマネジメント業務」が分析されており、AI時代におけるマネジメントのあり方も模索されています。

人事制度・採用・育成

採用領域では、新卒採用におけるインターンの位置づけ見直し（「HRzine」）や、リファラル採用（「マブチモーター」）、「採用マーケティング」（「インフィニティエージェント」）など多様な手法が展開されています。20代キャリア採用では「応募～内定が3週間以内」が約5割を占める（「学情調べ」）など、選考のスピードアップが求められています。人事制度においては、「カルビー」が約17年ぶりに人事制度を刷新するなど、組織の変革に合わせた抜本的な見直しが進んでいます。従業員エンゲージメントの向上や、育児離職と両立の男女差実態（「日本の人事部」）といった多様な働き方への対応、コミュニケーション研修の強化（「ヒューマン」）も重要な動向です。

HRテック・AI活用

HRテック領域では、AIの活用が採用、人事異動、人材育成など多岐にわたり加速しています。「KPMGジャパン」はAIでリアルタイムに対話の質を高める「対人対話ナビゲーションエージェント」を提供し、「トラスコ中山」ではAI活用により人事異動の意思決定プロセスを高速化しました。「東芝」の統合人事給与システム「Generalist/HR/PR」への人財検索AI機能搭載や、「MIXI」によるAI面接導入など、具体的なHR業務へのAI組み込みが進んでいます。一方で、「パーソル総合研究所」のコラム「生成AIはなぜ職場に広がらないのか」が示すように、AI活用の普及には課題も存在しますが、「マネーフォワード・辻庸介社長」のように経営層はAIの波に乗り遅れることへの強い危機感を持っています。
