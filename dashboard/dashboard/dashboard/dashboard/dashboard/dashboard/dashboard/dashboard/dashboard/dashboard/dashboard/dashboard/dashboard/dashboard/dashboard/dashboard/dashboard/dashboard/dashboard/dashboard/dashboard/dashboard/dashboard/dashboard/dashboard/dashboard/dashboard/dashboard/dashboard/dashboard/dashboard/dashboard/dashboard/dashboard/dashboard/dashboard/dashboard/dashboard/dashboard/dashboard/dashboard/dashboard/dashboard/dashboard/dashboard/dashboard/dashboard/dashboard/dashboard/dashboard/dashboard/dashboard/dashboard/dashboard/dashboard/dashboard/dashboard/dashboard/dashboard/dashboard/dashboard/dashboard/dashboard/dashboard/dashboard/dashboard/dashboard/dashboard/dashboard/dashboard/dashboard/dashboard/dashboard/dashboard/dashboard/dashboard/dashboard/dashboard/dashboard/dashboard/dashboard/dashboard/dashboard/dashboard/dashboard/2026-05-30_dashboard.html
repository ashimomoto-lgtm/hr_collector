1on1・マネジメント領域

1on1の有効性とその実践における課題が注目されており、「パーソル総合研究所」のコラムでは「1on1という『旅』の途中で上司がぶつかる３つの『壁』」や「なぜ1on1は機能しないのか？」といったテーマが繰り返し議論されています。管理職には、部下のキャリア開発支援やフォロワーシップの醸成が強く求められており、「パーソル総合研究所」は「多様性時代の全員活躍マネジメント」としてAUBEモデルを提唱しています。また、「ダイヤモンド・オンライン」の記事群は、部下を鼓舞し、健全な職場環境を築くためのリーダーシップのあり方について具体的に言及しており、マネジメント層の対話力や組織風土改革への関与が重視されている動向が見られます。

人事制度・採用・育成

初任給の引き上げや福利厚生の拡充など、人材獲得競争を背景とした報酬・待遇改善の動きが活発です。「メットライフ生命」が大卒初任給を40万円に引き上げ、「IDOM」が入社1年目から有給19日を付与するなど、具体的な施策が発表されています。また、シニア層の活用が喫緊の課題となっており、「日経ビジネス」は「静かな退職」を防ぐ人事戦略として「大和ハウス」や「三谷産業」の事例を紹介し、成果主義や多様性を活かした再活性化が模索されています。キャリア自律支援やオンボーディングの重要性も高まっており、「カルビー」が人事制度を抜本的に刷新するなど、企業は従業員のエンゲージメント向上と持続的な成長を両立させるための制度改革を進めています。

HRテック・AI活用

HRテックの導入は、人材マネジメントの高度化と業務効率化を推進しています。「ワークデイ」のWorkday HCMを「星野リゾート」が導入し、国内外約8000名の人材マネジメントを強化する事例が見られます。「jinjer」の「ジンジャー人事評価」では給与改定シミュレーション機能が提供され、人事評価と給与計算の連携が進んでいます。AI活用は採用分析の高度化やスキル定義の自動生成に寄与しており、「タレントアンドアセスメント」の「SHaiN」や「プラスアルファ・コンサルティング」の「タレントパレット」がその代表例です。一方で、「パーソル総合研究所」の調査では「生成AIはなぜ職場に広がらないのか」といった課題も指摘されており、導入後の実態と効果的な活用方法が今後の焦点となるでしょう。
