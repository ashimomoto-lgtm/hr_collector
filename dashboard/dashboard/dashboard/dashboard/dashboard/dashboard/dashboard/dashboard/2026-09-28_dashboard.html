「AIを使うほど、賢くなくなる」——“認知負債”という組織リスク

2 HR界隈トレンド分析

1on1・マネジメント領域

管理職の役割は、キャリア面談を通じた部下のキャリア開発支援や、メンバーの主体性・独自性を活かすリーダー行動へのアップデートが求められています（パーソル総合研究所「キャリア面談の進め方」「リーダー行動のアップデート」）。「エン調べ」によると、入社1年目に意欲が高い社員の4割が2年目に失速する一方で、低意欲層の36.9％は「上司」によって持ち直すことから、上司のマネジメントが部下の意欲に大きく影響することが示されています。また、「日本の人事部」の調査では、マイクロマネジメントが部下の「成長錯覚」を広げる可能性が指摘されており、伴走型マネジメント育成プログラムの提供（シンギュレイト）や「攻めの心理的安全性」eラーニング（日本の人事部）など、より自律を促すマネジメント手法が注目されています。部下を「モンスター社員」に変える上司の話し方（ダイヤモンド・オンライン）や、アンガーマネジメントのコツ（日経ビジネス）など、部下とのコミュニケーションや感情コントロールの重要性も強調されています。

人事制度・採用・育成

人的資本開示への関心が高まり、「資本市場に向けた人的資本開示【改訂版】」（大和総研）のような書籍が刊行される中、企業は人事制度改革を進めています。「WECARS」は固定残業時間の短縮や有休の拡充といった人事制度改革を実施し、従業員エンゲージメント向上を目指す動きが見られます。「カルビー」の内定者家族向けセミナーや「ピジョン」の「子育てエンゲージメントカード」のように、従業員のライフステージに合わせた支援やエンゲージメント施策が多様化しています。「LIXIL」が回答率90％超の内製サーベイで組織変革を促進したり、「オーケーウェブら3社」が人事のオープンコミュニティ「HRラウンジ」を立ち上げるなど、組織エンゲージメントや人材育成の取り組みが活発化しています。外国人雇用における人権リスク対応（三菱UFJリサーチ&コンサルティング）や高年齢者雇用安定法への対応、海外進出時の新しい雇用スキーム「EOR」と「PEO」（HRzine）など、多様な働き方やグローバル化に対応した制度設計も課題となっています。

HRテック・AI活用

HR領域でのAI活用は加速しており、「フォワード」が採用AI「エースジョブ」に判定特化AI「Jev」を導入したり、「アウンコンサルティング」がAI採用広報支援サービス「AIO for HR」を提供するなど、採用プロセスでの活用が進んでいます。人材育成においても、「日経ビジネス」がAIを活用した「パラシュート型」の育成を提唱し、「エクサウィザーズ」は「イオン」の次世代経営幹部候補の育成を支援するなど、AIが個別最適化された学習をサポートする動きがあります。一方で、「日経ビジネス」が「役に立たないAI」の事例を挙げているように、過度な期待は禁物であり、生成AIの業務定着には課題も指摘されています（日本の人事部）。「パーソル総合研究所」は「AIを使うほど、賢くなくなる」という"認知負債"のリスクを警鐘しており、AIと人間の適切な協働が求められています。「カオナビ」が人材データとサーベイを掛け合わせた「カオナビエンゲージメント」をリリースするなど、データに基づいた組織改善や離職予兆の可視化（インフィニットマインド）にHRテックが活用されています。
