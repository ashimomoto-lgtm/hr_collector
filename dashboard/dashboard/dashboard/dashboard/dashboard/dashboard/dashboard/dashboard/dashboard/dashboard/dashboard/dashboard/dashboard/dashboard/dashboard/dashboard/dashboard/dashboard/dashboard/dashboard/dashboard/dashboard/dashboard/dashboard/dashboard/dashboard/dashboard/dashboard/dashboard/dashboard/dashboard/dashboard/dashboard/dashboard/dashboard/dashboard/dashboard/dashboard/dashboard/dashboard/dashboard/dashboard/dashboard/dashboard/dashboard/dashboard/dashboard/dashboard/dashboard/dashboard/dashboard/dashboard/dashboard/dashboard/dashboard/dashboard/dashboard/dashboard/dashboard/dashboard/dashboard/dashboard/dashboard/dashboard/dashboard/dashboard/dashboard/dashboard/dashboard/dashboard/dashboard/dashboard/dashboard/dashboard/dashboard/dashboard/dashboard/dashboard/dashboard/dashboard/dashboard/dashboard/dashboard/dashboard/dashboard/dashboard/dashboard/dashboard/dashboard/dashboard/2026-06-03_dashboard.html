1on1・マネジメント領域

1on1の課題と重要性が改めて認識されており、「パーソル総合研究所」のコラムでは「1on1という『旅』の途中で上司がぶつかる３つの『壁』」や「なぜ1on1は機能しないのか？」といったテーマで、その機能不全の原因と部下の考える力を育てる対話の再設計が議論されています。多様化する働き方の中で、マネジメント層にはフィードバックを求め合えるチーム作りやキャリア開発支援の役割が強く求められ、「パーソル総合研究所」の「多様性時代の全員活躍マネジメント」ではAUBEモデルが提唱されています。また、部下の主体性を引き出す「フォロワーシップ」の醸成が重要視され、「もう管理職だけに背負わせない、部下のフォロワーシップの時代へ」といった視点から、組織全体のエンゲージメント向上が図られています。「ダイヤモンド・オンライン」の「優秀な部下が『静かに辞意を固める』瞬間・ワースト1」が示すように、離職防止の観点からも上司のマネジメントがより重要になっています。「EVeM」が提供する「EVeMマネ型トレーニング」のようなマネジメントワークショップも登場し、管理職のスキルアップが活発化しています。

人事制度・採用・育成

人事制度の刷新や見直しが活発で、「カルビー」が約17年ぶりに人事制度を抜本的に刷新した事例や、「森永製菓」が「56歳」役職定年を廃止するなど、多様な働き方やシニア層の活躍を促進する動きが見られます。初任給の引き上げも顕著であり、「メットライフ生命」が大卒初任給を40万円に引き上げたほか、「労務行政研究所」による「2026年度 新入社員の初任給調査」でもその動向が示されています。従業員のエンゲージメント向上やウェルビーイングへの配慮も進んでおり、「IDOM」が有給休暇制度を拡大し「ライフスタート手当」を新設したり、「ホットランドHD」が「カンリー福利厚生」を導入したりする事例が見られます。採用市場では「伊藤忠商事」が「みんなの新卒就職人気企業ランキング」で2年連続総合首位を獲得するなど、企業ブランドが重要視される一方で、「ダイヤモンド・オンライン」の「スタートアップが大好きな『リファラル採用』の注意点」のように採用手法の多様化と課題も指摘されています。キャリア形成支援も強化されており、「NTTドコモ」が実践するキャリア開発施策や「日本の人事部」の「キャリア形成とロールモデルに関する実態調査」など、個人の自律的なキャリア形成を支援する取り組みが注目されています。

HRテック・AI活用

AIはHR領域において急速に活用が進んでおり、「メルカリ」がCTOをCHRO兼CAIOに任命しAIネイティブ企業への変革を目指すなど、経営戦略の中核にAIが位置づけられています。採用活動では、「HRクラウド」が「採用一括かんりくん」にAIでオファーレターを自動作成する機能を追加し、「ウォンテッドリー」も「Wantedly Hire」でAIが選考基準を提案する新機能をリリースするなど、AIによる効率化・高度化が進んでいます。人事評価やタレントマネジメントにおいてもAIの活用が広がり、「jinjer」が「ジンジャー人事評価」で給与改定シミュレーション機能を提供し、「プラスアルファ・コンサルティング」の「タレントパレット」にはAIがスキル定義を自動生成する機能が追加されています。しかし、「パーソル総合研究所」のコラム「生成AIはなぜ職場に広がらないのか」や「生成AIを仕事で使っても、なぜ私たちは忙しいままなのか」が示すように、AIツールの導入と実際の業務活用にはまだ課題も存在します。「リクルートワークス研究所」の「AIはホワイトカラーの仕事を奪う？」といった調査や「日本の人事部」の「AI時代の転職・キャリアに関する実態調査」が示すように、AIが雇用やキャリアに与える影響についても注目が集まっています。
