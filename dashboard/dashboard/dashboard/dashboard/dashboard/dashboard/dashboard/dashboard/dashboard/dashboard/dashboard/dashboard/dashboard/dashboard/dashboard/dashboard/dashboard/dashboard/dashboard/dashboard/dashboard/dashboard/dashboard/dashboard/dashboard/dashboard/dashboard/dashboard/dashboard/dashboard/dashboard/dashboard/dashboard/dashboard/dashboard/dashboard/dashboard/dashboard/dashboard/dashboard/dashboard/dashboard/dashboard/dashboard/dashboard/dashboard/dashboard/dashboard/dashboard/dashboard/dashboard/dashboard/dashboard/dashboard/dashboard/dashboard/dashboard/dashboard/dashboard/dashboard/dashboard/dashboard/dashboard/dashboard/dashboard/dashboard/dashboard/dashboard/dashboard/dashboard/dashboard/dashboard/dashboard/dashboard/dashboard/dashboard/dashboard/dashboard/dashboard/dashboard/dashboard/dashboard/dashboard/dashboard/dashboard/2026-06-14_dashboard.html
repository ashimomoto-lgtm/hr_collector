2 HR界隈トレンド分析

1on1・マネジメント領域

1on1の重要性が認識されつつも、パーソル総合研究所の調査では「1on1という『旅』の途中で上司がぶつかる３つの『壁』」や「なぜ1on1は機能しないのか？」といった機能不全の課題が指摘されています。多様性時代においては、上司だけでなく部下の「フォロワーシップ」が重視され、パーソル総合研究所は「もう管理職だけに背負わせない、部下のフォロワーシップの時代へ」と提言し、主体性を引き出すマネジメントへの転換が求められています。また、キャリア開発支援における管理職の役割が強調され、部下のキャリア自律を促す教育や面談の重要性が高まっています。さらに、日本の人事部が紹介する「『異質を認め合う組織』」の構築や、パーソル総合研究所が提唱する「健全な対立」を育むリーダー行動が、多様性時代のマネジメントに不可欠とされています。

人事制度・採用・育成

人的資本経営の進展に伴い、JTが「定年年齢の引き上げ」や「年齢に左右されない人材マネジメント」を導入するなど、多様な働き方やキャリア形成を支援する人事制度改革が進んでいます。採用においては、味の素が「新卒採用の縁をキャリア採用につなぐサービス」を開始し、長期的な視点での人材確保が図られているほか、大東建託が「PayPayで給与の受け取りが可能に」なる「賃金デジタル払い制度」を導入するなど、従業員の利便性を高める動きも見られます。育成面では、日本の人事部が「『企業が提供する学習の定着と業務活用』に関する実態調査」を実施しており、明治安田が「レンタル移籍」を導入するなど、主体的に価値を生み出す人材育成への投資が活発化しています。働き方改革の進展でバーンアウトは減少する一方、パーソル総研は「職場の『低体温化』などが進行」していると指摘し、若年層の定着支援や従業員ウェルビーイングの向上が引き続き重要なテーマとなっています。女性活躍推進や障害者雇用支援も継続的な取り組みであり、シチズン時計の「スキル管理」実装のように、現場の課題を乗り越え、人材の可視化と活用を進める動きが見られます。

HRテック・AI活用

HRテック領域ではAIの活用が急速に進展しており、パソナやROXXの「Zキャリア AI面接官」のような採用プロセスにおけるAI面接官の導入、ミイダスの「ミイダス AI採用バディー」による中小企業の採用戦略立案支援など、多岐にわたるサービスが提供されています。人事・マネジメント領域においても、Hajimariの「即プロ人事」のようにAIとの対話を通じて組織課題を明らかにするサービスや、WHI Holdingsの「COMPANY Talent Management」シリーズで組織課題を紐解くAI機能が登場し、PeopleXによる人事コンサルティングのAX（AIトランスフォーメーション）も拡充されています。一方で、アトラシアンの調査ではAI導入のROI（投資収益率）を証明できる企業がわずか「6％」であるとされ、パーソル総合研究所も「生成AIはなぜ職場に広がらないのか」という課題を指摘しており、AI活用の実態と効果にはまだギャップがあります。日本の人事部が「学生の『AI面接』に関する意識調査」や「採用現場におけるAI活用実態調査」を行うなど、AIがHR領域に与える影響の評価と、その普及に向けた課題解決が今後の焦点となるでしょう。
