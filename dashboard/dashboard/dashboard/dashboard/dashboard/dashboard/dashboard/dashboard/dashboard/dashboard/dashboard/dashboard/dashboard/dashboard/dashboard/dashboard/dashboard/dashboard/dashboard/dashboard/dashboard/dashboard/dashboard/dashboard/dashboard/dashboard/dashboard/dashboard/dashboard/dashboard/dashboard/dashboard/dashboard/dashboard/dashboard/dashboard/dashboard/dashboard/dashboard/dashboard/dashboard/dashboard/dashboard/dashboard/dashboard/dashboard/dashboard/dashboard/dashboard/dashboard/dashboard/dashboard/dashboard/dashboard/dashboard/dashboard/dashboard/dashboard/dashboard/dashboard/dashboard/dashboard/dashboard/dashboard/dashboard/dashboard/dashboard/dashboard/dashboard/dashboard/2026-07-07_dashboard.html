2 HR界隈トレンド分析

1on1・マネジメント領域

1on1は依然として重要なマネジメント手法であるものの、機能不全や上司が直面する「壁」が課題として指摘されており（パーソル総合研究所「なぜ1on1は機能しないのか？」）、部下の考える力を育てる対話の再設計が求められています。多様性時代のマネジメントでは、管理職がキャリア開発支援やフィードバックを求め合えるチーム作りを担う一方、「もう管理職だけに背負わせない、部下のフォロワーシップの時代へ」（パーソル総合研究所）という視点も重要視されています。また、ハラスメント回避行動が新たなリスクを生む可能性や、エンゲージメントの膠着状態、若手のバーンアウト（燃え尽き症候群）といった心理的側面への対応も喫緊の課題です。組織マネジメント課題を診断する「マネジメントカルテ」のようなツールの活用も進み、管理職の選抜・育成プログラムへの関心も高まっています。

人事制度・採用・育成

人事制度・採用・育成領域では、インフレと人材不足を背景に、若手の早期離職や新入社員の育成・定着が大きな課題となっています（パーソル総合研究所「給与の未来展望」）。「高卒新人に広がる『初任給バブル』」といった採用競争の激化が見られる一方で、SHIFTが「440人の採用ストップ」を発表するなど、AI活用による採用戦略の変化も顕著です。ジョブ型・スキル型からケイパビリティ型への人材マネジメントの移行が議論され、リスキリング・リカレント教育の意義が強調されています（三菱UFJリサーチ&コンサルティング）。ANAグループが従業員教育訓練に「Monoxer」を導入するなど、教育への投資も活発であり、法定雇用率引き上げに向けた障がい者雇用や、キャリア自律を促すキャリア開発施策（NTTドコモ）も注目されています。

HRテック・AI活用

HRテック・AI活用領域では、AIが人事・採用・育成の各プロセスに変革をもたらしています。SmartHRが「AIスキル定義読み取り」機能を提供開始し、TalentXが「MyTalent Platform」でAIネイティブ採用を実現するなど、AIを活用したタレントマネジメントシステムや採用ツールが普及しています。AI普及による厳選採用・採用抑制の報道は28卒の就活スケジュール前倒しに影響を与えており（レバレジーズ調べ）、人事職の8割以上が専門的定型業務を外部ツールに任せる合理性を認識しています（ゴウリカ調べ）。NTTドコモソリューションズでは新卒エンジニア研修に生成AIを導入しており、jinjerも「AI Assistant」機能を提供するなど、AIは業務効率化と人材育成の両面で活用が進む一方で、生成AIの職場への普及にはまだ課題があることも示唆されています（パーソル総合研究所）。
