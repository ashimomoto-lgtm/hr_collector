1on1・マネジメント領域

現代のマネジメントは、多様な働き方や価値観に対応し、部下の自律的な成長を促す方向へとシフトしています。パーソル総合研究所のコラム「なぜ私たちは、それでも1on1をあきらめないのか？」が示すように、1on1やキャリア面談を通じた個別の支援が重要視されています。一方で、アデコ調べでは「社員の約8割が将来管理職になりたくない」と回答するなど、管理職の負担感や魅力低下が課題です。マイクロマネジメントによる「成長錯覚」を防ぎ、権限委譲や心理的安全性確保によるチームの自律性を高めるマネジメントが求められています。書籍『逸脱させるマネジメント』や『抱え込む上司はいらない』からも、個の能力を最大限に引き出す新しいマネジメント手法への関心が見て取れます。

人事制度・採用・育成

人事制度・採用・育成領域では、新卒採用において「コミュニケーション能力」が約8割の企業で重視される一方で、26卒の学生はキャリアへの意識や働く価値観が多様化しています。TalentXの調査によると、リファラル採用では「報酬額」よりも「仕組みの構築」が紹介率を左右し、採用手法の多様化と戦略性が求められています。育成面では、管理職候補者育成プログラムや成人学習の重要性が高まり、ウィルネクストの調査が示すように育休復帰後の女性のキャリア意識変化への対応も課題です。また、大学卒新入社員の初任給を引き上げた企業が4割に達するなど、多様な人材の定着と活躍を促すための制度設計が不可欠となっています。ミドルシニア層の働きがい低下傾向（NEWONE調査）も、全世代にわたる人事制度の見直しを促しています。

HRテック・AI活用

HRテック・AI活用は、人事領域における効率化と高度化を急速に進めています。コニカミノルタジャパンが人財育成AI「AIシェルパ」を採用した事例や、NECが「35体のAIエージェント」で「無人部署」を実現した事例のように、AIは育成から業務効率化まで多岐にわたります。LayerXの「バクラク人事労務」やエフアンドエムの「オフィスステーション」におけるAI機能導入など、人事労務業務の自動化・効率化が進展しています。一方で、KiteRaの調査では「6割がAIエージェント活用に対する社内ルール・ガバナンスの整備遅れを経営課題と認識」しており、AIの悪用リスクやパーソル総合研究所が指摘する「認知負債」といった課題への対応も重要視されています。JetBの「Our AI面接」の「受検ログ機能」など、採用プロセスでのAI活用も進んでいます。
