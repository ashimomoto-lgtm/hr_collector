管理職の役割は、キャリア面談を通じた部下のキャリア開発支援（パーソル総合研究所コラム「キャリア開発風土醸成へ」）や、ワークエンゲージメント向上におけるサポート（日本の人事部「ワークエンゲージメントの高い人に共通する『上司のサポート』」）が重視されています。しかし、アデコ調べでは社員の約8割が「将来管理職になりたくない」、管理職の約6割が「管理職は損」と回答しており、管理職のスキル不足や負担増が課題です。マイクロマネジメントによる「成長錯覚」の指摘（パーソル総合研究所コラム「その成長実感は本物か」）もあり、部下の自律性を促す権限委譲や心理的安全性（日本の人事部『攻めの心理的安全性』）の確保が求められています。また、日経ビジネスでは「カスハラ労災」を防ぐための管理職の役割が強調されるなど、多岐にわたる課題への対応が求められています。

人事制度・採用・育成

人事制度・採用・育成領域では、新卒採用においてコミュニケーション能力を重視する傾向が約8割の企業で見られます（日本の人事部「新卒の選考では、約8割がコミュニケーション能力を重視」）。企業は人材育成に注力しており、セブン＆アイや三井化学・レゾナックがトップ人材育成や育成制度の強化に言及しています。環境省がタレントマネジメントシステム「カオナビ」を導入し、職員一人ひとりの成長を後押しするなど、システムを活用した個人の成長支援が活発です。また、人事異動が離職検討のきっかけとなるケースが約6割に上る（HRBrain調べ）ことから、異動時の丁寧な面談やオンボーディングの重要性が高まっています。初任給の引き上げ企業が4割に達するなど、人手不足を背景とした採用競争も激化しています。

HRテック・AI活用

HRテック・AI活用は急速に進展しており、コニカミノルタジャパンが人財育成AI「AIシェルパ」を導入し、管理職候補者育成に活用する事例が見られます。採用領域では、UUUMがAI面接「COREMIRU Scan」を本格導入し、インディードリクルートパートナーズの調査ではAI活用後も採用数を減らさない企業が8割以上と、効率化と質向上を両立する動きが顕著です。タレントマネジメントシステムでは「タレントパレット」がMCP対応サーバー機能や「GLOBIS 学び放題」との連携を強化し、AIによる「タレントインテリジェンス」への進化が期待されています。一方で、生成AIの業務定着における課題や、「AIを使うほど賢くなくなる」という"認知負債"のリスク（パーソル総合研究所コラム「『AIを使うほど、賢くなくなる』」）も指摘されており、適切な活用と検証が求められています。
