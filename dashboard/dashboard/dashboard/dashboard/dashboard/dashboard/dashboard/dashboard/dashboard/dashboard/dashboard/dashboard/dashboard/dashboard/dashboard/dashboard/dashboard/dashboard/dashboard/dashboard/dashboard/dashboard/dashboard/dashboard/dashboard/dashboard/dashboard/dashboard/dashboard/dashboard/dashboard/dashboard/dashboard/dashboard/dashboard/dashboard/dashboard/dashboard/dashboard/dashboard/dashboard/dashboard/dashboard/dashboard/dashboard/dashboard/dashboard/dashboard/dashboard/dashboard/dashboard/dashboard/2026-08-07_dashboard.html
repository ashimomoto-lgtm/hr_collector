2 HR界隈トレンド分析

1on1・マネジメント領域

1on1は、パーソル総合研究所の「なぜ私たちは、それでも1on1をあきらめないのか？」シリーズが示すように、上司が直面する「壁」を乗り越え、部下の主体性を引き出す重要な手段として引き続き注目されています。しかし、ダイヤモンド・オンラインの「管理職は死亡率が高い」という記事や日経ビジネスの「全方位忖度マシーン」といった表現が示すように、管理職の疲弊や負担増大も顕著です。パーソル総合研究所の指摘するマイクロマネジメントによる「成長錯覚」を防ぎつつ、多様な働き方や価値観に対応したマネジメントへの転換が求められています。日本の人事部の「マネジメントに関する意識調査」や『マネジメントカルテ』提供開始の動きは、組織のマネジメント課題を可視化し、改善を促すニーズの高まりを示唆しています。フォロワーシップの醸成やパワハラ対策も重要なテーマとして議論されています。

人事制度・採用・育成

人的資本経営の観点から、キャリア開発と人材育成の重要性が増しています。パーソル総合研究所の「キャリア開発風土醸成へ」シリーズが示すように、管理職によるキャリア面談やキャリア開発支援が求められ、NTTドコモや川崎重工業では「学習者」視点での人材育成や研修後の行動変容を促す取り組みが実践されています。採用においては、back checkの調査が示すように「本人情報だけでは足りない」という意識が高まり、ギブリーの「Track Talent Assessment」のような適性検査が活用されています。多様な人材の活躍推進も進んでおり、エスエス製薬の「クロスメンタリング」による女性キャリア支援、日立製作所の「仕事と介護の両立推進サービス」、SHIROの「全社業務推進グループ」新設、三菱電機の「Global Career Passport」導入など、各社が独自の制度を構築しています。若手社員の「主体性」を求める一方で、Z世代エンジニアのOJT指導の難しさや、ワーキングマザーの「小1の壁」など、働き方の多様化に伴う新たな課題への対応も喫緊の課題となっています。

HRテック・AI活用

HRテック領域では、生成AIの活用が急速に進んでいます。日本の人事部の記事「AI面接」が示すように、採用プロセスにおけるAIの導入は対話の質を高め、より「人間らしい」採用を目指す動きが見られます。また、レゾナックが「生成AIを活用した管理職向け従業員エンゲージメント改善支援アプリ」を自社開発したように、マネジメント領域においてもAIが活用され始めています。HRzineの「生成AIがマネジメントにもたらす本質的変化は、業務効率化ではなく『メンバーへの向き合い方』」という指摘は、AIが単なる効率化ツールではなく、マネジメントの質的向上に貢献する可能性を示唆しています。一方で、パーソル総合研究所のコラム「生成AIはなぜ職場に広がらないのか」が問いかけるように、その普及にはまだ課題も存在しており、導入後の伴走支援サービス『アイカタ』のような取り組みも始まっています。
