1on1・マネジメント領域

1on1は上司が直面する「壁」や「旅」として言及され、その継続の重要性が示唆されています（パーソル総合研究所「なぜ私たちは、それでも1on1をあきらめないのか？」）。多様な働き方や価値観の中で、管理職は「全方位忖度マシーン」と化し疲弊する傾向が見られ（日経ビジネス）、その役割の再定義が求められています。部下の「成長錯覚」を招くマイクロマネジメントを避け（パーソル総合研究所）、主体性を引き出すフォロワーシップの醸成や、キャリア開発支援が管理職の重要な役割として注目されています。また、組織の「縦割り」意識や「優秀な人ほど辞めていく職場」といった課題解決のため、マネジメントの転換が急務とされています。

人事制度・採用・育成

採用では、新卒採用向け適性検査「Track Talent Assessment」のリリースや、学生の内々定保有状況の調査（マイナビ）が進む一方、JR東日本が「博士専用の採用枠」を設けるなど、多様な人材獲得への動きが見られます。育成面では、集合研修やOJTの実態調査（日本の人事部）が行われ、「Z世代エンジニアに対するOJT指導の難易度」が課題視されており、研修の「行動変容」を促す重要性が強調されています（HRzine）。人事制度では、USJが「60代クルー850人に拡大」するなどシニア採用が拡大し、三菱電機が「Global Career Passport」を導入するなど、多様な働き方を支援する制度が注目されています。また、ワーキングマザーの「小1の壁」や仕事と介護の両立支援（日立製作所、エムステージ）など、従業員のライフステージに合わせたサポートの必要性が高まっています。

HRテック・AI活用

HRテックとAIの活用は急速に進展しており、「AI面接」による採用の質の向上（日本の人事部）や、研修の「AI活用伴走サービス『アイカタ』」の提供（日本の人事部）など、多岐にわたる領域で導入が進んでいます。特に生成AIは、レゾナックが「管理職向け従業員エンゲージメント改善支援アプリを自社開発」するなど、マネジメント領域での活用が注目されており、業務効率化だけでなく「メンバーへの向き合い方」の本質的変化をもたらすと期待されています。一方で、人事部門における生成AI活用の課題として「情報漏洩・プライバシー保護への不安」が最多であり（日本の人事部）、職場への普及には慎重な姿勢も見られます。タレントマネジメントシステム「HRBrain」や統合人事システム「SmartHR」「COMPANY」の導入事例も増え、人材データ活用基盤の強化が進んでいます。
